title: 监控：机器容量和每个 worker 在做什么、做了多久
status: active
---

## 目标

主 agent 能看到机器容量和每个 worker 现在在做什么（写代码、跑测试、排队、停滞）、做了多久，不用自己去查进程。

## 范围

议程和 watch 里的「正在跑的重活」；负载越过阈值的提醒；停滞和合入被拒、worker 已退出的变更。

## 不做

不替主 agent 结束 worker；不做通用的系统监控。

## 成功标准

- S1 议程和 watch 显示哪个变更正在跑整组测试、已跑多久，以及排队的数量。（已满足：C-632, C-637）
- S2 负载越过阈值时 watch 只输出一行，带回差，不在阈值附近来回跳（测试证明）。（已满足：C-632）
- S3 停滞的派发、合入被拒且 worker 已退出的变更，出现在要主 agent 判断的事里。（已满足：C-632）
