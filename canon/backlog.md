# 待办顺序

负责人在这里排定先做哪些变更（D-20）：每个列表项开头的变更编号就是顺序，越靠前越先做。只有负责人编辑这个文件；agent 新建的变更不用加进来，会自动排在清单之后（按编号）。没有任务的 agent 从 `canon change list` 最前面取第一个没被认领的变更。

1. C-60 子 agent 的 worktree 从本地最新提交建立：并发时基底落后会让测量和合入都出错
2. C-103 每个 worktree 分配一个端口：并发跑服务时互不抢端口
3. C-59 常驻文字设大小预算：每个会话都付这笔 token
4. C-42 canon stats 判定评审拦截之后的去向：衡量评审准不准
5. C-54 合入后后台抽查规则、测试和代码是否一致
6. C-58 人的回答由 Claude Code 的记录佐证
7. C-34 定期审计会话注入的内容
8. C-39 合入后自动推送到远端：推送到远端要先问人
