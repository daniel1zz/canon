# 命令行（cli）

`canon` 命令行：agent 或人要做的每个动作对应一个命令，每个退出码只有一种含义。子领域 `cli/install`：canon 自带的项目级 skill 和 hook 怎样装进项目、怎样更新（D-9）。

命令不集中登记：每个子领域在自己代码目录的 `commands.ts` 里定义自己的命令和它在 `--help` 里的位置，`src/cli/main.ts` 只按领域列表组装，只有新增领域时才改（D-15）。

## 术语

- **退出码**：0 成功；1 被结果检查拒绝；2 用法错误或输入无效；3 找不到；4 环境错误；5 冲突（被另一个 worktree 认领、已经回答过、已经存在）；70 canon 自身的 bug；75 排队超时。完整定义见 BR-2022 和 D-4。
