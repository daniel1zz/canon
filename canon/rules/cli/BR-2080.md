---
id: BR-2080
title: canon init 把 canon 的 skill 装进项目的 .claude/skills
status: active
---

## 规则

`canon init` 和 `canon skills install` 把 canon 自带的每个 `canon-*` skill 复制到当前项目的 `.claude/skills/` 下，并写一份清单 `.claude/skills/.canon-skills.json`（每个文件的哈希），提示把它们和项目一起提交；只装 `canon-` 开头的 skill，不写用户主目录下的任何东西。`canon init` 对已有的 skill 副本和 `canon skills install` 一样处理（BR-2081），并且在写其他任何文件之前完成，所以 skill 冲突时 `canon init` 什么也不写。在 canon 自己的仓库里，源头就是目标，安装什么也不做。

## 例子

- 在新仓库执行 `canon init` → 出现 `.claude/skills/canon-test/SKILL.md` 等文件和清单，`~/.claude` 没有变化
- 源头里还有 `user-own` 这个 skill → 不安装
- 再执行一次 `canon skills install`，源头没变 → 输出 `skills: up to date`
- 项目里已有改过的 `.claude/skills/canon-b/SKILL.md`，执行 `canon init` → 退出码 5，仓库里没有出现 `canon/`
- 在 canon 自己的仓库里执行 `canon skills install` → 输出 `skills: up to date`，退出码 0
