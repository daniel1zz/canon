title: 帮助选项只在 -- 之前生效
status: active
---

## 规则

命令行里在 `--` 之前出现 `--help` 或 `-h` 时，canon 输出那个命令的用法（BR-2101）、退出码 0，不检查其余参数，也不运行命令；`--` 之后的每个词都是位置参数，`--help`、`-h` 也一样，命令照常检查参数（BR-2097）并运行。

## 例子

- `canon search --help` → 输出 `USAGE canon search`，退出码 0
- `canon stats --bogus --help` → 输出用法，退出码 0
- `canon search -- --help` → 不输出用法，按查询词 `--help` 搜索，退出码 0
- `canon stats -- -h` → 不输出用法；`stats` 没有位置参数，退出码 2
