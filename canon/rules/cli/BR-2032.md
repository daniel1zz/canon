## 规则

`canon init --floor <命令>` 在仓库根目录建出 `canon/product.md`（中文标题：目的、使用者、承诺、不做的事）、`canon/config.yaml`（写入 floor）和 `canon/rules`、`canon/decisions`、`canon/changes`、`canon/notes`；没给 floor 时提示必须先配置。

## 例子

- 新仓库执行 `canon init` → 建出上述文件和目录，提示 set `floor`
