## 规则

`canon init --floor <命令>` 在仓库根目录建出 `canon/product.md`、`canon/config.yaml`（写入 floor）和 `canon/rules`、`canon/decisions`、`canon/changes`、`canon/notes`；已存在的文件不覆盖并提示；没给 floor 时提示必须先配置。

## 例子

- 新仓库执行 `canon init` → 建出上述文件和目录，提示 set `floor`
- `canon/product.md` 已存在 → 内容不变，提示 exists
