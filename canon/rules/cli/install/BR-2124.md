---
id: BR-2124
title: 已有不是 canon 写的 reference-transaction hook 时，canon 不覆盖它
status: active
---

## 规则

hook 目录里已有 `reference-transaction`，而它的第二行不是 canon 的标识行（或者它是符号链接、不是普通文件）时，canon 不覆盖它：`canon init`、`canon install` 和 `canon update` 在写任何文件之前、也在其他检查（包括 BR-2081、BR-2083 和 `.claude/settings.json` 能不能改，BR-2087）之前以退出码 5 拒绝（`canon init` 在分离的 HEAD 上的拒绝比它更早，BR-2032），提示里写明这个文件的路径；`--force` 也不覆盖。`canon update --check` 把它列为过期（`not installed: that file was not written by canon`），退出码 1。

## 例子

- `.git/hooks/reference-transaction` 是用户自己的脚本 `#!/bin/sh\nexit 0` → `canon install` 退出码 5，提示里有这个路径，脚本内容不变，`.claude/skills` 没有被写
- 同样的情况 `canon install --force` → 仍是退出码 5
- 同样的情况 `canon update --check` → 退出码 1，列出 `not written by canon`
- 别人的 hook 和 BR-2083 的符号链接同时存在 → 先检查 hook，退出码 5
- 别人的 hook 存在，`.claude/settings.json` 又不是合法 JSON → `canon install` 和 `canon update` 都是退出码 5
- 文件第二行是 canon 的标识行 → 按 BR-2123 更新它
