## 规则

安装 Codex 目标时，AGENTS.md 没有 canon 管理段就追加用 `<!-- canon:begin -->` 与 `<!-- canon:end -->` 包围的短段，要求会话先运行 canon brief 并使用适用的 canon 技能。已有管理段只更新段内内容，其余文字逐字保留。重复安装不重复段落。卸载只移除这个管理段；删除后没有内容才删除文件。标记只有一边、重复、倒置，或 AGENTS.md 是符号链接时，预检退出码 2，什么也不写。管理段是 canon 维护的入口，其他文字的本地修改不算技能冲突，不被 --force 覆盖。

已有非空 AGENTS.override.md 时它是 Codex 的有效入口，管理段改写在该文件，AGENTS.md 的旧管理段移除；以后有效入口变回 AGENTS.md 时相同处理。每个文件的用户文字仍原样保留，卸载从两个文件分别移除管理段。

## 例子

- AGENTS.md 是用户的约定 → 原文保留，末尾多一个管理段
- 连续 install 两次 → 只有一个管理段；用户段内容未变
- 管理段版本旧 → 替换该段，用户后来加的正文仍保留
- 用户文件有 begin 没有 end，或 begin 出现两次 → 退出码 2，没有技能和 hooks 写入
- 卸载只由 canon 创建的 AGENTS.md → 文件删除；有用户文字 → 只留下用户文字

- 用户有非空 AGENTS.override.md → 管理段写入 override，用户的 AGENTS.md 不变；以后清空 override 并安装 → 管理段迁回 AGENTS.md
