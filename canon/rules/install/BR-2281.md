## 规则

本地清理（BR-2280）不删 `refs/canon/archive/*` 和 `refs/canon/snapshots/*`：还有时打印两类各自的数量和找回方法（`git for-each-ref refs/canon/archive` 列出、`git checkout -b <分支> <ref>` 取回），并说明它们以后不会再被自动清理。加 `--purge-recovery` 时把它们一起删掉，并打印删掉的数量。

## 例子

- 有 2 个存档、30 个快照，不加参数 → 两类 ref 都还在，输出里有 `2` 和 `30` 以及找回方法
- 同样的情况加 `--purge-recovery` → `git for-each-ref refs/canon` 为空，输出删掉了 32 个
- 没有存档也没有快照 → 不打印找回说明
