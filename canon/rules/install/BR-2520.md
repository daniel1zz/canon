## 规则

本条只适用于按 BR-2459 选中的 Claude 目标；Codex 目标的同一个 hook 见 BR-2459。

`canon init`、`canon install`、`canon update` 在合并会话 hook（BR-2087）的同一次写入里，确保项目的 `.claude/settings.json` 的 `hooks.Stop` 里有一个条目，命令是 `canon goal check --hook || echo '{"systemMessage":"canon goal check failed or canon is not on PATH: the goal was not checked"}'`（它做什么见 BR-2519，D-132）；已经有就不动，`hooks.Stop` 里别的条目和文件里别的设置原样保留。缺这一项时，`canon update --check` 把它列为过期：`hook: canon goal check --hook when a session stops (.claude/settings.json)`，退出码 1。`canon uninstall` 和 canon 的其他条目一起删掉它（BR-2278）。canon 出错或不在 PATH 上时，`echo` 让这一行以 0 结束，输出一个放行的 JSON，会话照常停下。

## 例子

- 新项目 `canon init` → `hooks.Stop` 里有命令是 `canon goal check --hook || echo ...` 的条目
- 已有别的 Stop 条目 → `canon install` 保留它，另加这一条
- 删掉这一条后 `canon update --check` → 退出码 1，列出 `hook: canon goal check --hook when a session stops (.claude/settings.json)`；`canon install` 后退出码 0
- PATH 上没有 canon 时执行这条命令 → 输出 `{"systemMessage":...}`，退出码 0
- `canon uninstall` 的变更里 → 这一条被删掉
