## 规则

`canon update --check` 比较项目里 canon 装的文件和当前 canon 带的版本，每次都当场重新计算，不用缓存：项目里改过、canon 没有新版本的文件不算过期（BR-2089）。全部一致时输出 `up to date` 和版本号，退出码 0；否则逐行列出过期的项（缺少、内容不同或 canon 已经删掉的 skill 文件，缺少的或旧形式的会话 hook，BR-2087；缺少的 Bash 快照 hook，BR-2185；缺少的检查 `--as` 的 hook，BR-2343；缺少或不是 `"head"` 的 `worktree.baseRef`，BR-2264；缺少的提问工具记录 hook，BR-2274；缺少的编辑后复述提示 hook，BR-2404；canon 撤回、但还留在文件里的 PreToolUse hook 和放行规则，BR-2130；缺少、旧的、不可执行或不是 canon 写的 git 守卫，BR-2123、BR-2124；`info/exclude` 里缺少 `/.claude/worktrees/` 一行，列为 `git exclude: /.claude/worktrees/ …`，BR-2305；项目里没有 `canon/architecture.md`，列为 `file canon/architecture.md: missing …`，已经有这个文件的不算过期，不管里面写什么；main 已有提交而 `canon/config.yaml` 没有 `links_since`，列为 `config canon/config.yaml: links_since missing …`，BR-2452），项目里改过的 skill 文件标出 `(edited in this project)`，退出码 1。装的东西读不了、判断不了是否过期时不算过期，以退出码 2 拒绝（`.claude/settings.json` 不是合法 JSON 或其中的 `worktree` 不是对象，BR-2087、BR-2264；清单文件不是合法 JSON，BR-2195）。它只读，不改任何文件，也不打开协调数据库（所以不会新建它）。版本号由 canon 带的全部 skill 文件的内容算出，内容变了版本就变。

## 例子

- 刚 `canon init` 完 → 退出码 0，`up to date`；`.git/canon/` 没有出现
- canon 更新了 `canon-a/SKILL.md` → 退出码 1，列出 `skill canon-a/SKILL.md`，项目里的文件不变
- 项目里改过 `canon-b/SKILL.md`，canon 也更新了它 → 这一行带 `(edited in this project)`
- `.claude/settings.json` 里没有运行 `canon brief` 的 hook → 列出 `hook: canon brief at session start`
- `.claude/settings.json` 里的 hook 是旧的 `canon brief` → 列出 `hook: canon brief at session start, older form`
- `.claude/settings.json` 里没有 `worktree.baseRef: "head"` → 列出 `setting: worktree.baseRef "head"`
- `.claude/settings.json` 里没有 `canon work check-as --hook` 的 PreToolUse 条目 → 列出 `hook: canon work check-as before each Bash call`
- `.claude/settings.json` 里没有记录提问工具回答的 PostToolUse hook → 列出 `hook: canon human record after each answer to the question tool`
- `.claude/settings.json` 里没有编辑后的复述提示 hook → 列出 `hook: canon restatements --hook after each Write or Edit (.claude/settings.json)`
- 项目里没有 `canon/architecture.md` → 退出码 1，列出 `file canon/architecture.md: missing`
- 项目里有 `canon/architecture.md`，内容是别的 → 不列出
- `.claude/settings.json` 里 `"worktree": "head"`（不是对象）→ 退出码 2，不列过期项
