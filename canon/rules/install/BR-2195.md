status: active

## 规则

`.claude/skills/.canon-skills.json` 存在但不是合法 JSON 时，`canon init`、`canon install`、`canon update` 和 `canon update --check` 以退出码 2 拒绝，提示 `.claude/skills/.canon-skills.json is not valid JSON; fix or delete it`，什么也不写（`canon init` 也不建 `canon/`，`canon update` 不开变更）；`canon brief` 和 `canon work start` 的提示行改为 `cannot check for updates` 加这个原因（BR-2085）。

## 例子

- 清单内容是 `{ broken` → `canon install` 退出码 2，提示里有 `is not valid JSON`，skill 文件和清单都不变
- 同样的清单 → `canon update --check` 退出码 2；`canon brief` 输出 `canon project files: cannot check for updates (...is not valid JSON...)`
- 清单是合法 JSON → 照常按 BR-2081 安装
