title: 项目里改过、canon 没有新版本的 skill 文件保留原样，不算过期
status: active
business: 更新
---

## 规则

项目里的 skill 文件和 canon 带的版本不同，但 canon 带的版本仍是上次装进来时清单记下的那一版（canon 没有更新它，是项目自己改了），这个文件就算项目自己的改动：`canon update --check`、`canon brief` 不把它算作过期，`canon install` 和 `canon update` 保留它不动，并在安装输出里列出 `kept skill <文件>`；只有加 `--force` 才换回 canon 的版本。canon 之后更新了这个文件时，按 BR-2081 处理。

## 例子

- 项目改了 `canon-b/SKILL.md`，canon 没改它 → `canon update --check` 退出码 0，`canon brief` 没有过期提示
- 同时 canon 更新了 `canon-a/SKILL.md`，执行 `canon update` → 合入后 `canon-a` 是新版本，`canon-b` 仍是项目改过的内容
- 执行 `canon install --force` → `canon-b/SKILL.md` 换回 canon 的版本
- 项目改了 `canon-b/SKILL.md`，canon 也更新了它 → 不适用本条，按 BR-2081 以退出码 5 拒绝
