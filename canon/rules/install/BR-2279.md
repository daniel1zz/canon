---
id: BR-2279
title: canon uninstall 不删项目里改过的 skill 文件，除非加 --force
status: active
---

## 规则

清单里记着、但项目里改过（内容和清单记的哈希不同）的 canon skill 文件，`canon uninstall` 不删：在开变更之前以退出码 5 拒绝并列出这些文件，什么都不改；加 `--force` 才连它们一起删。清单里没记的文件（项目自己加在 `canon-*` 目录里的）不删，目录因此不为空时保留目录。清单不是合法 JSON 时以退出码 2 拒绝（BR-2195）。

## 例子

- `.claude/skills/canon-test/SKILL.md` 在项目里改过 → `canon uninstall` 退出码 5，列出这个文件，没有开变更
- 同样的情况加 `--force` → 这个文件也被删掉
- `.claude/skills/canon-test/mine.md` 是项目自己加的 → 卸载后它和 `canon-test/` 目录都还在
