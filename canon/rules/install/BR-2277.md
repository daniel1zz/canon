## 规则

`canon uninstall` 在做任何改动之前检查进行中的工作：活着的认领、`worktrees` 目录下有未提交改动或有不在 main 上的提交的 worktree、有不在 main 上的提交的 `change/*` 分支。有任何一项就以退出码 5 拒绝，每项一行列出（变更编号和原因），并提示先合入或用 `canon work drop` 存档后再运行；什么都不改。已经合入、干净的 worktree 和已合入的分支不算。

## 例子

- 别的会话认领着 C-12，它的 worktree 里有未提交的文件 → 退出码 5，列出 `C-12`，`.claude/skills`、`.claude/settings.json`、git 守卫都没变，没有开新变更
- C-7 的 worktree 干净，分支已经合入 main，没有认领 → 不算进行中，照常卸载
- 没有 worktree，但 `change/C-9` 分支比 main 多一个提交 → 退出码 5，列出 `C-9`
