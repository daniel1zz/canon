title: 安装 skill 时不覆盖项目里改过的文件

## 规则

`canon install` 只覆盖或删除仍和清单里记录的哈希一致的文件（也就是 canon 上次写下、之后没人改过的文件）。任何一个文件在项目里被改过、又会被覆盖或删除时，整次安装都不做，以退出码 5 拒绝并列出这些文件；加 `--force` 才覆盖。源头里删掉的文件，在项目里没被改过就一并删除。项目里改过、canon 却没有更新的文件不会被覆盖，见 BR-2089。

## 例子

- canon 更新了 `canon-a/SKILL.md`，项目里的副本没改过 → 更新它
- canon 删掉了 `canon-a/references/x.md`，项目里的副本没改过 → 删除它
- 项目里改过 `canon-b/SKILL.md`，canon 也更新了它 → 退出码 5，列出这个文件，其他文件也都不更新
- 同样的情况加 `--force` → 覆盖
