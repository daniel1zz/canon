## 规则

`canon init`、`canon install`、`canon update` 在合并会话 hook（BR-2087）的同一次写入里，确保项目的 `.claude/settings.json` 的 `hooks.PostToolUse` 里有一个 `matcher` 为 `AskUserQuestion` 的条目，命令是 `canon human record || echo '{"systemMessage":"canon human record failed or canon is not on PATH: this answer was not recorded for canon"}'`（记录的内容见 BR-2275）；已经有就不动，`hooks.PostToolUse` 里别的条目和文件里别的设置原样保留。只写项目的 `.claude/settings.json`，不碰用户目录下的设置。缺这一项时，`canon update --check` 把它列为过期：`hook: canon human record after each answer to the question tool (.claude/settings.json)`，退出码 1。这个 hook 只记录，不拦截：canon 出错或不在 PATH 上时，`echo` 让这一行以 0 结束，并给用户一条提示。

## 例子

- 新项目 `canon init` → `.claude/settings.json` 的 `hooks.PostToolUse` 里有 `matcher` 为 `AskUserQuestion`、命令是 `canon human record || echo ...` 的条目
- 已有别的 PostToolUse 条目（`matcher` 为 `Write`）→ `canon install` 保留它，另加这一条
- 已经装过 → `canon install` 不改文件；`canon update --check` 不列它
- 删掉这一条后 `canon update --check` → 退出码 1，列出 `hook: canon human record after each answer to the question tool (.claude/settings.json)`；`canon install` 后退出码 0
- PATH 上没有 canon 时执行这条命令 → 输出 `{"systemMessage":...}`，退出码 0
