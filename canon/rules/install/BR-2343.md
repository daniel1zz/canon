## 规则

本条只适用于按 BR-2459 选中的 Claude 目标。

`canon init`、`canon install`、`canon update` 在合并会话 hook（BR-2087）的同一次写入里，确保 `.claude/settings.json` 的 `hooks.PreToolUse` 里有一个单独的、`matcher` 为 `Bash` 的条目，命令是 `canon work check-as --hook || echo '{"systemMessage":"canon work check-as failed or canon is not on PATH: --as was not checked for this Bash call"}'`（BR-2340）；已经有就不动，别的条目（包括快照条目，BR-2185）和其余设置原样保留。缺这一项时，`canon update --check` 把它列为过期：`hook: canon work check-as before each Bash call (.claude/settings.json)`，退出码 1。`canon uninstall` 把这个条目和 canon 别的条目一起删掉（BR-2278）。这个条目的命令不以撤回的 `canon hook pre-bash`（BR-2130）开头，不会被当作撤回的 hook 删掉。canon 出错或不在 PATH 上时，`echo` 让这一行以 0 结束并给用户一条提示，这次调用照样放行；只有检查成功并判定 `--as` 不符才拒绝（BR-2340）。

## 例子

- 新项目 `canon init` → PreToolUse（`Bash`）里有快照条目和 check-as 条目
- 只有快照条目的旧项目 `canon install` → 加上 check-as 条目，快照条目不变；再 `canon install` 不改文件
- 删掉 check-as 条目后 `canon update --check` → 列出 `hook: canon work check-as before each Bash call`，退出码 1
- 已有别的 `Bash` PreToolUse 条目 → 保留它，另加 check-as 条目
- `canon install` 时文件里有撤回的 `canon hook pre-bash` 条目 → 它被删，check-as 条目留下
- PATH 上没有 canon 时执行这条命令 → 输出 `{"systemMessage":...}`，退出码 0
