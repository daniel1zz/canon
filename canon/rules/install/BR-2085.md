## 规则

`canon brief` 和 `canon work start` 每次都按 BR-2084 检查；有过期的项时各输出一行提示：过期了几项、当前版本，要 agent 告诉用户，用户要更新时运行 `canon update`。不过期时不输出这一行。提示只是告知，不会自动更新任何东西；找不到 canon 自带的 skill 时，这一行改为说明无法检查及原因。

## 例子

- 项目里没有 `canon/architecture.md`，新会话开始时 `canon brief` → 输出同一行，写 1 项过期；`canon update` 补上文件后这一行没有了

- canon 更新了一个 skill，新会话开始时 `canon brief` → 输出一行 `canon's project files are out of date (1 item(s), version …): tell the user; when they want it, run canon update`
- 同样的情况执行 `canon work start --title X` → 也输出这一行，开始照常完成
- 项目已经是最新 → 没有这一行
