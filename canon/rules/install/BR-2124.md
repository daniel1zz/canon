## 规则

hook 目录里已有 `reference-transaction`，而它的第二行不是 canon 的标识行（或者它是符号链接、不是普通文件）时，canon 不覆盖它：`canon init`、`canon install` 和 `canon update` 在写任何文件之前、也在其他检查（包括 BR-2081、BR-2083 和 `.claude/settings.json` 能不能改，BR-2087）之前以退出码 5 拒绝（比它更早的只有两个：`canon init` 在分离的 HEAD 上的拒绝，BR-2032；`canon/config.yaml` 里 main 不是 git 接受的分支名，退出码 2，BR-2123），提示里写明这个文件的路径；`--force` 也不覆盖。`canon update --check` 把它列为过期（`not installed: that file was not written by canon`），退出码 1。

判断和写入之间别人写进来的 hook 也不覆盖：hook 缺少时，canon 的守卫以排他的方式放上去，路径上已经有文件就不放；hook 是 canon 的旧版本时，canon 先把它挪到同目录下的旁边，核对挪走的仍是 canon 写的，才放上新的。这时路径上的文件不是 canon 写的，canon 把它留在（或放回）原处，退出码 5，提示里写明路径；放回时路径上又有了文件，挪走的那份留在同目录下，提示里写明它的路径。旧版本挪走之后，路径上出现的是另一个 canon 刚放上的当前守卫时，算已经装好，退出码 0，挪走的旧版本删掉。canon 什么时候都不删除、不替换不是它写的文件，判断路径空着之后再改名放上去也不行。hook 目录不支持硬链接时，canon 在动旧版本之前就发现（先在同目录下试建一个硬链接再删掉），以退出码 4 停下，写明原因，旧版本原样留在原处。试建成功之后，放新守卫的排他放置仍以路径被占以外的原因失败时（比如磁盘读写错误），也以退出码 4 停下；这时挪走的旧版本也只用同样的排他方式放回原处，按放回的结果分三种：放回了，就删掉挪走的那份；路径上又有了文件，就只删掉挪走的那份，不动路径上的文件；放回也失败，就把旧版本留在挪走的位置，提示里写明它的路径。三种都是退出码 4。

## 例子

- `.git/hooks/reference-transaction` 是用户自己的脚本 `#!/bin/sh\nexit 0` → `canon install` 退出码 5，提示里有这个路径，脚本内容不变，`.claude/skills` 没有被写
- 同样的情况 `canon install --force` → 仍是退出码 5
- 同样的情况 `canon update --check` → 退出码 1，列出 `not written by canon`
- 别人的 hook 和 BR-2083 的符号链接同时存在 → 先检查 hook，退出码 5
- 别人的 hook 存在，`.claude/settings.json` 又不是合法 JSON → `canon install` 和 `canon update` 都是退出码 5
- 文件第二行是 canon 的标识行 → 按 BR-2123 更新它
- 别人的 hook 存在，`canon/config.yaml` 里 `main: "a..b"` → `canon install`、`canon update` 和 `canon update --check` 都是退出码 2，提示分支名不合法，hook 内容不变
- hook 缺少，`canon install` 判断之后、写入之前别的工具写进了 `#!/bin/sh\nexit 0` → 退出码 5，提示里有这个路径，文件内容仍是 `#!/bin/sh\nexit 0`，hook 目录里不留 canon 的临时文件
- hook 是 canon 的旧版本，判断之后、写入之前被换成别人的脚本 → 退出码 5，别人的脚本原样留在原处
- hook 缺少，判断之后、写入之前另一个 canon 已经写好了当前的守卫 → 退出码 0，文件是当前的守卫
- hook 缺少、判断和写入之间没有别人写 → 照常装好，退出码 0（BR-2123）
- hook 是 canon 的旧版本，判断之后被换成别人的脚本 A，canon 挪走 A、要放回时路径上又有了别人的脚本 B → 退出码 5，B 不变，A 留在同目录下，提示里写明 A 的路径
- hook 是 canon 的旧版本，canon 挪走它之后别的工具在空着的路径上写了自己的脚本 → 退出码 5，别人的脚本不变，挪走的旧版本被删掉
- hook 目录不支持硬链接、hook 缺少 → `canon install` 退出码 4，提示里写明要能建硬链接，hook 目录里不留 canon 的临时文件
- hook 目录不支持硬链接、hook 是 canon 的旧版本 → 退出码 4，提示里写明要能建硬链接，路径上仍是原来的旧版本，hook 目录里不留 canon 的文件
- 试建硬链接成功，之后放新守卫和放回旧版本都因磁盘读写错误失败 → 退出码 4，路径空着，canon 的旧版本留在同目录下，提示里写明它的路径
- hook 是 canon 的旧版本，放新守卫因磁盘读写错误失败、放回能做 → 退出码 4，路径上是原来的旧版本，hook 目录里不留 canon 的文件
- hook 是 canon 的旧版本，放新守卫因磁盘读写错误失败的那一刻别的工具在空着的路径上写了自己的脚本 → 退出码 4，别人的脚本不变，挪走的旧版本被删掉
- hook 是 canon 的旧版本，挪走之后另一个 canon 在路径上放好了当前的守卫 → 退出码 0，文件是当前的守卫，挪走的旧版本被删掉
