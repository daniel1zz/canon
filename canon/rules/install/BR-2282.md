## 规则

加 `--remove-knowledge` 时，`canon uninstall` 在本地清理（BR-2280）之后，在主检出里把 `canon/` 整个从 main 删掉并另提交一次（提交信息 `Remove canon/ (canon uninstall --remove-knowledge)`），配了 `remote` 时推到远端；这次提交不经过 floor 和规则评审，因为 canon 已经不在这个项目里了。主检出不在 main 上、或 `canon/` 下有未提交的改动时，在本地清理之后以退出码 5 拒绝这一步并说明原因，`canon/` 不动。不加时 `canon/` 下的文档保留。main 上已经没有 `canon/` 时这一步什么都不做。

## 例子

- 卸载时加 `--remove-knowledge`，主检出在 main 上且干净 → main 上没有 `canon/`，最新提交是 `Remove canon/ (canon uninstall --remove-knowledge)`
- 主检出在别的分支上 → 退出码 5，`canon/` 还在 main 上，本地清理已经做完
- 不加 → `canon/rules` 等文档留在 main 上
