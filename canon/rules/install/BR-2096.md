## 规则

canon 装进其他项目的文字（`.claude/skills/canon-*` 下的文件、`canon brief` 输出的工作说明）在反引号和代码块之外不写 canon 自己的文档编号，因为这些编号在其他项目里不存在，会成为悬空引用，或者被误当成那个项目自己的文档。写在反引号或代码块里的编号是举例，不受限制。

## 例子

- skill 里写“一条规则一个触发条件和一个结果（D-5）” → 测试失败，指出文件和编号
- skill 里写 `bun test -t "BR-2022"`（在反引号里） → 允许
- 工作说明里写 `it("BR-n: ...")` → 允许（不是具体编号）
