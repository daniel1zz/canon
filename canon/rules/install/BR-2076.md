id: BR-2076
title: canon init 不覆盖已存在的文件
status: active
business: 初始化
---

## 规则

`canon init` 遇到 `canon/` 下已经存在的文件时不覆盖（`.claude/skills` 下的 skill 副本按 BR-2081 处理），原样保留，并为它输出一行 `exists <路径>`；这不算失败，退出码 0（BR-2022 的 5 只用于新建单个文档或领域）。

## 例子

- `canon/product.md` 已存在 → 内容不变，输出 `exists canon/product.md`，退出码 0
