## 规则

`canon update` 的杂务（BR-2086）标题是 `更新 canon 装进项目的文件到版本 <版本>`。提交标题为 `Update canon project files to <版本> (<杂务身份>)`；提交正文的每个过期项独占一行 `- <项>`，与此次 `canon update --check` 会列出的项一致。不写 Change 文档。版本号的来源见 BR-2084。

## 例子

- 只有 canon-a/SKILL.md 过期 → 提交标题含目标版本和杂务身份，正文只有 `- skill canon-a/SKILL.md`
- 同时缺少会话 hook → 正文另有 `- hook: canon brief at session start (.claude/settings.json)`
- settings 是空对象 → 正文列出缺少的五个 hook 和 worktree.baseRef 设置，与检查输出一致
- 更新已是最新 → 无新提交，见 BR-2086
