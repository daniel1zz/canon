id: BR-2082
title: 找不到 canon 自带的 skill 时以环境错误失败
status: active
---

## 规则

canon 自带 skill 的源头：设置了 `CANON_SKILLS_SOURCE` 时只用它；否则是运行这个 canon 的仓库里的 `.claude/skills`（用 `bun` 跑源码时是源码所在的仓库，跑编译好的 `dist/canon` 时先用和它同在 `dist/` 下发布的 `dist/skills`（BR-2412），里面没有 `canon-*` 时才用它所在的仓库，跑 npm 包里打包好的 `dist/canon.js` 时是这个包）。找不到含 `canon-*` 的源头时，`canon init`、`canon install` 和 `canon update` 以退出码 4 失败，并且 `canon init` 在写任何文件之前就失败。

## 例子

- `CANON_SKILLS_SOURCE` 指向一个空目录，执行 `canon init` → 退出码 4，提示找不到，仓库里没有出现 `canon/`
- 从 canon 仓库编译出的 `dist/canon` 执行 `canon install` → 从 canon 仓库的 `.claude/skills` 安装
- 同一个 `dist/canon` 旁边有发布的 `dist/skills` → 从 `dist/skills` 安装，不用仓库 `.claude/skills` 里更新的文字
- 从 npm 包里的 `dist/canon.js` 执行 `canon install`，没设 `CANON_SKILLS_SOURCE` → 从这个包里的 `.claude/skills` 安装
