## 规则

目标的选择与路径映射按 BR-2459；下文的 .claude 路径和 Claude 专用设置仅用于 Claude 目标，Codex 的原生入口和管理段按 BR-2459、BR-2460。

安装 skill 只在选定目标的 `canon-*` 目录里写和删（目标根路径按 BR-2459），而且只写普通文件：清单里出现不在 `canon-*` 下的路径（绝对路径、含 `..`、不是 `canon-` 开头），或者要写、要删的路径上有任何一级是符号链接（包括 `.claude`、`.claude/skills` 本身），都以退出码 2 拒绝，什么也不写、不删；`--force` 也不例外。

## 例子

- 清单里有一项 `../../../victim.txt`，哈希和那个文件一致 → 退出码 2，项目外的 `victim.txt` 不变
- 项目里提交了链接 `.claude/skills/canon-a` → 指向项目外的目录，执行 `canon install --force` → 退出码 2，那个目录里的文件不变
- 正常的 `.claude/skills/canon-a/SKILL.md` → 照常安装
- 项目里提交了链接 `.claude/skills/canon-a`，同时 `canon-b/SKILL.md` 改过、canon 也更新了它 → 退出码 2（先检查链接），什么也不写

- Codex 目标的 .agents/skills/canon-a 是链接，或其清单含 ../victim → 退出码 2，目标外文件不变
