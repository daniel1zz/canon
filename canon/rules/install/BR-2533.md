## 规则

本条只适用于按 BR-2459 选中的 Claude 目标；Codex 目标的同一记录见 BR-2459。

`canon init`、`canon install`、`canon update` 在合并会话 hook（BR-2087）的同一次写入里，确保项目的 `.claude/settings.json` 的 `hooks.SessionStart` 和 `hooks.PostModelSwitch` 里各有一个条目，命令是 `canon work model --hook || echo '{"systemMessage":"canon work model failed or canon is not on PATH: the model of this session was not recorded"}'`（它做什么见 BR-2531）；已经有就不动，这两个事件里别的条目（包括 SessionStart 的 `canon brief`）和文件里别的设置原样保留。缺其中一个时，`canon update --check` 把缺的列为过期：`hook: canon work model --hook at session start (.claude/settings.json)` 或 `hook: canon work model --hook when the model changes (.claude/settings.json)`，退出码 1。`canon uninstall` 和 canon 的其他条目一起删掉它们（BR-2278）。canon 出错或不在 PATH 上时，`echo` 让这一行以 0 结束，会话照常开始或切换。

## 例子

- 新项目 `canon init` → `hooks.SessionStart` 有 `canon brief` 和 `canon work model --hook` 两个条目，`hooks.PostModelSwitch` 有 `canon work model --hook`
- 已有 PostModelSwitch 的用户条目 → `canon install` 保留它，另加这一条
- 删掉 PostModelSwitch 的这一条后 `canon update --check` → 退出码 1，列出 `hook: canon work model --hook when the model changes (.claude/settings.json)`；`canon install` 后退出码 0
- `canon uninstall` 的变更里 → 这两条都被删掉
