## 规则

`canon init`、`install`、`update` 接受 `--agent claude|codex|all`；新仓库不传时默认 claude，已有 canon 目标不传时沿用它们，显式目标增加到已有目标。不是上述值时退出码 2，什么也不写。目标由 canon 写过的技能清单、准确匹配的 hook 或 BR-2460 的管理标记识别，不凭用户目录存在推断。Claude 的目标位置不变；Codex 的技能副本与清单放在 `.agents/skills`，hook 合并进 `.codex/hooks.json`，项目指令按 BR-2460 处理，技能来源不变。各目标均适用 BR-2081、BR-2083、BR-2089、BR-2195；先对所有目标完成预检，任何一个目标被拒时没有任何目标被写入。

Codex 的 SessionStart 和 SubagentStart 调用 `canon brief --hook --runtime codex`（BR-2023）；Bash 的 PreToolUse 入口绑定 BR-2182、BR-2340，request_user_input 的 PostToolUse 绑定 BR-2275，apply_patch 的 PostToolUse 绑定 BR-2402。命令带 `--runtime codex` 指明输入协议。既有用户 hook 原样保留，不重复添加，不写 Claude 专用 worktree 设置。安装后提示用户在 Codex 里 trust hooks。不改用户配置中的信任、权限或 reviewer；只有新建、仅选 codex 的项目初始 review 值是 `codex exec --ephemeral --sandbox read-only -`；选 all 时仍用 Claude 的初始值，已有配置不变。trust 提示至少包含 `trust` 和 `Codex /hooks`。

BR-2084 的状态检查、BR-2086 的更新和 BR-2278 的卸载均覆盖已安装的目标；更新提交含所有改动资产，卸载只删 canon 管理的文件和 hook。Codex 配置不是合法 JSON 对象、hooks 事件形状不合法或路径是符号链接时退出码 2；用户文件的保留与 --force 按既有规则。只选 Codex 时不创建 .claude，也不安装 Claude 专用的 info/exclude 条目。canon 自己的仓库按 BR-2080 不复制技能源。其 `.agents/skills` 链接由源码维护者随仓库提交，安装器不创建、改写或删除这个入口；它不在 BR-2083 本次要写删的路径中。

Codex 的技能缺少、更新或撤回时，过期项用 `skill .agents/skills/<相对技能路径>` 标识；合并配置缺少条目或启动命令需升级时用 `hook:` 行，点名事件、命令及 `.codex/hooks.json`；有效根指令的管理段需增删改时用 `file <文件名>: canon instruction block missing or outdated`。其中任一项需写入就不是 current；清单、配置和指令读不了时按各自错误退出，不把错误当成 current。

## 例子

- 新仓库 init --agent codex → .agents/skills 有技能和清单，.codex/hooks.json 有 canon hook，AGENTS.md 有管理段，.claude 不出现；再次安装不重复
- 新仓库 init 不带目标 → 仍写 Claude 入口；已有 Codex 项目 install 不带目标 → 不新增 Claude
- Claude 项目 install --agent codex → 原有 Claude 入口不变，Codex 入口增加；update --check 检查两端
- 用户自己已有 .codex/hooks.json 的 echo hi，没装 Codex canon → 普通 install 不碰它；显式选 codex 后保留 echo hi 并合并 canon hook
- all 的 Codex 配置损坏或技能有冲突 → 退出码 2 或 5，Claude 技能和 canon/ 也不写
- --agent typo → 退出码 2，没有安装文件
- Codex 端源技能更新 → update 把 .agents、.codex、AGENTS.md 的改动与其他目标一起合入；卸载后用户自己的 hook 和技能仍在

- 新建仅选 codex → review 精确为 `codex exec --ephemeral --sandbox read-only -`；选 all → Claude 默认 reviewer；已有自定义 review → 不变
- canon 自己仓库已有链接 .agents/skills 指向其技能源 → install 不写此链接和技能文件；其他仓库把 .agents/skills 链向技能源 → 退出码 2
- Codex 少一个身份检查条目 → update --check 退出码 1，hook 行包含 PreToolUse、canon work check-as 和 .codex/hooks.json
