# knowledge/links

规则和决策的正文点名别的规则或决策时，被点名的文档的行为改了，点名它的文档可能已经和它对不上。这里让这种引用在写的时候就被看到：canon 从正文找出引用，被引文档的行为变了就标为可疑，引用方的作者复核后记下；`canon links` 列出和复核，`canon context`、`canon brief` 提示。可疑引用不拦合入，验收才要求清完（D-89）。复核记在哪、没记的怎么算见 D-95。

## 术语

- **引用**：一条没作废的规则或一个没被取代的决策（引用方）的正文在反引号和代码块外点名另一条规则或另一个决策（被引方），定义见 BR-2423。
- **指纹**：被引方的行为摘要：规则是行为哈希，决策是 `## 决定` 段的哈希（BR-2423）。
- **可疑引用**：被引方现在的指纹和这条引用的基准不同，或者引用在起点之后才写、还没有记录（BR-2423、BR-2424）。
- **复核记录**：引用方 front matter 的 `links`，由 `canon links confirm` 写（BR-2425），合入带 `--finish` 时也给变更新加的引用写（BR-2440）；有记录就只看记录。
- **起点提交**：`canon/config.yaml` 的 `links_since`；没有记录的引用和被引方在这个提交里的版本比较，它之前的都算复核过（BR-2424）。
