## 规则

`canon links list` 列出整个项目现在全部可疑的引用（BR-2423），按引用方编号再按被引方编号排序（编号按前缀和数字），每条一行：`<引用方> -> <被引方>: <被引方> changed since <基准>`，基准是 BR-2424 找到的提交的 7 位短编号；最后一行是 `<n> suspect reference(s) in <m> document(s); re-read the named document, fix the referring one if needed, then: canon links confirm <referring> <named>`，没有时是 `no suspect references`。`--json` 只输出数组，每项 `{ "from", "to", "since" }`，`since` 是完整的提交编号。退出码总是 0。

读 git 历史失败（不是 git 仓库、git 出错）时退出码 4；仓库还没有提交不算失败（BR-2424）。

## 例子

- `BR-1` 到 `BR-2` 可疑（基准提交 `1a2b3c4…`），`D-1` 到 `BR-2` 也可疑 → 两行 `BR-1 -> BR-2: BR-2 changed since 1a2b3c4` 和 `D-1 -> BR-2: …`，最后一行 `2 suspect reference(s) in 2 document(s); …`，退出码 0
- `BR-10` 和 `BR-9` 都有可疑引用 → `BR-9` 那行在前
- 没有可疑引用 → 输出 `no suspect references`，退出码 0；`--json` 输出 `[]`
- 有可疑引用时 → 退出码仍是 0
