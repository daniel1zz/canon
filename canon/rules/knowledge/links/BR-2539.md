## 规则

一次合入后的评审（BR-2441）完成（记录变成 `done`）时，canon 比较这次合入前后的语料：对每条指纹变了或新建的规则和决策 S，合入后每份点名 S 的生效规则或决策 R，记一条 `link.reviewed` 事件（R、S、S 的新指纹、合入后的提交），因为这次评审的范围包含点名改动文档的文档（BR-2009），R 和新的 S 已经被对照过（D-137）。已有同样三项的记录时不重复记。

判定可疑（BR-2424、BR-2425）时，R 指向 S 的引用如果有一条 `link.reviewed` 的指纹等于 S 现在的指纹，就不算可疑，`canon links list`、`canon brief`、`canon context` 和验收（BR-2537）都按这个判定。S 之后又改了，指纹不同，引用重新算可疑，直到下一次评审或 `canon links confirm`。

这条规则开始生效后的第一次评审完成时，canon 还按以前已完成的评审记录补记一次（只做一次，记一条 `link.reviewed.backfill` 事件）：那些评审给的是改动规则所在的整个顶层领域，所以补记只算和 S 在同一个顶层领域里的规则 R，决策和别的领域的引用不补记。评审失败或没完成的合入不记。

## 例子

- 合入改了 `BR-8`，评审完成，`BR-7` 点名 `BR-8` → 记 `link.reviewed`（`BR-7`、`BR-8`、`BR-8` 的新指纹），`canon links list` 不再把 `BR-7 -> BR-8` 列为可疑
- 之后又一次合入改了 `BR-8`，评审还在排队 → `BR-7 -> BR-8` 重新可疑；那次评审完成后又不可疑
- 合入后的评审失败 → 不记，引用仍然可疑
- 补记时，`D-5` 点名 work 领域的 `BR-8` → 不补记，仍然可疑；work 领域的 `BR-7` 点名 `BR-8` → 补记
- 已经补记过一次 → 之后的评审完成时不再补记
