## 规则

`canon brief` 说出可疑引用（BR-2423）：在认领了变更的 worktree 里，对这个变更的正文和 `rules` 点名的每份规则或决策，列出它作为引用方或被引方的每条可疑引用，每条一行 `Suspect reference: <引用方> -> <被引方> (<原因>; canon links confirm <引用方> <被引方>)`，原因和 `canon links list` 的写法相同（BR-2427）；在别的地方，有可疑引用时说一行 `<n> suspect reference(s): canon links list`。没有就什么都不说。认领了变更的 worktree 里这几行和 BR-2147 的评审建议一样，属于 BR-2024 说的“这个变更自己的东西”：只涉及这个变更点名的文档。起点提交读不出来（BR-2424）时说一行 `canon links: <错误>`，`canon brief` 其余部分照常。

## 例子

- 认领了 `C-1`，它的 `rules` 有 `BR-2`，`BR-1` 到 `BR-2` 按起点提交可疑 → 一行 `Suspect reference: BR-1 -> BR-2 (BR-2 changed since <起点短编号>; canon links confirm BR-1 BR-2)`
- 同上，但 `BR-3` 到 `BR-4` 也可疑，`C-1` 不点名它们 → 只列 `BR-1 -> BR-2`
- 主 checkout 里，项目有 3 条可疑引用 → 一行 `3 suspect reference(s): canon links list`
- 没有可疑引用 → 没有这一行
- 没设 `links_since` → 一行 `canon links: canon/config.yaml has no links_since …`，退出码仍是 0
