title: canon context 列出规则或决策的双向引用并标出可疑的
status: active
---

## 规则

`canon context <规则或决策的编号>` 在输出里加一节 `# References`，列出这份文档的双向引用（BR-2423）：`Names:` 下是它点名的规则和决策，`Named by:` 下是点名它的没作废的规则和没被取代的决策，各按编号排序，每项一行 `- <编号> <标题>`；可疑的那项后面加 ` [suspect: <原因>; canon links confirm <引用方> <被引方>]`，原因和 `canon links list` 的写法相同（BR-2427）。哪一边都没有时写 `(none)`。这份文档本身不是引用方（作废的规则、被取代的决策）时，`Names:` 下写 `(not tracked: <编号> is <状态>)`。目标是路径、领域或变更时没有这一节。

起点提交读不出来（BR-2424：没设 `links_since`、不可达、git 出错）时，`canon context` 照常输出其余部分，这一节写 `canon links: <错误>`，退出码 4。

## 例子

- `BR-1` 点名 `BR-2`（可疑）和 `D-1`，`BR-3` 点名 `BR-1` → `canon context BR-1` 有 `# References`，`Names:` 下 `- BR-2 … [suspect: BR-2 changed since …; canon links confirm BR-1 BR-2]` 和 `- D-1 …`，`Named by:` 下 `- BR-3 …`
- `canon context BR-2`（同上）→ `Named by:` 下 `- BR-1 … [suspect: BR-2 changed since …; canon links confirm BR-1 BR-2]`
- 只有变更 `C-1` 点名 `BR-1` → `Named by:` 下是 `(none)`
- `BR-1` 已作废 → `Names:` 下 `(not tracked: BR-1 is retired)`，`Named by:` 照常
- `canon context src/billing` → 没有 `# References`
- 没设 `links_since` 时 `canon context BR-1` → 其余照常，这一节写 `canon links: canon/config.yaml has no links_since …`，退出码 4
