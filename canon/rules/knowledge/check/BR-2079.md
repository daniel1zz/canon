## 规则

没有配置 `code_root` 时，顶层领域 README 的 `code:` 里列出的每个路径（目录或文件，相对仓库根目录）都必须存在，否则 `canon check` 在这个 README 上报 `domain-code-missing`，因为不存在的路径会让 `canon context <路径>` 悄悄漏掉这个领域。配置了 `code_root` 时不做这项检查：README 不该写 `code:`（BR-2117），约定的目录是否存在由 BR-2118 检查。

## 例子

- billing 的 README 写 `code: [src/billing, src/gone]`，`src/gone` 不存在 → 报 `domain-code-missing`，指出 `src/gone`
- `code:` 里写的是存在的文件 `src/main.ts` → 不报
