# 检查（knowledge/check）

`canon check` 检查整个 `canon/` 是否自洽：文件格式、编号唯一、引用存在、领域的代码位置（README 的 `code:` 或 `code_root` 下的目录）和代码目录对得上、规则有测试在标题里点名、必填段落非空、没有残留的模板占位行、规则 `lists` 声明的代码列表和文字及代码对得上、测试不读 `floor_skip_paths` 下的真实文件。合入时也会跑它（`work/land`）。另有一种只提示、不算发现的输出：固定加载的文字超出预算（BR-2257）。

## 术语

- **发现（finding）**：一条检查结果，带种类（如 `ref-dangling`）、文件和说明。
- **提示（hint）**：写在标准错误上、以 `hint ` 开头的一行，不算发现，不改变退出码。
- **测试标题**：`test`、`it`、`describe` 的第一个参数；只有会运行的测试标题里的规则编号才算这条规则有测试。
