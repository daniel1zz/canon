## 规则

在变更的 worktree 里（不是主 checkout），`canon check` 对这项工作改动的规则和决策（和 `canon work review` 用同一种找法：HEAD 和 main 的 merge base 到当前的工作区，BR-2358）的新行（定义同 BR-2402）按 BR-2401 判定，每处复述在标准错误写一行：`note: ` 加 BR-2401 的那行格式。它不是发现：标准输出和退出码不受影响（BR-2189）。主 checkout 里不做这项提示。

## 例子

- worktree 里 `BR-2` 新加了一句照抄 `BR-1` 并点名它的话 → 标准错误有 `note: canon/rules/billing/BR-2.md:9: BR-2 restates BR-1`，标准输出是 `ok: ...`，退出码 0
- 这句复述在 main 上的 `BR-2` 里就有，这次只改了别的行 → 没有这行 `note:`
- 主 checkout 里有同样的复述 → 没有这行 `note:`
