---
id: BR-2257
title: 每个会话固定加载的文字超过 session_text_budget 时，canon check 和 canon work test 提示一行，不算发现
status: active
business: 固定加载的文字大小
---

## 规则

`canon/config.yaml` 配置了 `session_text_budget`（大于 0 的整数，单位字节）时，`canon check`（带不带 `--sizes`、`--json` 都一样）和 `canon work test` 按 BR-2256 量出每个会话固定加载的文字合计；合计大于预算时，在标准错误输出一行 `hint session-text: <合计> bytes loaded every session, over session_text_budget <预算> (<根指令文件> <a>, work guide <b>, skill descriptions <c>); canon check --sizes lists each part`，其中根指令文件按 BR-2256 选择，`<c>` 是所有 skill 描述的字节数之和。这是提示，不是发现（D-37）：不算进发现条数，不改变标准输出和退出码，合入时的 `canon check` 也不因此拒绝。合计等于或小于预算时不提示；没配置 `session_text_budget`（或写成 `null`）时不提示。`session_text_budget` 写成 0、负数、小数或不是数字时，按配置错误处理（BR-2045），所有命令以退出码 2 失败，信息里有 `session_text_budget`。

## 例子

- `session_text_budget: 100`，合计 150 字节，没有发现 → `canon check` 标准输出只有 `ok: ...` 一行，标准错误有一行以 `hint session-text: 150 bytes loaded every session, over session_text_budget 100` 开头，退出码 0
- 同一个仓库运行 `canon work test` → 输出同一行提示，退出码和没有这行提示时一样
- `session_text_budget: 150`，合计 150 字节 → 不提示
- 没配置 `session_text_budget`，合计 100000 字节 → 不提示
- `session_text_budget: 100`，合计 150 字节，带 `--json`，没有发现 → 标准输出是 `[]`，提示在标准错误里，退出码 0
- `session_text_budget: 0` 或 `session_text_budget: 1.5` 或 `session_text_budget: "8KB"` → `canon check` 退出码 2，信息里有 `session_text_budget`

- Codex 会话、AGENTS.md 为 7 字节，预算 1 → 提示根指令部分是 `AGENTS.md 7`；有非空 AGENTS.override.md 时改为该文件名及其字节数，不写 CLAUDE.md。
