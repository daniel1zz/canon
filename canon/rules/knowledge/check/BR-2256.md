title: canon check --sizes 报出每个会话固定加载的文字大小
status: active

## 规则

`canon check --sizes` 在标准错误输出里，按下面的顺序每部分一行报出它的 UTF-8 字节数，只量大小，不看内容（D-37）：仓库根目录的 `CLAUDE.md` 整个文件，行为 `session-text CLAUDE.md: <n> bytes`；`canon brief` 最先输出的工作说明（当前运行的 canon 自带的那一段，不含后面的变更、交接和问题），行为 `session-text work guide: <n> bytes`；`.claude/skills/` 下每个 skill 目录的 `SKILL.md` 里 front matter 的 `description`，按目录名排序，行为 `session-text <路径> description: <n> bytes`。最后一行是 `session-text total: <合计> bytes`，后面跟 `, budget <预算>`，没配置 `session_text_budget` 时跟 `, no budget (session_text_budget)`。没有 `CLAUDE.md`、没有某个 skill 的 `SKILL.md` 时不输出这一行；`SKILL.md` 没有 `description` 或 front matter 解析不了时按 0 字节算，行尾加 ` (no description)`。和 `canon check` 其他部分一样不跟随符号链接（BR-2186）：`CLAUDE.md`、skill 目录或 `SKILL.md` 是符号链接时不读它，按 0 字节算，行尾加 ` (symbolic link, not read)`。标准输出、`--json` 的输出和退出码都和不带 `--sizes` 时一样（BR-2189）。不带 `--sizes` 时不输出这些行。

## 例子

- `CLAUDE.md` 有 2063 字节，一个 skill `.claude/skills/a/SKILL.md` 的 description 是 `做 A`（5 字节），没配置预算 → 标准错误依次有 `session-text CLAUDE.md: 2063 bytes`、`session-text work guide: <工作说明字节数> bytes`、`session-text .claude/skills/a/SKILL.md description: 5 bytes`、`session-text total: <三者之和> bytes, no budget (session_text_budget)`；标准输出仍然是 `ok: ...` 那一行，退出码 0
- 同一个仓库不带 `--sizes` → 标准错误里没有 `session-text` 行
- 没有 `CLAUDE.md` → 没有 `session-text CLAUDE.md` 这一行，合计里不算它
- skill `b` 的 `SKILL.md` 没有 `description` → `session-text .claude/skills/b/SKILL.md description: 0 bytes (no description)`
- `CLAUDE.md` 是指向 `AGENTS.md` 的符号链接 → `session-text CLAUDE.md: 0 bytes (symbolic link, not read)`，不读链接指向的文件
- 配置了 `session_text_budget: 12000` → 最后一行是 `session-text total: <合计> bytes, budget 12000`
- 带 `--sizes --json`，有一条发现 → 标准输出只有 JSON 数组，`session-text` 行都在标准错误里，退出码 1
