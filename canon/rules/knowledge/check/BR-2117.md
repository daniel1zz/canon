## 规则

`canon check` 在下列 README 上报 `domain-code-declared`，提示删掉 `code:`：配置了 `code_root` 时，任何领域的 README 写了非空的 `code:`；没有配置 `code_root` 时，子领域的 README 写了非空的 `code:`。子领域只写业务（范围、术语、规则），它的代码按 `code_root` 的约定，或者通过外层顶层领域的 `code:` 找到。不需要 `code:` 的 README 可以没有 front matter。

## 例子

- 没有 `code_root`，`canon/rules/work/drop/README.md` 写 `code: [src/work/drop.ts]` → 报 `domain-code-declared`
- 没有 `code_root`，顶层的 `canon/rules/work/README.md` 写 `code: [src/work]` → 不报
- `code_root: src`，`canon/rules/work/README.md` 写 `code: [src/work]` → 报 `domain-code-declared`
- `code_root: src`，README 没有 front matter → 不报
- 没有 `code_root`，子领域 README 没有 front matter → 不报
