## 规则

已退役：负责人 2026-11-04 选择去掉这条提示。本仓库里得到提示的 7 个文件都是误报，C-254 真正出问题的子进程在被测的代码里，提示看不到。以下是退役前的内容。

`canon check`（带不带 `--json`、`--sizes` 都一样）和 `canon work test` 在 `tests` 配置（BR-2046）找到的 JS/TS 测试文件（`.js`、`.ts`、`.jsx`、`.tsx`，含 `.mjs`、`.cjs`、`.mts`、`.cts`）里找两样东西：改 `process.env` 的写法（`process.env.X =`、`process.env["X"] =`、`+=`、`??=`、`||=`、`&&=`、`delete process.env…`、`Object.assign(process.env, …)`），和不传 `env` 的 `Bun.spawn(…)` 或 `Bun.spawnSync(…)` 调用。不传 `env` 指：只有一个参数且不是对象字面量；或者选项（第二个参数，或唯一的参数是对象字面量时就是它）是对象字面量，顶层既没有 `env` 键，也没有 `...` 展开。同一个文件两样都有时，每个这样的文件在标准错误输出一行 `hint env-spawn: <文件>:<第一处改动的行>: assigns process.env and starts Bun children without env (line <行号> 或 lines <行号, 行号, …>); they get the environment bun started with, not that change: pass env: { ...process.env } or set the variable before bun starts`，行号是这些调用所在的行，按文件里的顺序。理由：Bun 启动子进程时不传 `env` 用的是 bun 进程启动时的环境，测试运行中对 `process.env` 的改动传不到子进程，测试可能什么都没验证。

这是提示，不是发现：不算进发现条数，不改变标准输出和退出码，合入时的 `canon check` 也不因此拒绝。静态判断会误报（例如改的只是 `PATH`、靠它找可执行文件，或者子进程本来就不需要那个变量），所以只提示。选项是变量或函数调用的结果时看不出带没带 `env`，不提示。注释行（去掉开头空白后以 `//` 或 `*` 开头）里的写法不算。局限：在别的文件里（帮助函数、被测的代码）启动的子进程、`node:child_process`（它用调用时的 `process.env`）和其他语言的测试都不看。

## 例子

- `src/a.test.ts` 第 3 行 `process.env.X = "1";`，第 5 行 `Bun.spawnSync(["sh", "-c", "echo $X"]);` → 标准错误有一行 `hint env-spawn: src/a.test.ts:3: assigns process.env and starts Bun children without env (line 5); …`，`canon check` 退出码 0，标准输出只有 `ok: …`
- 同一文件第 5 行改成 `Bun.spawnSync(["sh"], { env: { ...process.env } })` → 不提示
- 第 5 行是 `Bun.spawnSync(["sh"], { cwd: root, ...opts })` → 不提示（有展开）
- 第 5 行是 `Bun.spawnSync(["sh"], opts)` → 不提示（看不出）
- 第 5 行是 `Bun.spawn({ cmd: ["sh"], stdout: "pipe" })` → 提示
- 只有 `Bun.spawnSync(["sh"])`，文件里没有改 `process.env` → 不提示
- 只有 `delete process.env["X"]` 和 `Bun.spawn(["sh"], { cwd: root })` → 提示
- 第 3 行改了 `process.env`，第 5、9 行各有一个不传 `env` 的调用 → 只有一行提示，写 `(lines 5, 9)`
- `// process.env.X = "1"` 只在注释里，加上 `Bun.spawnSync(["sh"])` → 不提示
- 同样的写法在 `tools/a.test.ts`，`tests` 只配置了 `src/**/*.test.ts` → 不提示
- 同样的写法在 `src/a.test.py` → 不提示
- 第一个例子的仓库运行 `canon work test` → 输出同一行提示，退出码和没有这行提示时一样
