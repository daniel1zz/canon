## 规则

在变更的 worktree 里，`canon check` 按 BR-2403 找出这项工作改动的决策（没有被取代的），把 `## 决定` 段分成条目：顶格的列表项（`1.`、`1、`、`-`、`*` 开头）连同它下面缩进的行算一条，不是列表的段落以空行分开、各算一条。一条里有这次新写的行、而整条（反引号和代码块里的字不算）一个规则编号都没有时，在标准错误写一行 `note: <路径>:<条目第一行的行号> an item of <决策>'s 决定 this work wrote names no rule: …(BR-2471)`，说明它许下的行为要有一条点名这个决策的规则（还没做的写成计划中的），并在这里点名；不许下产品行为的条目可以不管。它只是提示：不算发现，不进标准输出，不改变退出码。这项工作没写的条目不提示（D-112）。

## 例子

- 变更新建 `D-2`，`决定` 第 2 条“敌人有韧性值：”下面缩进一行“韧性打空进入硬直。”，两行都没有规则编号 → 一条提示，行号是“敌人有韧性值”那一行
- 同一个 `D-2` 第 1 条写了“按 `BR-9`”→ 不提示
- 第 3 条只在反引号里写了 `` `BR-12` `` → 算没点名，提示
- main 上已有的 `D-3` 的条目没写规则，这项工作只改它的 `后果` → 不提示
- 有提示时标准输出没有这句，退出码不因它改变
