## 规则

`canon/` 下的一份文档里，同一个 `## <标题>` 行（去掉首尾空白后相同）在代码块（以 ```` ``` ```` 或 `~~~` 开始和结束）以外出现不止一次时，`canon check` 报 `section-duplicate`，每个重复的标题一条，写明文档编号、标题和每一处在文件里的行号，并说明 canon 只读第一处、要合成一段。已经关闭（`done` 或 `dropped`）的变更是历史，不报（和 BR-2161 的 D-24 同理）。

## 例子

- 打开的变更 `C-1` 在第 67 行和第 79 行各有一个 `## 教训` → 报 `section-duplicate`：`C-1: ## 教训 appears on lines 67 and 79; canon reads only the first, so merge them into one`
- 同一个文件里 `## 要改什么` 也出现两次 → 再报一条，写它自己的行号
- `## 教训` 只出现一次，另一处在代码块里 → 不报
- `## 教训` 和 `## 教训二` 各出现一次 → 不报
- 已经 `done` 的变更有两个 `## 教训` → 不报
- 决策 `D-1` 有两个 `## 方案` → 报（不看状态）
