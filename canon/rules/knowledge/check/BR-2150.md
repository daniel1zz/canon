id: BR-2150
title: 待办清单里的编号必须是存在的变更
status: active
---

## 规则

`canon check` 对 `canon/backlog.md` 里排进清单的每个编号（BR-2148 认定的列表项开头的编号），如果没有这个编号的变更，报告一条 `ref-dangling`，位置写成 `canon/backlog.md:<行号>`。已完成或已放弃的变更不算错误。没有 `canon/backlog.md` 时不报告。

## 例子

- 清单第 3 行是 `- C-99`，没有 `C-99` → `ref-dangling  canon/backlog.md:3: lists C-99, which is not a change`
- 清单里的 `C-1` 已经 done → 不报告
- 没有 `canon/backlog.md` → 不报告
