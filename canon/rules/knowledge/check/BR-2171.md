id: BR-2171
title: 当前文档里反引号写的仓库路径已被移走或删除时报 path-missing
status: active
---

## 规则

`canon check` 读当前文档里反引号写的片段（围起来的代码块不算）：生效的规则（不含 `## 例子`，那里是假想项目的输入）、领域 README、已接受的决策（不含 `## 背景` 和 `## 方案`，那里写的是做决定时的情况）、open 的变更，以及仓库根目录的 `CLAUDE.md` 和 `README.md`；已完成或放弃的变更、被取代的决策和笔记是历史，不读。一个片段算仓库路径，当它不含空白和占位符号（`<`、`>`、`*`、`?`、`{`、`}`、`$`、`|`、省略号、编号占位如 `C-n`、`://`），并且满足其一：含 `/` 且第一段是仓库根目录下现有的目录（结尾的 `/` 和 `:行号` 去掉后再看）；或者不含 `/`、是带常见扩展名（`.ts`、`.md`、`.yaml`、`.json`、`.sh` 等）的文件名。这样的路径现在不存在（文件名：仓库里没有同名文件），而 HEAD 的 git 历史里有过它（被移走或删除了），报 `path-missing`，写明文档和路径。历史里从没有过的路径（假想的例子、计划新建的文件）不报。有候选路径、但目录不是 git 仓库时，报一条 `path-missing`，写明读不到历史。

## 例子

- `CLAUDE.md` 写着 `src/coord`，代码已挪到 `src/work`，历史里有 `src/coord/db.ts` → 报 `path-missing`，指出 `src/coord`
- `README.md` 写着 `state.ts`，这个文件已删除、仓库里没有同名文件 → 报
- open 的变更写着计划新建的 `src/work/remote/`，历史里没有 → 不报
- 规则正文写着 `src/billing`，历史里从没有过 → 不报
- 规则的 `## 例子` 里写着已删除的 `src/old.ts` → 不报；同一路径写在 `## 规则` 里 → 报
- 已接受的决策在 `## 背景` 里写已删除的 `src/old.ts` → 不报；写在 `## 决定` 里 → 报
- done 的变更、被取代的决策、笔记里写已删除的 `src/old.ts` → 不报
- `src/<领域>/x.ts`、`src/**/*.test.ts`、单独的 `.ts`、`https://x.dev/a.md` → 不算路径
- `src/kernel/git.ts:12` → 按 `src/kernel/git.ts` 检查，存在就不报
- 已删除的路径写在代码块里，或者不加反引号 → 不报
