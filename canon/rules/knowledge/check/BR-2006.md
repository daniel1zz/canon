## 规则

`canon/rules/` 下的每个目录（包括子领域的目录）都必须有 `README.md`，front matter 里用 `code:` 列出至少一个代码路径（目录或文件，路径必须存在，BR-2079），缺少或为空列表时报 `file-invalid`，这样 `canon context <路径>` 不会悄悄漏掉某个领域。

## 例子

- `canon/rules/auth/` 下只有规则文件、没有 README → 报 `file-invalid`
- README 的 front matter 没有 `code:` → 报 `file-invalid`
- README 写 `code: []` → 报 `file-invalid`
- README 写 `code: [src/auth]` → 不报
- 子领域目录 `canon/rules/auth/tokens/` 没有 README → 报 `file-invalid`
