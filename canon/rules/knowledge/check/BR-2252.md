---
id: BR-2252
title: 决策来源引用的仓库文件现在还在时，摘录必须仍在文件里，否则报 source-quote-missing
status: active
---

## 规则

没被取代的决策（`accepted` 或 `proposed`）里，`## 方案` 段每条格式正确、指向仓库文件路径的来源（BR-2110），去掉 `:行号` 后现在是仓库里的一个文件时，`canon check` 不联网地核对摘录在这个文件现在的内容里：比较方法和合入时的核对（BR-2111）相同，文件内容和摘录都把连续空白合并成一个空格，再看摘录是不是文件内容的一段；`:行号` 只去掉，不核对行号。不在时报 `source-quote-missing`，信息写明决策编号、文件路径和摘录。来源路径本身或它在仓库里的任何一级上层目录是符号链接时，不跟随链接、不读它（BR-2186），也报 `source-quote-missing`，信息写明这个路径是符号链接、没有读，链接指向的东西存不存在都一样。文件现在不存在时不在这里报，由 BR-2110 处理（历史里有过就不报）。被取代（`superseded`）的决策是历史，它的来源不核对。网址来源不核对，只在合入时核对新增的（BR-2111）。

## 例子

- `accepted` 的决策写着 `- 来源：src/a.ts “export function refund(”`，`src/a.ts` 里有这段 → 不报
- 同一条来源，`src/a.ts` 里这个函数已改名为 `refundOrder`，摘录不在了 → 报 `source-quote-missing`，信息含 `D-1`、`src/a.ts` 和 `export function refund(`
- `- 来源：src/a.ts:12 “export function refund(”`，摘录在文件第 30 行 → 不报
- 摘录是 `“export   function refund(”`（多个空格），文件里是换行隔开的 `export` 和 `function refund(` → 不报
- `docs/k` 是指向仓库外某个文件的符号链接，`- 来源：docs/k “aws_secret_access_key = A”` → 报 `source-quote-missing`，写明 `docs/k` 是符号链接、没有读；摘录对不对、链接指向的文件在不在，结果都一样
- `docs` 是指向仓库外目录的符号链接，`- 来源：docs/x.ts “export function refund(”` → 同样报，写明是符号链接
- `proposed` 的决策，摘录不在文件里 → 报
- `superseded` 的决策，摘录不在文件里 → 不报
- 来源文件已挪走，HEAD 的历史里有过它 → 不报（BR-2110）
- `- 来源：https://example.com/a “some long quote”`，页面里没有这段 → `canon check` 不报
