## 规则

`canon quality verdict` 的 `--by owner` 必须带 `--question <n>`（D-145，P7）。这个问题要同时满足：

1. 已回答；
2. 问题文字里写着这条标准的编号（整个编号：`Q-1` 不匹配 `Q-10`）；
3. 没有被这条标准或别的标准的另一次判定引用过；
4. 答案是负责人本人的：人在终端里直接回答的，或 agent 转述且转述的原话和 Claude Code 的提问记录相符（同 BR-2331 对发布问题的要求，`witness` 是 `match`）。

不满足时退出码 1，不记，提示怎样问：`canon human ask "Q-n: <门槛>，在 <提交> 上通过吗？" --option pass,fail`。满足时记下事件，`question` 是问题编号，`owner_words` 是转述的原话（人直接回答时是答案）。通过与否仍由 `--result` 给出。`--by owner` 不带 `--question`，退出码 2。

## 例子

- 问题 #7 “`Q-3`：……通过吗？”，负责人在终端回答 → `--by owner --question 7 --result pass` 记下，owner_words 是答案
- 同上，agent 转述，原话和提问记录相符 → 记下
- 转述的原话和提问记录不符 → 退出码 1，不记
- 问题 #7 问的是 `Q-30`，判定 `Q-3` → 退出码 1，不记
- 问题 #7 还没有回答 → 退出码 1，不记
- 问题 #7 已经被 `Q-3` 的上一次判定引用 → 退出码 1，不记
- `--by owner` 没有 `--question` → 退出码 2
