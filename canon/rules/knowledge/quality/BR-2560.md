## 规则

`active` 说的是负责人确认过这条质量标准（D-145、D-146），所以只有负责人的回答能让一条标准变成 `active`，否则文档就在说假话（D-139 允许为文档不说谎而拒绝）。

合入时按编号比较合入的树和 main 上 `canon/quality` 下的质量标准：一条在合入的树里是 `active`，而在 main 上是 `draft`、`retired` 或还不存在时，算这次合入确认了它。有这样的质量标准时，和 BR-2510 让成功标准离开待负责人一样：

- 合入的是杂务：拒绝，退出码 1，提示改用变更。
- 变更文件的 `owner_answers` 里没有一个为这个变更问的（`canon human ask --change <C-n>`）、已经回答的问题：拒绝，退出码 1，信息列出这些质量标准的编号，提示先问负责人，再把问题编号写进 `owner_answers`。

这条只拦变成 `active` 这一处：新建 `draft`、改门槛和来源、改成 `retired`、从 `active` 改回 `draft`、main 上已经是 `active` 的标准改别的内容，都照常合入。

## 例子

- main 上 `Q-1` 是 draft，变更把它改成 active，没写 `owner_answers` → 拒绝，退出码 1，信息提到 `Q-1` 和 `canon human ask --change`
- 同上，`owner_answers: [12]`，#12 是为这个变更问的、已回答 → 合入
- `owner_answers: [12]`，#12 已回答但是为别的变更问的 → 拒绝；#12 是为这个变更问的但还没回答 → 拒绝
- 变更新建 `Q-2`，一开始就写 `status: active`，没写 `owner_answers` → 拒绝
- main 上 `Q-3` 是 retired，改回 active，没写 `owner_answers` → 拒绝
- 杂务把 `Q-1` 从 draft 改成 active → 拒绝，提示改用变更
- 变更新建 draft 的 `Q-4`，或把 active 的 `Q-1` 改成 retired，或改 active 的 `Q-1` 的门槛 → 合入
