## 规则

`canon quality verdict --by agent` 记下判定时（BR-2586），事件的 `self` 是 `true` 的条件（D-145：判定人就是写这个变更的会话时标为自评，不禁止）：记下它的执行者（BR-2023）也是某次合入（`land.ok` 事件）的执行者，这次合入在被判的构建提交的历史里、不在这条标准上一次判定的构建提交的历史里（没有上一次判定时不设下限），并且改到了这条标准管的范围（范围的解释按 BR-2589）。否则是 `false`；`--by test` 和 `--by owner` 一律是 `false`。

自评的判定照样算数（BR-2589），只在 `canon quality list`、`canon quality status` 和 `canon overview` 里单独标出来（BR-2590）。

## 例子

- 会话 A 合入了改到 `Q-1` 管的路径的 C-5，之后自己对 `Q-1` 记 `--by agent` 的判定，构建提交包含 C-5 → self 是 true
- 会话 B 没有合入过这些变更，记同样的判定 → self 是 false
- A 的合入只改了 `Q-1` 管的路径之外的文件 → A 的判定 self 是 false
- A 的合入在上一次判定的构建提交里已经有了 → A 这次的判定 self 是 false
- `--by owner` → self 是 false
