## 规则

`canon check` 对每条生效的质量标准（`draft` 或 `active`；`retired` 的不查）：

- 它的 `aspect` 不是方面清单（BR-2556）里的某个方面（名字完全相同）时，报 `ref-dangling`，信息写明这个方面，并说明要把它加进 `canon/quality/README.md` 的 `## 方面`；没有 `canon/quality/README.md` 时同样报（D-145、D-146）。
- 它的 `covers` 里的每一项，既不是一个存在的领域名、也不是仓库里存在的文件或目录时，报 `ref-dangling`，信息写明这一项。

方面清单里一个方面写明负责人定为不适用或推迟（BR-2556），却有生效的质量标准属于它时，报 `quality-aspect`，信息写明方面和这些质量标准的编号：两处说法相反，要么改方面清单，要么让这些标准 `retired`。

## 例子

- `Q-1` 的 `aspect: 音效`，方面清单有 `- **音效**：` → 不报
- `Q-1` 的 `aspect: 音效`，方面清单只有“战斗手感” → `ref-dangling`，信息提到“音效”和 `canon/quality/README.md`
- 没有 `canon/quality/README.md`，有一条 draft 的 `Q-1` → `ref-dangling`
- `Q-2` retired，方面不在清单里 → 不报
- `covers: [knowledge/quality]`，这个领域存在 → 不报
- `covers: [src/combat]`，仓库里没有这个目录 → `ref-dangling`，信息提到 `src/combat`
- `covers: [.]` → 不报
- 方面清单 `- **音效**：推迟：「先不做音效」`，`Q-3`（active）的 `aspect: 音效` → `quality-aspect`，信息提到“音效”和 `Q-3`
- 同上，但 `Q-3` 是 retired → 不报
