## 规则

每条保留的发现先找同一根因的未关闭 issue：评审指出的 issue 编号确实是一个带 `canon-review` 标签的未关闭 issue，或者用 `gh issue list --search` 找到标题相同（不区分大小写）的未关闭 issue；找到就在那个 issue 下评论，否则新建一个带 `canon-review` 标签的 issue。同一次评审里根因相同、或指向同一个已有 issue 的多条发现，合成一个 issue 或一条评论，正文逐条列出文件、行和出错情形。

## 例子

- 评审指出 `#12`，`#12` 未关闭 → 在 `#12` 下评论，不新建
- 评审没指出编号，但已有标题相同的未关闭 issue `#12` → 在 `#12` 下评论
- 评审指出 `#99`，但 `#99` 不在未关闭列表里 → 新建 issue
- 同一个根因有两条发现（第 1 行和第 2 行）→ 只新建一个 issue，正文列出两处
