title: 文档必须有类型要求的段落且内容非空
status: active
---

## 规则

每种文档类型可以声明必需的段落（`## <标题>`）。这个类型的每个文档，不论状态，都必须有这些段落，且每段去掉占位行后还有内容，否则 `canon check` 报 `doc-missing-section`，并列出缺的段。多出来的段落不受限制。内置的决策要求 `背景`、`方案`、`决定`、`后果`；变更要求 `为什么`、`要改什么`、`任务`；规则的形状由 `规则` 和 `例子` 两条规则单独管；笔记不要求段落。领域 `README.md` 必须有非空的 `## 术语`。

## 例子

- 变更 `C-1` 只有 `## 为什么` 和 `## 要改什么` → 报 `doc-missing-section`，提到 `## 任务`
- 变更 `C-2` 的 `## 任务` 下只有模板占位行 `- [ ] <任务>` → 报 `doc-missing-section`
- 变更 `C-3` 多了一段 `## 陷阱和假设` → 不报
- 已完成的决策 `D-1` 缺 `## 后果` → 报（不看状态）
- 领域 README 的 `## 术语` 是空的 → 报 `doc-missing-section`
