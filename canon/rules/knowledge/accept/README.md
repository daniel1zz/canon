# 验收（knowledge/accept）

验收是每份规则和决策的属性：在后台测试通过的提交上，它没有挂着未处理的评审意见、引用没有可疑的，就按当前文字记为已验收（D-137）。验收点 `refs/canon/accepted` 在代码测过、文档一致、评审完整、上次验收点之后改过的规则和决策都已验收时前移；后台测试每次通过都自动试一次，负责人也可以随时用 `canon accept` 发起；没改过的文档上的旧问题只挡它们自己，不挡验收点。发版发布已验收的提交（D-89）。这里只管验收这一个关口；各项条件本身由它们自己的领域定义（floor 在 work/land，评审意见在 knowledge/review/findings，可疑引用在 knowledge/links）。

## 术语

- **验收**：对一个提交确认 D-89 的条件成立（改过的文档按 D-137 逐份验收），并记录在 `refs/canon/accepted`。
- **文档验收**：一条规则或一份已接受的决策按它当前文字的指纹记为已验收（`doc.accept` 事件，BR-2537）。
- **待负责人裁决**：一条未处理的意见有未回答的裁决问题（BR-2461 的 `question` 列）。

## 业务

- **验收**：每份文档什么时候算已验收、后台测试通过后怎样自动验收，`canon accept` 查什么、按什么顺序、通过和不通过各输出什么、`refs/canon/accepted` 怎么移动。
