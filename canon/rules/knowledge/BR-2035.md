## 规则

规则、决策和领域 README 里，只要还有一整行是模板占位（例如单独一行 `<...>`，或 `- <...> → <...>`），`canon check` 就报 `template-unfilled`；写在反引号或代码块里的不算。

## 例子

- 规则的例子里还有 `- <边界上的具体输入或状态> → <必须出现的结果>` → 报 `template-unfilled`
- 例子写 `` `canon work start <C-n>` `` → 开始变更 → 不报
- 领域 README 里还有单独一行 `<这个领域管什么、不管什么。>` → 报 `template-unfilled`
