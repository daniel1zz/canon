status: active

## 规则

`canon context <目标>` 返回的每个顶层领域下，既没有被选出、也没有作为导入列出（BR-2119）的子领域，在一行里按名字列出：`Other subdomains, not included: <名字>, … (canon context <name>)`，不带它们的 README 和规则，让读的人知道同一个顶层领域里还有哪些行为可能相关。没有这样的子领域时没有这一行。

## 例子

- `code_root: src`，目标 `src/work/drop/drop.ts`，work 有子领域 work/claims、work/drop、work/land → 有一行 `Other subdomains, not included: work/claims, work/land (canon context <name>)`
- 目标 `work` → 全部子领域都已返回，没有这一行
- 返回的 billing 没有子领域 → 没有这一行
