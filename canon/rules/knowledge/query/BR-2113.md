## 规则

领域可以有子领域：`canon/rules/<领域>/<子领域>/`，名字写作 `<领域>/<子领域>`，各有自己的 README 和代码路径。`canon context <路径>` 返回代码路径覆盖这个路径的每个领域和子领域，再加上它们外层的每个领域（外层的 README 和直接属于外层的规则）；同一个领域下、代码路径不覆盖它的子领域不返回；`canon context <领域名>` 返回这个领域、它下面的所有子领域和外层领域；目标是文档编号时，返回它提到的规则所在的领域和外层领域。

## 例子

- work 的代码是 `src/work`，子领域 work/drop 的代码是 `src/work/drop.ts`，目标 `src/work/drop.ts` → 返回 work 和 work/drop，不返回 work/land
- 目标 `src/coord/db.ts` 只被 work 覆盖 → 只返回 work 和直接属于它的规则
- 目标 `work` → 返回 work 和它的全部子领域
- 目标是规则 `BR-1`，它在 work/drop 里 → 返回 work 和 work/drop
