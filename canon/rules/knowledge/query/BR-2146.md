## 规则

`canon context <目标>` 在上下文之后加一段 `# Open review notes`，逐条列出目标（是规则或决策时）、上下文里列出的规则和决策的未处理评审建议（BR-2145），每条写明文档编号、建议原文、得到它的变更和日期，并说明建议不拦截、不单独开变更，在改这份文档时处理。没有未处理的建议时不输出这一段。

## 例子

- `BR-1` 有未处理的建议“例子缺少边界另一侧”，执行 `canon context billing`（`BR-1` 在 billing 领域）→ 输出 `# Open review notes` 和 `BR-1: 例子缺少边界另一侧`
- 执行 `canon context BR-1` → 同样列出这条建议
- billing 领域的规则都没有未处理的建议 → 输出里没有 `Open review notes`
