## 规则

`canon search <词…>`（不是编号）没有任何文档包含全部词时，输出最后多一行提示：`no document contains every word: canon/ is written in Chinese, so try Chinese keywords (canon search 合入), or an id (canon search BR-12)`。一个文档都没有命中时，先输出 `(no match)` 再输出这行提示。有文档包含全部词时没有这行。按编号搜索没有结果时只输出 `(no match)`。`--json` 的输出里没有提示。

## 例子

- 搜索 `review split`，没有文档同时含两个词，有文档含 review → 列出部分命中的文档，最后一行是提示
- 搜索 `zzqq`，没有文档含它 → `(no match)`，然后是提示
- 搜索 `sessions hours`，`BR-3` 两个词都有 → 没有提示
- 搜索 `BR-999`，不存在 → 只有 `(no match)`
