## 规则

`canon context` 把规划中的规则和生效的规则一起列出（BR-2007），在编号后加 ` [规划中]`：只列标题时是 `- BR-n [规划中] <标题>`，`--full` 时这条规则的标题行是 `## BR-n [规划中] <标题>`；生效的规则不加。`canon show` 一条规划中的规则时，第一行在路径后加两个空格和 `[规划中]`（BR-2213）。

## 例子

- billing 有生效的 `BR-1`“退款”和规划中的 `BR-2`“部分退款” → `canon context billing` 输出 `- BR-1 退款` 和 `- BR-2 [规划中] 部分退款`
- 同上加 `--full` → 有 `## BR-2 [规划中] 部分退款` 一行，下面是 `BR-2` 的全文
- `canon show BR-2` → 第一行 `canon/rules/billing/BR-2.md  [规划中]`
- `canon show BR-1` → 第一行 `canon/rules/billing/BR-1.md`，没有 `[规划中]`
- 作废的 `BR-3` → `canon context billing` 里没有它（BR-2028）
