title: 每次 canon search 记一个事件，带查询和结果数
status: active

## 规则

每次 `canon search` 运行完都在事件表记一条 `search` 事件，主题为空，内容是 `query`（原样的查询）、`results`（列出的文档数，受 `--limit` 限制）和 `full`（列出的文档里包含全部词的个数；按编号搜索时等于 `results`）。`--json` 时也记。

## 例子

- 搜索 `sessions hours`，列出 `BR-3` → 事件 `{query: "sessions hours", results: 1, full: 1}`
- 搜索 `sessions refunds`，列出两条部分命中 → `{results: 2, full: 0}`
- 搜索 `zzqq`，没有结果 → `{results: 0, full: 0}`
