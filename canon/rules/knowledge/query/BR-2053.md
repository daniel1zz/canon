## 规则

`canon context <目标>` 除了 BR-2007 的内容，还按类型列出提到其中任一规则的声明类型文档（编号、标题、状态、路径）。目标是声明类型的文档编号时，返回它提到的规则所在的领域。

## 例子

- `SP-1` 的正文提到 billing 领域的规则，`canon context billing` → 输出里有 `# spec` 一节，列出 `SP-1`
- `canon context SP-1` → 返回 billing 领域
- `SP-2` 没提到 billing 的任何规则 → 不出现在 billing 的上下文里
