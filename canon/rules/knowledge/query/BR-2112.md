## 规则

`canon context <目标>` 默认对每个领域输出领域 README 全文，而规则只列编号和标题，最后一行提示用 `canon show <编号>` 读要改的规则、用 `canon context <目标> --full` 读全部规则全文；加 `--full` 时输出每条规则的全文，每条的标题行按 BR-2007 带出它的业务，不再有这行提示。选出哪些领域、规则、决策和变更不受影响（BR-2007）。规则评审拿到的当前内容始终是全文，因为它要对照整个领域找矛盾。

## 例子

- billing 领域有规则“Refund window”，正文 “Refunds within 30 days.”，执行 `canon context billing` → 有 `- BR-1 Refund window`，没有 “Refunds within 30 days.”，最后提示 `canon context billing --full`
- 执行 `canon context billing --full` → 有 `## BR-1 Refund window` 和正文，没有 `--full` 的提示
- 合入后评审改动过的 billing 规则 → 评审拿到的 billing 当前内容包含每条规则的正文
