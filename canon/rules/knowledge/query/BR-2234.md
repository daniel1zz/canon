id: BR-2234
title: canon context 的目标是不存在的编号时退出码 3，是什么都不匹配的路径时照常退出并提示
status: active
---

## 规则

`canon context <目标>` 的目标写成编号的样子（某个文档类型的前缀、`-`、数字，不区分大小写，和 `canon show` 一样，BR-2213）而没有这个编号的文档时，向标准错误输出 `canon: <目标> does not exist`，标准输出什么都不写，退出码 3。目标不是编号的样子（路径或领域名），而没有任何领域、规则或文档匹配时，照常输出 `No domain, rule or document matches. Domains: canon rule domains`，退出码 0：路径可能是还没有对应领域的新目录，不算找不到。

## 例子

- `canon context BR-99999`，没有这条规则 → 标准错误 `canon: BR-99999 does not exist`，标准输出为空，退出码 3
- `canon context br-99999` → 同样退出码 3
- `canon context BR-1`，规则存在 → 输出这条规则和它所在的领域，退出码 0
- `canon context src/nowhere`，没有领域的代码覆盖它 → `No domain, rule or document matches. …`，退出码 0
