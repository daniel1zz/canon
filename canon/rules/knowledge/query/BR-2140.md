title: 被部分修改的决策在 canon show 和 canon context 里指向修改它的决策
status: active
---

## 规则

一个已接受（accepted）的决策在 `amends` 里列出决策 X 时，`canon show X` 在文件全文之后加一行 `partly amended by <编号> <标题> (<路径>)`；`canon context` 输出里 X 出现在决策列表或作为目标时，同样写明 `partly amended by <编号>`。列出 X 的决策还是提议中（proposed）或已被取代（superseded）时，不显示这一行。

## 例子

- `D-10`（accepted）写着 `amends: [D-9]` → `canon show D-9` 最后一行是 `partly amended by D-10 <D-10 的标题> (canon/decisions/D-10.md)`；`canon context` 列出 `D-9` 的那一行带 `partly amended by D-10`
- `canon context D-9`，`D-10`（accepted）写着 `amends: [D-9]` → 输出第一行是 `# D-9 <D-9 的标题> — partly amended by D-10`
- `D-12`（superseded）写着 `amends: [D-9]`，没有别的决策修改 `D-9` → `canon show D-9` 和 `canon context` 都没有 `partly amended by`
- `D-11`（proposed）写着 `amends: [D-9]`，没有别的决策修改 `D-9` → `canon show D-9` 和 `canon context` 都没有 `partly amended by`
