# 搜索和上下文（knowledge/query）

agent 怎样找到要读的东西：`canon search` 按词或编号找，`canon context <路径|领域|编号>` 给出相关领域的说明、规则、决策和进行中的变更。路径按约定（`code_root` 下的目录和领域一一对应）或顶层领域 README 的 `code:` 对应到和它匹配的领域和子领域，再带上外层领域的说明、目标文件导入的代码所在的领域，以及同一顶层领域下其余子领域的名字；规则默认只列标题，`--full` 给全文。给的是规则或决策的编号时，末尾还列出和它最相关的文档（引用、全文、共用名字三种排名融合，D-90），编辑规则或决策后的 hook 也列这些。

## 业务

- **上下文**：按一个目标（仓库路径、领域名或文档编号）把相关领域现在的全部内容摆出来，给写代码和评审的人用。

## 术语

- **上下文**：`canon context` 的输出。
- **代码路径**：配置了 `code_root` 时是 `<code_root>/<领域路径>`；没有时是顶层领域 README 的 `code:`，子领域没有。
- **匹配**：领域的某个代码路径等于目标、是目标所在的目录，或在目标这个目录之下。
- **导入的领域**：目标文件的相对 import 指向的代码所在的领域，运行时从文件里读出，不在任何地方声明。同一个顶层领域下的列出规则标题，别的顶层领域只列名字。
