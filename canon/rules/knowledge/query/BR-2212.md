title: canon search 最多列出 --limit 条，--limit 必须是正整数

## 规则

`canon search <查询>` 按 BR-2073 的顺序最多列出 `--limit` 条结果，不写时是 20 条；`--json` 也一样。`--limit` 的值必须是正整数（`1`、`2`、`20` 这样只由数字组成、大于 0 的数）；是别的值（`abc`、`0`、`-1`、`1.5`、空字符串）时以退出码 2 拒绝，错误信息写明 `--limit` 和收到的值，在读文档和记 `search` 事件（BR-2134）之前就拒绝，不输出 `(no match)` 和提示。

## 例子

- 有 25 篇文档含 `sessions`，`canon search sessions` → 列出 20 条
- 同样的文档，`canon search sessions --limit 1` → 只列出 1 条，`search` 事件的 `results` 是 1
- `canon search sessions --limit abc`，有文档含 `sessions` → 退出码 2，信息里有 `--limit` 和 `"abc"`，没有 `(no match)`，事件表里没有新的 `search` 事件
- `canon search sessions --limit 0` → 退出码 2
- `canon search sessions --limit 1.5` → 退出码 2
