## 规则

`canon context <目标>` 按 BR-2113 选出领域和子领域，对每个选出的领域返回它的 README、它直接包含的每条生效规则（默认只列标题，`--full` 给全文，BR-2112）、提到其中任一规则的已接受决策，以及提到或在 `rules` 里列出其中任一规则的未完成变更；目标可以是仓库路径（和领域的代码目录双向匹配）、领域名或文档编号。

## 例子

- 目标 `src/billing/refund.ts`，billing 领域的代码目录是 `src/billing` ，billing 没有子领域 → 返回 billing 的 README 和它的全部生效规则，不返回 auth 领域
- billing 里有一条作废规则、一个提议中的决策 → 两者都不返回
- 目标是变更 `C-1`，它在 `rules` 里列出 billing 的规则 → 返回 billing 领域
