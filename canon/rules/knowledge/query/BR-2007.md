## 规则

`canon context <目标>` 按 BR-2113 选出领域和子领域，对每个选出的领域返回它的 README、它直接包含的每条生效和规划中的规则（规划中的标明，BR-2238）（默认只列标题，`--full` 给全文，BR-2112）、提到其中任一规则的已接受决策，以及提到或在 `rules` 里列出其中任一规则的未完成变更；目标可以是仓库路径（和领域的代码目录双向匹配）、领域名或文档编号。只列标题时，每条规则的标题后面标出它 front matter 里的 `business`（BR-2430），写成 ` [业务: <业务名>]`；没有 `business` 的不标。

## 例子

- 目标 `src/billing/refund.ts`，billing 领域的代码目录是 `src/billing` ，billing 没有子领域 → 返回 billing 的 README 和它的全部生效规则，不返回 auth 领域
- billing 里有一条作废规则、一个提议中的决策 → 两者都不返回
- billing 里有一条规划中的规则 → 返回它
- 目标是变更 `C-1`，它在 `rules` 里列出 billing 的规则 → 返回 billing 领域
- billing 的一条规则写了 `business: 退款`，默认只列标题 → 它那一行末尾是 `[业务: 退款]`
- billing 的另一条规则没有写 `business` → 它那一行末尾不标业务
