## 规则

`canon show <编号>` 先输出这份文档在仓库里的路径一行（规划中的规则在路径后加两个空格和 `[规划中]`，BR-2238），再空一行，然后是文件的原文（含 front matter，不做任何改写）；被已接受的决策部分修改的决策，之后再加 BR-2140 的那一行。编号不区分大小写：`br-1` 和 `BR-1` 找到同一份文档。没有这个编号的文档时退出码 3（BR-2022），什么都不输出到标准输出。

## 例子

- `canon/rules/billing/BR-1.md` 的内容是 `---\nid: BR-1\n…` → `canon show BR-1` 输出第一行 `canon/rules/billing/BR-1.md`，第二行为空，之后是这个文件的全部原文，包括 `id: BR-1` 那一行
- `canon show br-1` → 和 `canon show BR-1` 输出相同，退出码 0
- `canon show BR-999`（不存在）→ 退出码 3，标准输出为空
