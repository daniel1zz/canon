## 规则

评审收到的提示里，每个在这次合入里改动的版本，和每条在这次合入里改动的、带 `release` 标签的规则所属的版本，各有一段：版本编号、标题、状态，没有在改动文档里出现过的版本还有它的全文，以及标着这个版本的规则（不含作废的）一行一条，写编号、领域、标题，规划中的规则注明；提示的要求里写明：标着某版本的规则做了该版本“不做”里排除的事或超出它的“范围”，该版本的“不做”和它自己的“范围”或标着它的规则矛盾，评审都可以拦。规则索引里带标签的规则写着它的版本。没有版本改动、也没有带标签的规则改动时，提示里没有版本段。

## 例子

- 合入只改了 `R-1` 的 `## 不做` → 提示里有 `# Release R-1` 一段，列出标着 `R-1` 的每条规则
- 合入只改了标着 `R-1` 的 `BR-3` → 提示里有 `# Release R-1` 一段，含 `R-1` 的全文（因为它不在改动的文档里），其中 `## 不做` 可见
- 同一次合入既改了 `R-1` 又改了标着它的规则 → `R-1` 只有一段，不重复它的全文
- `BR-4` 没标版本，只改了它 → 提示里没有版本段
- 提示的规则索引里 `BR-3` 一行写着 `[R-1]`，没标版本的规则没有
