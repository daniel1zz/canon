## 规则

评审的回答（BR-2367）里，标准是 `contradiction` 或 `restatement` 的意见，文字里一段原文都没引（按 BR-2433 认引文：「」、“”或单个反引号里的文字，只有编号的不算）时，canon 不把它当拦截意见，而是当成提示（`note`），文字后面加上 `(canon: given as [<标准>] but quotes no text, so taken as a note)`；它不让结论变成 `block`，也不记成未处理意见（BR-2434）。这两类标准说的都是文档里已经有的文字，评审的说明要求引出原文（D-119）。别的标准没引原文照样拦。

## 例子

- `{"criterion":"contradiction","text":"BR-1000 cites BR-956 only in the part this call shows; cannot be decided here"}` → 结论是 `ok`，这条是提示，末尾有 `(canon: given as [contradiction] but quotes no text, so taken as a note)`
- `restatement`，文字是 ``未发现可判定的 restatement，`BR-5` 无复述`` → 提示（反引号里只有编号，不算引文）
- `restatement`，文字是 `BR-5 「三天内退款」 restates BR-4 「五天内退款」` → 拦截
- `untestable`，文字是 `BR-4 says nothing about exit codes` → 拦截
