status: active
business: 合入后的代码评审
---

## 规则

评审返回的每条发现必须有类别（`security` 或 `concurrency`）、标题、根因、文件、大于 0 的行号，以及在什么输入或时序下出错的说明；缺任何一项的发现被丢弃，打印一行 `dropped ...`，不提 issue。

## 例子

- 一条发现没有文件 → 丢弃，不提 issue
- 一条发现的类别是 `style` → 丢弃
- 一条发现写明 `src/queue.ts:1` 和“两个合入者同时调用 → 都合入” → 保留
