---
id: BR-2143
title: 改动常驻说明时，合入前评审同一条要求是否已写在别处
status: active
business: 常驻说明的重复评审
---

## 规则

常驻说明是每个会话开始时都会读到的文字：main 上的配置（同 BR-2074，不取自被合入的树）`instructions` 列出的文件（仓库里的相对路径；没配置时是 `CLAUDE.md`）、`.claude/skills/<名字>/SKILL.md` 的 `description`，以及 `canon brief` 输出的工作说明。一次合入新增或修改了 `instructions` 列出的文件或任何 `.claude/skills/<名字>/SKILL.md`（例外见 BR-2410）时，合入在规则评审之后调用配置的评审命令，提示里有改动过的文件名和所有常驻说明的当前文字；改动过的 `.claude/skills/<名字>/SKILL.md` 还附上被合入的树里的全文（评审在 main 提交的临时 worktree 里运行，BR-2216，那里只有旧文字）。提示里还附上每个改动过的常驻说明文件在这次合入里的 unified diff（base 到 head），让评审分得出新旧。只判断这次合入带进来的重复：同一条要求（指令、条件、限定）已经写在另一份常驻说明里，或者在同一份里写了两遍，并且这两处至少有一处在这次合入新增或改动的行里（diff 的 `+` 行）时，评审拦截，合入被拒，结论写明重复的两处；被删掉的行造不成重复，移动的行（一处删、另一处加）算新增；两处都在没改动的文字里的重复是原来就有的，不拦截，评审最多把它写成结论为 `ok` 的发现，作为不拦截的提示输出（同 BR-2145）；一句指向别处的引用、在通用要求上加的本项目限定不算重复。只删除这些文件、或没有改动它们时，不做这次评审。评审命令以非 0 退出，或者没有输出有效的结论时，合入被拒，拒绝原因是 `review`。main 上没有配置 `review` 时合入被拒（被合入的树自己设了 `review` 也一样，评审命令要先单独合入），原因 `review`，信息列出这些文件，先给出评审命令的写法，再建议 `review: none` 先用 `canon human ask` 问负责人；canon 不核对（同 BR-2074、BR-2295）；main 上已经是 `review: none` 时合入照常进行，输出 `review: none` 和被跳过的文件，写一条 `review.skip` 事件；在同一次合入里把 `review` 改成 `none` 见 BR-2295。`instructions` 的格式见 BR-2151。

## 例子

- 只改了 `CLAUDE.md`，评审结论 `block` → 合入被拒，拒绝原因是 `review`，提示里有 `CLAUDE.md` 的新文字和工作说明
- 改了 `.claude/skills/x/SKILL.md`，评审结论 `ok` → 合入成功，提示里有每个 skill 的 description，以及 `.claude/skills/x/SKILL.md` 改动后的全文
- `instructions: [docs/agent.md]`，只改了 `CLAUDE.md` → 不做这次评审；改了 `docs/agent.md` → 评审
- `CLAUDE.md` 里原来就有两句重复的要求，这次合入只改了不相关的一行 → 提示里的 diff 只有那一行带 `+`，评审结论 `ok`，合入成功，重复作为 `review note` 输出
- 这次合入在 `CLAUDE.md` 里新加了一行，重复了别处已写的要求 → 提示里的 diff 里这一行带 `+`，评审结论 `block` 时合入被拒
- 只改了代码和变更文件 → 不做这次评审
- 改了 `CLAUDE.md`，没有配置 `review` → 合入被拒，原因 `review`，信息含 `CLAUDE.md` 和 `review: none`，事件表没有 `review.skip`
- 改了 `CLAUDE.md`，main 上已经是 `review: none` → 输出 `review: none — CLAUDE.md`，事件表多一条 `review.skip`，合入成功
- 改了 `CLAUDE.md`，评审命令以退出码 3 结束 → 合入被拒，拒绝原因是 `review`
- main 上 `instructions` 是默认的 `CLAUDE.md`，变更改了 `CLAUDE.md`，同时把 `instructions` 改成 `[docs/other.md]` → 仍按 main 上的清单评审 `CLAUDE.md`，评审回答 `block` 时合入被拒
- main 上没有 `review`，变更设了 `review` 又改了 `CLAUDE.md` → 合入被拒，原因 `review`，信息提示先单独合入 `review`，评审命令没有被调用
