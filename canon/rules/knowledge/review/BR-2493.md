## 规则

规则评审（BR-2009）的提示告诉评审：下面给出的变更如果有 `## 方案依据` 一节，遇到下面任一情况，就给一条 `note`（点名变更编号，从不拦截）：

- 它说沿用的决策并没有决定这个变更做出的某个选择，也就是用沿用掩盖了新选择；
- 没写最坏的失败，或没写什么结果能证明它选错了；
- 对持久数据、外部边界或依赖给的证据，只是一个链接或一句断言，没有回答这类选择要回答的问题（数据怎样演进和恢复；外部对象自己的配置和限制；为什么用这个依赖、它在实际运行环境里的限制）。

方案依据好不好不是拦截标准（BR-2367 的标准名里没有它），和其他 note 一样不记成未处理的意见（BR-2434）。先审计、不拦截，见 D-124。

## 例子

- 规则评审的提示含 `When the change shown below has a section 方案依据 (its design basis), add a note (never block)`
- 规则评审的提示含 `a new choice hidden behind the reuse` 和 `no result that would prove the choice wrong`
