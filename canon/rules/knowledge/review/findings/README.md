# knowledge/review/findings

评审意见的记账：合入后的评审给出、核实成立（BR-2442）的点名拦截标准的意见有身份，记成未处理的意见，挂在它点名的每份文档上，写的人和下一个改这份文档的人在 `canon context`、`canon brief` 里看得到；只能显式关闭，之后的评审没提到它不算关闭（D-89、D-97）。不拦截的建议不在这里，见 knowledge/review 和 D-21。

## 术语

- **身份**：标准、点名的编号、被指出原文的哈希，定义见 BR-2433。
- **未处理的意见**：记了账、还没关闭的意见，一个身份同时最多一条。
- **关闭**：作废点名的文档（BR-2435）、判为误报（BR-2438）、复问后不再成立（BR-2439）。
