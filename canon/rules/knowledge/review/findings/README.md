# knowledge/review/findings

评审意见的记账：合入后的评审给出的点名拦截标准的意见有身份，全部记成未处理的意见（BR-2442），挂在它点名的每份文档上，交给主 agent 当场处理；写的人和下一个改这份文档的人在 `canon context`、`canon brief` 里也看得到。只能显式关闭，之后的评审没提到它不算关闭（D-89、D-97、D-99）。不拦截的建议不在这里，见 knowledge/review 和 D-21。

## 业务

- **交给主 agent**：合入后评审的拦截意见怎样记账、怎样告诉主 agent，不另跑核实。
- **关闭**：主 agent 或人怎样关闭一条意见：修掉了，或者引原文说明不成立。

## 术语

- **身份**：标准、点名的编号、被指出原文的哈希，定义见 BR-2433。
- **未处理的意见**：记了账、还没关闭的意见，一个身份同时最多一条。
- **关闭**：作废点名的文档（BR-2435）、判为误报（BR-2438）、`canon finding close` 写明修复提交或引原文（BR-2453）。
- **主 agent**：派子 agent 干活、做决定的那个会话（D-99）。
