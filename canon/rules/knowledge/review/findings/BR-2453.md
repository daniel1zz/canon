## 规则

`canon finding close <意见编号> (--fixed <提交> | --spurious "<原文>") --reason "<理由>"` 关闭一条未处理的意见（BR-2434），agent 和人都可以用，执行者照常记下（BR-2023）。下面的检查都通过之后，再按 BR-2478 核对意见的档位（D-118）。按这个顺序检查，先成立的决定退出码，被拒时什么都不写：

- 意见编号（可以带 `#`，如 `#3`）不是正整数、`--fixed` 和 `--spurious` 没给或两个都给、`--reason` 没给或去掉首尾空白后为空 → 退出码 2；
- 没有这个编号的意见、`--fixed` 的提交解析不出来 → 退出码 3；
- 意见已经关闭 → 退出码 5，信息写明它是怎么、什么时候关闭的；
- `--fixed`：提交不在 main 上（不是 main 最新提交的祖先或它本身），或者它已经包含在意见记账时评审看到的提交里（修复要在意见之后），或者它没有改动意见所挂的任何一份文档（规则、决策、版本按编号找文件，常驻说明按路径）→ 退出码 1，信息写明是哪一种；
- `--spurious`：原文把连续空白压成一个空格、去掉首尾空白后少于 8 个字符，或者在 main 最新提交上意见所挂的每一份文档里（同样压过空白）都找不到它 → 退出码 1，信息列出查过的文档。

criterion 是 `overview` 的意见（总览和生效文档矛盾）多算一份文档：架构总览 `canon/architecture.md`，`--fixed` 的提交和 `--spurious` 的原文都照常对它检查——这类意见的修复通常落在总览里，而总览没有文档编号。

通过时在同一个写事务里写一条 `finding.close` 事件（主题是意见记账时的变更编号，详情有 `finding`、`how`（`fixed` 或 `spurious`）、`commit` 或 `quote`、`reason`），并关闭这条意见，关闭方式就是 `how`，关闭事件是这条事件；输出 `closed review finding #<编号>: fixed by <提交前 9 位>` 或 `closed review finding #<编号>: spurious, quoted from <文档编号或总览路径>`，退出码 0。两个会话同时关闭同一条意见时只有一个写进去，另一个得到退出码 5。

## 例子

- 意见 #3 挂在 `BR-1`、`BR-7` 上，main 上之后的提交 `abc123` 改了 `BR-7` 的文件 → `canon finding close 3 --fixed abc123 --reason "BR-7 改成只适用海外订单"` 关闭它，输出 `closed review finding #3: fixed by abc123…`，事件 `finding.close` 的 `how` 是 `fixed`
- `--fixed` 给的是意见记账时评审看到的那个提交本身 → 退出码 1，信息写明修复要在意见之后
- `--fixed` 给的提交只改了代码，没改 `BR-1`、`BR-7` → 退出码 1
- `--fixed` 给的提交只在变更分支上、还没合入 main → 退出码 1
- `--spurious "本规则只适用于海外订单"`，`BR-7` 在 main 上逐字有这句（中间换行也算）→ 关闭，输出 `spurious, quoted from BR-7`
- `--spurious "海外订单的退款"`（7 个字符）→ 退出码 1；`--spurious "海外订单的退款。"`（8 个字符，`BR-7` 里有）→ 关闭
- `canon finding close '#3' --fixed abc123 --reason x` → 和写 `3` 一样
- `--spurious` 的原文只出现在意见文字里、不在 `BR-1`、`BR-7` 里 → 退出码 1，信息列出 `BR-1`、`BR-7`
- 在 Claude Code 会话里运行，意见已定为 A 档 → 照常关闭，执行者是这个 agent；还没定档 → 按 BR-2478 拒绝
- 意见 #3 已被合入作废 `BR-7` 关闭 → 退出码 5，信息写明 `retired` 和关闭时间
- `canon finding close 0 --fixed abc` → 退出码 2；只给 `--reason` → 退出码 2
- `canon finding close 99 --spurious "……" --reason x`，没有 #99 → 退出码 3
- `[overview]` 的意见挂在 `BR-7` 上，修复提交只改了 `canon/architecture.md` → `--fixed` 关闭它
- 同一条意见，`--spurious` 引的原文只在架构总览里逐字存在 → 关闭，输出 `quoted from canon/architecture.md`
- `[contradiction]` 的意见，`--fixed` 的提交只改了 `canon/architecture.md` → 退出码 1，总览只算 `overview` 意见的文档
