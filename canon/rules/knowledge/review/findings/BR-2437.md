## 规则

在认领了变更的 worktree 里，`canon brief` 对挂在 BR-2147 那一组文档上的每条未处理意见输出一行 `Open review finding <和 BR-2436 相同的那一行，不带开头的 "- ">`，每条只输出一次。不在认领了变更的 worktree 里时，有未处理意见就输出一行 `<n> open review finding(s) on <m> document(s) (A <a>, B <b>, C <c>, untriaged <u>): canon context <id> lists them`，括号里是各档和还没定档的条数（BR-2477），n 是全部未处理意见的条数，m 是它们挂着的文档去重后的份数；一条都没有时不输出这一行。

## 例子

- 变更 `C-2` 的 `rules: [BR-1]`，`BR-1` 上有未处理意见 #1 → 在 `C-2` 的 worktree 里，brief 输出 `Open review finding #1 untriaged [contradiction] BR-1, BR-7: ...`
- 变更只在反引号里写了 `BR-1` → 不输出
- 主 checkout，#1 挂在 `BR-1`、`BR-7` 上，#2 挂在 `BR-1` 上 → `2 open review finding(s) on 2 document(s) (A 0, B 0, C 0, untriaged 2): canon context <id> lists them`
- 主 checkout，没有未处理意见 → 不输出这一行
