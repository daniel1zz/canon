## 规则

`canon context <目标>` 在未处理的建议（BR-2146）之后加一段 `# Open review findings`，列出挂在 BR-2146 那一组文档上的未处理意见（BR-2434），每条只列一次，按记账先后。这一段先写一行固定的说明（先说怎么定档，BR-2477、BR-2478；再列出 BR-2453、BR-2435、BR-2438 的关闭方式），然后每条一行：`- #<意见编号> <档位> [<标准>] <编号>: <意见文字> (<变更>, opened <记账日期 YYYY-MM-DD>, <天数> days ago)`，其中档位是 `tier A`、`tier B`、`tier C`，还没定档写 `untriaged`（BR-2477）；编号是点名的编号用逗号加空格连起来，一个都没点名时写 `-`；没有变更时括号里没有变更那一项，天数是记账至今的整天数，正好 1 天写 `1 day ago`。已关闭的意见不列；没有可列的意见时没有这一段。

## 例子

- 有未处理意见时，标题之后的说明行是 `Give each a tier with canon finding tier <n> A|B|C --reason "<why>" (A you settle it, B another session supports the close with canon finding advise, C the owner approves it through canon finding ask then --owner <question>; a spurious close is B at least). Settle each now: fixed, canon finding close <n> --fixed <commit> --reason "<why>"; does not hold, canon finding close <n> --spurious "<quote from a document it names>" --reason "<why>". Open until closed explicitly (also: a document it names retired or superseded, or canon verdict record); a later review that does not mention one does not close it.`
- `BR-1`（billing 领域）上有今天记的未处理意见 #1 `[contradiction] BR-1 和 BR-7 的「三天」矛盾`，来自 `C-9`，执行 `canon context billing` → `- #1 untriaged [contradiction] BR-1, BR-7: BR-1 和 BR-7 的「三天」矛盾 (C-9, opened <今天>, 0 days ago)`
- 同一条挂在 `BR-1` 和 `BR-2` 上，两者都在上下文里 → 只列一次
- `BR-7` 在别的领域，执行 `canon context BR-7` → 也列出 #1
- 记账已 3 天 → `3 days ago`；1 天 → `1 day ago`
- 没有变更 → `(opened <日期>, 0 days ago)`
- #1 已关闭，或者上下文里的文档都没有未处理意见 → 输出里没有 `Open review findings`
