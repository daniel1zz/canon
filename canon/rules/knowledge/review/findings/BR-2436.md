## 规则

`canon context <目标>` 在未处理的建议（BR-2146）之后加一段 `# Open review findings`，列出挂在目标（是规则或决策时）、上下文里列出的规则和决策上的未处理意见（BR-2434），每条只列一次，按记账先后。这一段先写一行，说明意见只能显式关闭（判为误报、点名的文档作废、复问后不再成立），之后的评审没提到它不算关闭；然后每条一行：`- #<意见编号> [<标准>] <编号>: <意见文字> (<变更>, opened <记账日期 YYYY-MM-DD>, <天数> days ago)`，其中编号是点名的编号用逗号加空格连起来，一个都没点名时写 `-`；没有变更时括号里没有变更那一项，天数是记账至今的整天数，正好 1 天写 `1 day ago`。已关闭的意见不列；没有可列的意见时没有这一段。

## 例子

- `BR-1`（billing 领域）上有今天记的未处理意见 #1 `[contradiction] BR-1 和 BR-7 的「三天」矛盾`，来自 `C-9`，执行 `canon context billing` → `- #1 [contradiction] BR-1, BR-7: BR-1 和 BR-7 的「三天」矛盾 (C-9, opened <今天>, 0 days ago)`
- 同一条挂在 `BR-1` 和 `BR-2` 上，两者都在上下文里 → 只列一次
- `BR-7` 在别的领域，执行 `canon context BR-7` → 也列出 #1
- 记账已 3 天 → `3 days ago`；1 天 → `1 day ago`
- 没有变更 → `(opened <日期>, 0 days ago)`
- #1 已关闭，或者上下文里的文档都没有未处理意见 → 输出里没有 `Open review findings`
