## 规则

规则评审（BR-2009）的提示里有一条拦截标准 `restatement`（BR-2367）：改动的规则或决策在这次合入新增或改动的行里，把另一条规则已经写明的行为（条件、结果、数字或先后）用相同或不同的说法再写一遍，而不是只点名那条规则（按 BR-x、见 BR-x）。不算复述：用几个字点明指的是那条规则的哪个行为（按 `BR-11` 的侦测半径）；写本文档在那条规则之上多出的、或和它不同的部分；决策的「来源：」行照抄原文。只在这次没有新增或改动的行里的复述只能是 `note`，所以已有的复述不拦无关的改动（D-84）。为此提示里多两段：`# Lines added or changed in this landing`，对每个合入的 base 上已有的改动规则或决策，列出它的新行（定义同 BR-2402，以合入的 base 为准），每行写行号和原文，只删了行的写 `(only lines removed)`；新的规则或决策不在这一段里，`restatement` 标准的说明写明不在这一段里的改动文档是新的、每一行都算新行；`# Possible restatements found by shared wording`，列出 BR-2401 在这些新行里（新文档是全部行）判定的复述，写明只是提示、换了说法的复述不在其中。没有对应内容时不出现那一段。`canon work review` 给出同样的提示（BR-2358）。增量评审（BR-2396）附第一段，不附第二段。

## 例子

- main 上已有的 `BR-2` 这次新加了第 9 行 → 提示的 `# Lines added or changed in this landing` 下有 `## BR-2` 和 `9: ` 加这一行的原文，没改的行不在其中
- 这次只新建了 `BR-3` → 提示里没有 `# Lines added or changed in this landing` 这一段，`restatement` 的说明写明不在这一段里的文档每一行都是新的
- `BR-2` 新加的行照抄了 `BR-1` 的句子并点名它 → `# Possible restatements found by shared wording` 下有 `BR-2 restates BR-1`
- `BR-2` 这次只删了一行 → 这一段写 `(only lines removed)`
- 评审返回 `{"findings":[{"criterion":"restatement","text":"BR-2 复述了 BR-1"}]}` → 结论是 `block`，这条意见按 BR-2442 记账
- 没有改动的规则或决策是 main 上已有的、也没有判定出复述 → 提示里没有这两段
- 改动 main 上已有的 `BR-2`、新加第 9 行，增量评审（BR-2396）时 → 提示里有 `# Incremental review`，也有 `# Lines added or changed in this landing` 下的 `## BR-2` 和 `9: ` 加这一行的原文，没有 `# Possible restatements found by shared wording`
- 同上，但 `BR-2` 是这次新建的 → 增量评审的提示里没有 `# Lines added or changed in this landing`，`BR-2` 每一行都算新行
