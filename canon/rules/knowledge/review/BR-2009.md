## 规则

一次合入新增、修改或删除了 `canon/rules` 或 `canon/decisions` 下的任何文件（包括领域 README），且配置了评审命令时，评审收到规则和决策的新文字、被删除文件在 main 上的原文，以及每个受影响领域（含 README 被改的领域）的完整上下文；受影响的是子领域时，给的是它所在的整个顶层领域（含全部子领域），这样跨子领域的矛盾也能被发现；结论为 `block`、评审命令运行失败或没有输出有效结论时都拒绝合入，main 不动。

## 例子

- 新规则写“退款大概会在某个时间后处理”，评审返回 `block` → 合入被拒绝，退出码 1，main 不变
- 评审命令退出码非 0 → 合入被拒绝，提示评审无法运行
- 只改了 billing 领域的 README，评审返回 `block` → 合入被拒绝
- 改了 work/land 里的一条规则 → 评审收到整个 work 领域（含 work/claims 等子领域）的全文
- 用 `git rm` 删掉一条规则文件 → 评审收到这条规则删除前的原文；返回 `block` 时合入被拒绝
