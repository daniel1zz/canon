status: active
---

## 规则

规则评审和常驻说明的重复评审都用配置里的 `review` 命令：canon 在 worktree 目录下用 `sh -c` 运行它，把评审提示从标准输入交给它，从标准输出里取第一个 `{` 到最后一个 `}` 之间的文字当作 JSON 结论，前后可以有别的文字。结论里 `verdict` 必须是 `ok` 或 `block`；`findings` 是字符串列表，没有或不是列表时当作没有意见。命令以非 0 退出时，错误是 `review command exited <退出码>: <标准错误的前 500 个字符>`；输出里没有 JSON、JSON 解析不了、或 `verdict` 是别的值时，是无效结论；这两种情况合入都被拒绝（BR-2009、BR-2143）。

## 例子

- 命令输出 `Here is my answer: {"verdict":"block","findings":["BR-1 is vague"]} done` → 结论 `block`，意见 `BR-1 is vague`
- 命令输出 `{"verdict":"ok"}` → 结论 `ok`，没有意见
- 命令先读完标准输入再回答 → 读到的就是完整的评审提示
- 命令输出 `looks fine to me`（没有 JSON）、`{"verdict":"ok",}`（解析不了）或 `{"verdict":"maybe"}` → 无效结论
- 命令向标准错误输出 `boom` 并以退出码 3 结束 → `review command exited 3: boom`
