## 规则

评审的回答（BR-2367）里，一条带拦截标准的意见，文字里含有下面任何一个说法（比较时两边都去掉所有空白、不分大小写）时，canon 不把它当拦截意见，而是当成提示（`note`），文字后面加上 `(canon: given as [<标准>] but its own text says there is no problem, so taken as a note)`；它不让结论变成 `block`，也不记成未处理意见（BR-2434）：

- `未发现阻断`
- `no blocking defect`
- `no blocking issue`

表里只放“整体没有阻断问题”这种结论句；`no conflict`、`does not contradict`、`没有矛盾` 这类说法常常后面还跟着真问题，不在表里，含有它们的意见照样拦（D-134，统计见 C-597 的方案依据）。评审提示同时写明：结论是没有阻断问题的意见用 `note`。没引原文的 `contradiction`、`restatement` 先按 BR-2481 处理。

## 例子

- `{"criterion":"contradiction","text":"BR-1 要求「三天内退款」，BR-2 要求「三天内退款」，二者一致，没有矛盾。未发现阻断问题。"}` → 结论是 `ok`，这条是提示，末尾有 `(canon: given as [contradiction] but its own text says there is no problem, so taken as a note)`，不记成未处理意见
- `{"criterion":"restatement","text":"BR-6 「按 BR-5 的半径」 agrees with BR-5; overall no blocking defect from the rules shown."}` → 提示
- `{"criterion":"restatement","text":"BR-6 「按半径排序」 orders by radius, so no conflict, but it duplicates the mapping in BR-5 「按半径排序」"}` → 照旧拦截（`no conflict` 不在表里）
- `{"criterion":"untestable","text":"BR-4 says nothing about exit codes"}` → 拦截
