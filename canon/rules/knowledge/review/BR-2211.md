---
id: BR-2211
title: 代码评审列出、搜索、新建或评论 issue 失败时报错退出
status: active
---

## 规则

合入后代码评审调用 `gh`（`CANON_GH`，默认 `gh`）列出带 `canon-review` 标签的未关闭 issue、按标题搜同根因 issue（`gh issue list --search`，BR-2072）、新建 issue 或在 issue 下评论时，`gh` 以非 0 退出，脚本输出 `code-review: <原因>`（原因里有出错的 `gh` 命令和它的退出码），退出码 1，不输出 `code-review: no findings`。列出失败时不调用评审命令。搜索失败时不把这条发现当成没有同根因 issue 去新建，这次评审的发现一条都不提交：搜索在新建和评论之前，为每条发现分组时进行（负责人 2026-11-04 选择报错退出，而不是照样新建可能重复的 issue）。新建或评论失败时，同一次评审里还没处理的发现不再提交。

## 例子

- `gh issue list --state open --label canon-review …` 以退出码 1 结束 → `code-review: gh issue list … exited 1: …`，退出码 1，评审命令没有被调用
- 有一条要新建 issue 的发现，`gh issue create` 以退出码 1 结束 → 退出码 1，没有 `code-review: no findings`
- 有一条发现，评审没指出已有 issue，`gh issue list … --search …` 以退出码 1 结束 → `code-review: gh issue list … --search … exited 1: …`，退出码 1，没有调用 `gh issue create`，没有 `code-review: no findings`
- 有一条发现，评审指出的 `#12` 是带标签的未关闭 issue → 不搜索，在 `#12` 下评论；这时 `--search` 坏了也不影响结果
- `gh` 每次调用都成功，没有发现 → 输出 `code-review: no findings`，退出码 0
