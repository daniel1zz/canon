---
id: BR-2211
title: 代码评审列出、新建或评论 issue 失败时报错退出
status: active
---

## 规则

合入后代码评审调用 `gh`（`CANON_GH`，默认 `gh`）列出带 `canon-review` 标签的未关闭 issue、新建 issue 或在 issue 下评论时，`gh` 以非 0 退出，脚本输出 `code-review: <原因>`（原因里有出错的 `gh` 命令和它的退出码），退出码 1，不输出 `code-review: no findings`。列出失败时不调用评审命令；新建或评论失败时，同一次评审里还没处理的发现不再提交。按标题搜同根因 issue（BR-2072）失败时该报错还是照样新建 issue，已作为待答问题交给负责人（`canon human pending`），定下来之前不在任何规则里。

## 例子

- `gh issue list --state open --label canon-review …` 以退出码 1 结束 → `code-review: gh issue list … exited 1: …`，退出码 1，评审命令没有被调用
- 有一条要新建 issue 的发现，`gh issue create` 以退出码 1 结束 → 退出码 1，没有 `code-review: no findings`
- `gh` 每次调用都成功，没有发现 → 输出 `code-review: no findings`，退出码 0
