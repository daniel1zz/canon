## 规则

`canon change list`、`canon brief` 给没任务的会话指的“第一个可以开始的变更”、议程里可派的活（BR-2527）和 `canon work watch` 的可开始列表，都先按档位（BR-2602，`P0` 在前）排，同一档里按现在的顺序（待办清单的顺序，没列进清单的按编号，BR-2148）。档位只改顺序（D-155），不改哪些变更可开始（依赖没满足的仍不可开始，BR-2564）。

## 例子

- 待办清单是 `C-3`、`C-4`，`C-7` 没列进清单、是 `P1` → 顺序是 `C-7`、`C-3`、`C-4`
- `C-3` 和 `C-7` 都是 `P1` → `C-3` 在前（清单里有它）
- `C-7` 是 `P1`，但它依赖的 `C-6` 还没合入 → 不在可开始的列表里
- 没有任何变更设过档位 → 顺序和以前一样
