## 规则

`canon release new --title "<标题>"` 在 `canon/releases/` 下新建一个版本文档：编号取已用过的最大编号加一（永不重复使用），状态是 `planned`，正文是模板，含 `## 目标`、`## 用户`、`## 范围`、`## 不做`、`## 成功标准`、`## 故事地图切片` 六节，每节一行 `<...>` 占位说明；标题只有 ASCII 时文件名带标题的 slug（`R-n-<slug>.md`），否则只有编号（`R-n.md`）。标题为空退出码 2，不写文件。六节有一节缺失、为空或还是占位行时，`canon check` 报 `doc-missing-section` 或 `template-unfilled`。

## 例子

- 没有任何版本时 `canon release new --title "MVP"` → 输出 `canon/releases/R-1-mvp.md`，退出码 0，front matter 是 `id: R-1`、`status: planned`，六节都在
- 再运行 `canon release new --title "第一版"` → `canon/releases/R-2.md`（标题含中文，没有 slug）
- 删掉 `R-2.md` 后再建一个 → 编号是 `R-3`，不是 `R-2`
- 刚建出的版本文档直接 `canon check` → 占位行还在，报 `template-unfilled`
- `canon release new --title "  "` → 退出码 2，`canon/releases/` 下没有新文件
