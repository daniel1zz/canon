## 规则

`canon release start <版本编号>` 把这个版本文档 front matter 的 `status` 从 `planned` 改成 `active`，写在运行它的工作树里，随所在的变更或杂务合入（D-130）；输出 `<版本编号> → active (<文件路径>; commit it with your change)`，退出码 0。可以同时有多个 `active` 的版本。

- 版本已经是 `active` → 输出 `<版本编号> is already active`，不写文件，退出码 0。
- 版本是 `shipped` 或 `dropped` → 退出码 1，提示它的状态，文件不变。
- 编号不是一个版本 → 退出码 3。
- 在 main 受保护的主 checkout 里运行 → 和 `canon release new` 一样拒绝。

## 例子

- `R-5` 是 planned → 文件里变成 `status: active`，退出码 0
- 再运行一次 → `R-5 is already active`，文件不变，退出码 0
- `R-1` 已发布 → 退出码 1，文件不变
- `R-3` 是 dropped → 退出码 1
- `canon release start R-99`，没有这个版本 → 退出码 3
