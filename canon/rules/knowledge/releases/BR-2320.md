## 规则

`canon release list` 列出状态不是 `shipped` 的版本，每行编号、状态、标题，按编号的数值排序；加 `--all` 连已发布的一起列；`--json` 输出同样的版本（不含正文）；一个也没有时输出 `(no releases)`，退出码 0。

## 例子

- 有 `R-2`（planned）、`R-10`（active）、`R-1`（shipped）→ `canon release list` 先 `R-2` 后 `R-10`，没有 `R-1`
- 同样的仓库 `canon release list --all` → 三个都列，`R-1` 在最前，状态写着 `shipped`
- 没有 `canon/releases/` → 输出 `(no releases)`，退出码 0
