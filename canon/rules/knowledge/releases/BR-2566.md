business: 版本的进度

## 规则

版本和模块文档（`dropped` 的除外）里有按 BR-2504 不算成功标准的列表项（没编号）时，`canon check` 在标准错误输出一行提示（D-151、D-139）：

`hint criteria-unnumbered: list items in ## 成功标准 without an S<k> id are not success criteria (BR-2504): <文档编号> (<条数>), …; give each criterion its id and move the rest out of the list: canon release migrate-criteria`

文档按编号的数值排序，版本在前、模块在后。只是提示：不产生发现，不改退出码，不影响合入。所有文档都没有这样的列表项时不输出这一行。

## 例子

- `R-2` 的成功标准一节有 `- S1 甲`、`- 验收方式：自己验收。`、`- 乙（未满足）` → 一行提示，含 `R-2 (2)`，退出码不变
- `R-2` 有 1 条、`F-3` 有 2 条这样的列表项 → 一行，`R-2 (1), F-3 (2)`
- 列表项都带编号，缩进的子项没有编号 → 不提示
- 说明文字写成列表外的段落 → 不提示
- `R-1` 是 `dropped`，有没编号的列表项 → 不计它
- 没有任何版本和模块 → 不提示
