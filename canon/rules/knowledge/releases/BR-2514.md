## 规则

状态是 `planned` 的版本，标着它的规则（BR-2509 的范围）里至少有一条在某个 `done` 的变更里有通过记录（`passes`）时，`canon check` 输出一行提示 `hint release-planned: <版本编号> is planned, but <n> rule(s) tagged with it have pass records: mark the release in progress with canon release start <版本编号>`（D-130）。这只是提示，不是拦截发现，退出码不受影响。`active`、`shipped`、`dropped` 的版本不提示。

## 例子

- planned 的 `R-2` 标着 3 条规则，其中 2 条在 done 的变更里有通过记录 → `hint release-planned: R-2 is planned, but 2 rule(s) …`，退出码 0
- 同一个版本改成 active → 没有这行提示
- planned 的版本标着的规则都没有通过记录 → 没有提示
- 通过的规则挂在 `R-2` 列着的模块上 → 同样提示
