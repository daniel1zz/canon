## 规则

判定状态是没判过、不通过或过期的生效的质量标准（BR-2589），在发布时列给负责人，由负责人在说 yes 时决定（D-145）：

- `canon release status <R-n>` 最后多一段 `质量标准没证明：Q-1 不通过，Q-2 过期，Q-3 没判过（写进发布问题，canon quality status）`，全是已证明或没有生效的标准时不输出这段；
- `canon release ship` 因为没有负责人的 yes 拒绝时（BR-2331），拒绝信息后面附上同一段，并说明要把它写进问负责人的问题里；放行时也输出这段，作为提示；
- 这些质量标准不改变 `canon release ship` 的条件：只有规则全部已通过和负责人的 yes 才决定能不能发布（BR-2333、BR-2331）。

## 例子

- `Q-1` 不通过、`Q-2` 已证明 → `canon release status R-1` 末尾 `质量标准没证明：Q-1 不通过（…）`
- 所有标准都已证明 → 没有这一段
- 负责人还没回答，`Q-3` 没判过 → ship 退出码 1，信息里有 `Q-3 没判过`
- 负责人已说 yes，`Q-1` 不通过，规则全部通过 → ship 照常发布，并输出这段提示
