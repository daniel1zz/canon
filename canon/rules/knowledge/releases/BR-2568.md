## 规则

一个版本算完成，当且仅当：标着它的规则（BR-2509 的范围，并入它的版本按 BR-2521 算进来，作废的不算）全部是已通过（执行状态同 `canon progress`），它的成功标准（它自己的、它没取消的模块的和并入它的版本的，BR-2504）全部是已满足，而且规则和成功标准合起来至少有一条（D-148、D-151）。一个模块算完成，按同样的条件看挂在它上面的规则（`feature: F-n`）和它自己的成功标准。

写着 `release` 或 `feature` 关联到它的变更（BR-2561）合入了几个、还剩几个，只当工作量显示（BR-2570 的四种状态各几个），不影响算不算完成：变更全部合入、规则或成功标准没达到，仍是未完成；没有任何关联变更、规则和成功标准都达到了，就是完成。计划（`## 计划`）的步骤做了几步也不算。

`canon release status`（BR-2328、BR-2329）和 `canon feature status`（BR-2569）按这条显示完成或未完成；`canon release ship` 不看它，只按 BR-2333。

## 例子

- `R-2` 标着 3 条规则都已通过，成功标准 `S1`、`S2` 都已满足 → 完成
- 同上，`S2` 未证明 → 未完成
- 规则都已通过，没有成功标准 → 完成
- 没有规则，成功标准都已满足 → 完成
- 没有规则也没有成功标准 → 未完成
- `R-2` 的模块 `F-1` 有一条未满足的成功标准 → `R-2` 未完成
- 关联 `R-2` 的变更 5 个都已合入，有一条规则待重新执行 → 未完成
- 关联 `R-2` 的变更一个都没合入，规则和成功标准都达到 → 完成
- `F-1` 挂着 2 条规则都已通过，它的 `S1` 待负责人 → `F-1` 未完成
