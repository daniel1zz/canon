## 规则

`canon release status R-n` 输出这个版本的汇总行（同 BR-2328），然后每种有规则的执行状态一行，写这个状态的规则编号（已通过和待 main 测试的在编号后写变更编号），按规则编号的数值排序；已发布的版本再写一行“发布后又改了”，列出带 `changed_in` 的规则和改它的版本。`--json` 输出一个对象：汇总字段加 `rules`（每条规则的 `id`、`title`、`state`、`change`、`changed_in`）和 `changed_after_ship_rules`。编号不存在或不是版本，退出码 3，标准输出没有内容。没标着它的规则时只有汇总行。

## 例子

- `R-2`（active）标着 `BR-5` 规划中、`BR-3` 已通过（变更 `C-7`）、`BR-4` 待重新执行 → `R-2` 汇总行，然后 `规划中: BR-5`、`已通过: BR-3 (C-7)`、`待重新执行: BR-4` 三行，没有“待 main 测试”那一行
- `R-1`（shipped）的 `BR-3` 写了 `changed_in: [R-2]` → 多一行 `发布后又改了: BR-3 (changed in R-2)`；`R-2`（未发布）的规则写了 `changed_in` → 没有这一行
- `canon release status R-1 --json` → `rules` 里每条规则的 `state` 是 `passed`、`planned`、`waiting` 或 `rerun`，`changed_after_ship_rules` 是 `["BR-3"]`
- `canon release status R-9`，没有这个版本 → 退出码 3
- `canon release status BR-3`（规则编号）→ 退出码 3，说它不是版本
- 版本没有标着它的规则 → 只有汇总行
