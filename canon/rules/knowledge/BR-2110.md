title: 方案里的来源要写明出处和原文摘录
status: active
---

## 规则

决策 `## 方案` 段里写到“来源：”的行，必须是 `来源：<网址或仓库里的文件路径> “<原文摘录>”`：网址以 `http://` 或 `https://` 开头；文件路径是仓库里的相对路径，不能是绝对路径，也不能含 `..`，可以带 `:行号`，去掉 `:行号` 后必须是仓库里现有的文件（不是目录）；摘录放在中文引号里，去掉多余空白后至少 8 个字符。格式不对或文件不存在时 `canon check` 报 `source-malformed`；摘录是否真在文件里，到合入时才核对（BR-2111）。模板留下的占位行不算。

## 例子

- `- 来源：https://arxiv.org/abs/2310.01798 “struggle to self-correct their responses”` → 不报
- `- 来源：src/knowledge/check/check.ts “export function check(”` → 不报
- `- 来源：arXiv 上那篇论文` → 报 `source-malformed`，没有摘录
- `- 来源：/Users/a/x.ts “some long quote”` → 报，绝对路径
- `- 来源：https://example.com “太短”` → 报，摘录不到 8 个字符
- `- 来源：arXiv “struggle to self-correct”`，仓库里没有叫 `arXiv` 的文件 → 报，不是仓库里的文件
- `- 来源：src/knowledge/check/check.ts:12 “export function check(”`，文件存在 → 不报
- `- 来源：src/knowledge “export function check(”`，`src/knowledge` 是目录 → 报
