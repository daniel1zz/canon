## 规则

决策的 `## 方案` 必须是一次真实的取舍：顶层列表里至少两项，每一项（连同它缩进的续行）写明“采用”或“否决”，并且至少一项采用、至少一项否决。不满足时 `canon check` 报 `decision-options`，不看决策的状态。没有 `## 方案` 段的决策（项目改了决策的必需段落）不检查这一条。

## 例子

- 只列了一个方案 → 报 `decision-options`
- 两项都写了“采用” → 报，没有被否决的方案
- 第 3 项只写“负责人这次没有选，不做” → 报，这一项既没写采用也没写否决
- 第 2 项写“先试过，后否决：……” → 不报
- 项目把决策的必需段落改成没有 `方案` → 不检查
