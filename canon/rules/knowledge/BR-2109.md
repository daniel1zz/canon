## 规则

决策的 `## 方案` 必须是一次真实的取舍：顶层列表里至少两项（列表项以 `-`、`*`、`+`、`1.` 或 `1)` 开头），每一项（连同它缩进的续行）写明“采用”或“否决”，并且至少一项采用、至少一项否决。“不采用”“未采用”“没采用”“没有采用”“不再采用”算否决，不算采用。判断时不看这一项里的来源行和引号（中文引号、反引号）里的文字，那是别人的原话，不是作者的取舍。

不满足时，`canon check` 在标准错误上写一行以 `note: <决策文件路径>: ` 开头的提醒，列出不满足的地方，末尾写 `(BR-2109)`；`canon work test` 在自己的输出里也打印这一行，不因此失败。不看决策的状态，退出码不变，不拒绝合入。没有 `## 方案` 段的决策（项目改了决策的必需段落）不检查这一条；`## 方案` 里只有模板占位行时也不提醒这一条，由 `template-unfilled` 报（BR-2035）。

依据：D-139（提醒代替拒绝）。

## 例子

- 只列了一个方案 → 标准错误有 `note: canon/decisions/D-2.md: D-2 has 1 option(s) under ## 方案; a choice needs at least two (BR-2109)`，退出码 0
- 两项都写了“采用” → 有提醒 `no option under ## 方案 is 否决`，退出码 0
- 第 3 项只写“负责人这次没有选，不做” → 有提醒，这一项既没写采用也没写否决
- 第 2 项写“先试过，后否决：……” → 没有提醒
- 项目把决策的必需段落改成没有 `方案` → 不检查
- 两项写成 `+ A：采用。`、`+ B：否决。`，或 `1) A：采用。`、`2) B：否决。` → 没有提醒
- 一项写“不采用，太慢”，另一项写“否决” → 有提醒，没有被采用的方案
- 第 2 项只在来源行 `来源：src/x.ts “we 否决 this one, quoted”` 里出现“否决” → 有提醒，这一项既没写采用也没写否决
- 刚用 `canon decision new` 建出、`## 方案` 还是模板 → 不提醒这一条，由 `template-unfilled` 报
- 状态是 proposed、accepted 或 superseded 的决策只列了一个方案 → 都在标准错误上提醒
- 有提醒时合入照常排队 → 退出码 0
