## 规则

规则的行为哈希是 `规则\n<## 规则 段>\n例子\n<## 例子 段>` 的 SHA-256 的前 16 个十六进制小写字符，其中每一段取标题下到下一个 `## ` 标题之前的文字，所有连续的空白（空格、制表符、换行）换成一个空格并去掉首尾空白；没有这一段时按空文字算。标题、front matter（状态、`untested` 等）、其他段落、领域 README 和术语都不影响它。

## 例子

- 只改规则标题，或在 `## 例子` 后面加一段 `## 背景` → 哈希不变
- 在 `## 规则` 段里加一个空行、把一个空格改成两个、改缩进 → 哈希不变
- `## 例子` 里把 `→ 退出码 2` 改成 `→ 退出码 3` → 哈希变了
- 把一句话从 `## 规则` 段移到 `## 例子` 段 → 哈希变了
- 规则正文是 `## 规则\n\nA\n\n## 例子\n\n- B\n` → 哈希是 `规则\nA\n例子\n- B` 的 SHA-256 的前 16 个字符
