## 规则

`canon doc set <编号> <字段> <值>` 在当前 worktree 里把文档 `<编号>` 的 front matter 字段改成 `<值>`（列表值用逗号隔开），按类型的声明校验（BR-2619），写进文件，记事件 `doc.set`（编号、字段、旧值、新值），不提交（同其他改文件的命令，由会话提交）。下面都以退出码 2 失败、什么都不写：字段没有声明；值不符合格式；字段是 canon 自己写的（`status`、`passes`、`links` 等，信息写明用哪个命令改）；`--clear` 一个 `due: create` 的字段。`--clear` 去掉一个可选字段。文档不存在时退出码 3。值和原来一样时输出“没有变化”，不写文件也不记事件。

## 例子

- `canon doc set C-9 owner_gate "设计稿"` → 写入，记 `doc.set`
- `canon doc set C-9 advances "R-1/S9"`，R-1 没有 S9 → 照写（存在与否由 `canon check` 的 `ref-dangling` 报，BR-2517）；写成 `R1/S9` → 退出码 2
- `canon doc set C-9 status done` → 退出码 2，信息写用 `canon work land --finish` 或 `canon change close`
- `canon doc set C-9 owner_gate --clear` → 退出码 2，它是新建时表态的字段
- `canon doc set C-99 owner_gate x`，C-99 不存在 → 退出码 3
