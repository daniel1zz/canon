## 规则

`canon doc set <编号> <字段> <值>` 在当前 worktree 里把文档 `<编号>` 的 front matter 字段改成 `<值>`（列表值用逗号隔开），按类型的声明校验（BR-2619），写进文件，记事件 `doc.set`（编号、字段、旧值、新值），不提交（同其他改文件的命令，由会话提交）。下面都以退出码 2 失败、什么都不写：字段没有声明；值不符合格式；字段是 canon 自己写的（`status`、`passes`、`links` 等，信息写明用哪个命令改）；`--clear` 一个 `due: create` 的字段。`--clear` 去掉一个可选字段。文档不存在时退出码 3。值和原来一样时输出“没有变化”，不写文件也不记事件。

## 例子

项目声明了 `types.design`，字段 `reviewer: { type: text, due: create }`、`risk: { type: enum, values: [low, high] }`、`refs: { type: ids, none: true }`：

- `canon doc set DS-1 risk high` → 写入，记 `doc.set`，输出提示提交
- `canon doc set DS-1 risk medium` → 退出码 2，信息写允许的值，文件不变
- `canon doc set DS-1 refs "BR-1, D-2"` → 写成列表 `[BR-1, D-2]`；`canon doc set DS-1 refs "none: 新设计"` → 写成这段文字
- `canon doc set DS-1 refs "none:"` → 退出码 2，理由不能为空
- `canon doc set DS-1 status done` → 退出码 2，信息写用哪个命令改状态
- `canon doc set DS-1 owner x`（没声明）→ 退出码 2，列出声明的字段
- `canon doc set DS-1 reviewer --clear` → 退出码 2，它是新建时表态的字段；`canon doc set DS-1 risk --clear` → 去掉
- `canon doc set DS-1 risk high` 再来一次 → 输出没有变化，不记事件
- `canon doc set DS-9 risk high`，DS-9 不存在 → 退出码 3
