## 规则

`canon rule new` 等新建命令在没有给出正文、项目也没有这个类型的模板文件（BR-2055）时，按类型写入内置的中文模板：规则是“规则”和“例子”两段（“规则”的提示写明只写一个能单独测试的行为、出现第二个能单独测试的结果就拆成另一条，别的规则写过的条件和结果只写“按 BR-x”，D-108），决策是“背景、方案、决定、后果”（“决定”的提示写明具体行为写在规则里、只写规则编号），方案的两个选项下各有一行 `来源：<网址或仓库里的文件路径> “<原文摘录，至少 8 个字符>”`（填好就符合 BR-2110，原样留着时 `canon check` 报 `template-unfilled`），变更是“为什么、要改什么、陷阱和假设、教训”，没有“任务”（“陷阱和假设”没有内容时整节删掉；“教训”的提示写明教训是对流程或工具的认识、本变更为自己的功能或修复写的规则、测试和检查不算（D-78），没有时写“无”，关闭变更时要求有内容，见 BR-2161），领域 README 是范围说明、“术语”和“业务”（BR-2430）。

## 例子

- `canon decision new --title 知识以文件存放` → 新文件里有 `## 背景`、`## 方案`、`## 决定`、`## 后果`
- `canon decision new --title x` → 新文件里每个选项下都有一行 `来源：<网址或仓库里的文件路径> “<原文摘录，至少 8 个字符>”`；把它填成真实的文件路径和摘录，`canon check` 不再报 `source-malformed` 和 `template-unfilled`；原样不改 → 报 `template-unfilled`
- `canon change new --title X` → 新文件里有 `## 陷阱和假设`，占位行要填写或连同这一节删掉，否则报 `template-unfilled`
- `canon change new --title X` → 新文件里有 `## 教训`，它的提示含“本变更为自己的功能或修复写的规则、测试和检查不是教训”，没有 `## 任务`
- `canon rule new` 不给 `--body` → `## 规则` 的提示含“只写“按 BR-x””和“就拆成另一条规则”
- `canon decision new --title x` → `## 决定` 的提示含“这里只写规则编号”
- `canon rule new` 不给 `--body` → 新文件里有 `## 规则` 和 `## 例子`，`canon check` 报 `template-unfilled` 直到填好
