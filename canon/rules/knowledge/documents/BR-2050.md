id: BR-2050
title: 声明的文档类型可以用 canon doc new 新建
status: active
---

## 规则

`canon/config.yaml` 的 `types:` 声明一个类型（名字作为 key，写明 `prefix`、`dir`，可选 `statuses` 和 `default`）后，`canon doc new --type <名字> --title <标题>` 按这个前缀分配编号（BR-2002），在 `canon/<dir>/` 下建文件（文件名规则同决策），写入默认状态（没写 `default` 时是第一个状态）。`--type` 不是任何类型时退出码 3。

## 例子

- 声明 `spec: {prefix: SP, dir: specs, statuses: [draft, approved]}`，执行 `canon doc new --type spec --title "Login flow"` → 建出 `canon/specs/SP-1-login-flow.md`，`status: draft`
- `canon/specs/` 里已有 `SP-7` → 新文档是 `SP-8`
- `canon doc new --type spek --title X` → 退出码 3
