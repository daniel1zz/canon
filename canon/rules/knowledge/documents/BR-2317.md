## 规则

`canon rule domain <名字>` 的名字最后一段（`<领域>/<子领域>` 取子领域那一段）是技术层的词时，照常建出领域，退出码仍是 0，并在输出里多写一行以 `hint:` 开头的提示，点名这个词，说明领域应按业务能力命名，并指向 `canon-domains` skill。技术层的词是代码里 `src/knowledge/documents/domain-names.ts` 的 `TECHNICAL_LAYER_WORDS`：`cli`、`api`、`config`、`configuration`、`db`、`database`、`ui`、`utils`、`util`、`common`、`core`、`shared`、`helpers`、`lib`、`misc`、`infra`、`infrastructure`、`model`、`models`、`service`、`services`、`controller`、`controllers`；只有整段完全相等才算，`billing-api`、`apis` 不算，大小写已由名字格式（BR-2115）限定为小写。名字最后一段不在这个列表里时没有提示。提示不是拒绝：不改变是否建出、退出码和建出的文件。

## 例子

- `canon rule domain billing` → 建出，没有 `hint:`
- billing 已存在，`canon rule domain billing/api` → 建出，退出码 0，输出有 `hint:`，点名 `api`，并提到按业务能力命名和 `canon-domains`
- `code_root` 已配置，`canon rule domain config` → 建出，退出码 0，输出有点名 `config` 的 `hint:`
- `canon rule domain billing-api` → 建出，没有 `hint:`（整段不等于列表里的词）
