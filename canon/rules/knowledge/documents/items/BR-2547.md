## 规则

一个段落有项的声明（BR-2546）时，canon 这样读它：

- **分项**：段落里顶格的列表项（以 `-`、`*`、`+`、`1.` 或 `1)` 开头）是一项；它下面不是顶格列表项的行接在这一项后面，用一个空格连起来；缩进的列表项是子项，有 `children` 声明时按它单独读，没有时也接在这一项后面。段落里没有任何列表项时，每个非空行是一项。模板占位行（BR-2035）不算项。这样分出来只有一项、声明写了 `none`、而且这一项（去掉列表符号和首尾空白）整个符合 `none` 时，这一段没有项。
- **对模板**：一项的文字去掉列表符号和首尾空白后，要从头到尾和模板对上：原样文字原样出现，每个槽位取一段符合它类型的非空文字（取出后去掉首尾空白）。可省略段要么整段出现，要么整段没有。有几种对法时，先选出现的可省略段最多的，个数一样时选靠前的可省略段出现的，再让前面的槽位取尽量长的；所以 `{text}(?: → {dest})` 按最后一个 ` → ` 分开。
- **用时**：读一项的时间随这一项的长度线性增长，不论声明的 `pattern` 和 `none` 怎么写（D-153）；所以项目声明的正则不会让 `canon check`、`canon show` 这些读文档的命令卡住，一项也不会因为匹配步数太多被引擎放弃、当成对不上。
- **结果**：对上的项得到每个槽位的值，没出现的可省略段里的槽位没有值；没有值的槽位声明了 `required: true` 时，这一项记为缺少这个槽位。元信息槽位都在可省略段里（BR-2546），它的值不符合类型时，这一段就算没出现。可省略段外的原样文字没出现、整项对不上模板时，这一项记为未知，带上原文和原因（哪段原样文字没出现）。canon 不按别的写法去猜。

## 例子

- 教训声明 `{text}(?: → {dest})`，项 `- 子进程拿不到改过的环境 → BR-2101` → text `子进程拿不到改过的环境`，dest `BR-2101`
- 同上，项 `- A → B 时要先 C → 只靠文字：一次性` → text `A → B 时要先 C`，dest `只靠文字：一次性`
- 同上，项 `- 没写去向的一句话` → text 是整句，dest 没有值；dest 声明了 `required: true` → 这一项记为缺少 dest
- 方案声明 `(?:[{verdict}] ){text}`，`verdict` 是 `enum` 的采用、否决，项 `- [不采用] 太慢` → 可省略段对不上，按没有它来读：text 是 `[不采用] 太慢`，verdict 没有值
- 例子声明 `(?:[{example}] ){text}`，`example` 是 `pattern: "e\\d+"`，项 `- [e3] 输入 → 结果` → example `e3`，text `输入 → 结果`；项 `- 输入 → 结果` → text `输入 → 结果`，example 没有值
- 项目类型声明 `{topic}：{text}`，两个都是文字槽位，项 `- 没有冒号的一句` → 未知，原因写明模板里的 `：` 没出现
- `- 第一句` 下面一行 `  接着说` → 一项，文字 `第一句 接着说`
- 段落里只有 `<每条一行：…>` 这样的占位行 → 没有项
- 声明 `none: "^无$"`，段落里只有一行 `无` → 没有项；段落里是 `无` 和 `- 另一条` 两项 → 两项都按模板读
- 声明 `(?:[{tag}] ){text}`，`tag` 是 `pattern: "(a+)+"`，段落里 50 项，每项是 `[`、40 个 `a`、`!] x` → 5 秒内读完（Bun 自带的回溯引擎要一分钟左右），每项 tag 没有值，text 是整项
- 同上，`tag` 是 `pattern: "(a+)+|a+!"`，项 `[`、40 个 `a`、`!] x` → tag 是 40 个 `a` 加 `!`，text `x`（回溯的引擎会在第一个分支里耗尽步数，把它当成对不上）
- 第一个声明加上 `none: "^(?:(a+)+|a+!)$"`，`tag` 换成 `pattern: "b"`，段落里只有一项：40 个 `a` 加 `!` → 符合 none，这一段没有项（回溯的引擎会耗尽步数，当成不符合）；这一项换成 40 个 `a` 加 `?` → 不符合 none，按模板读出这一项（tag 没有值，text 是整项）
