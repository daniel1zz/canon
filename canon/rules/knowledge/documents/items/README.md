# 段落项的元信息（knowledge/documents/items）

文档类型给自己的段落声明“每一项长什么样”，canon 按声明读出每一项里的元信息（D-144）。正文照旧是自然语言，只有程序要判断的那一小块（方案是采用还是否决、教训去哪儿、例子的编号、成功标准的状态）按声明的固定写法写在固定位置。

管：声明怎么写、写错怎样失败，按声明怎么读出每一项，读不出时怎样报告，读出的结果怎样导出；规则的行为哈希怎样跳过元信息由 `knowledge/documents` 的 BR-2236 管。不管：每种内置类型具体声明了什么，以及谁用这些元信息（总览、`canon check` 的其他检查、评审），那些在用它的领域里写。

## 术语

- **项的声明**：某个文档类型的某个段落里，每一项的格式模板和每个槽位的类型，以及读不出时怎样处理。
- **槽位**：模板里用 `{名字}` 标出、读的时候取出来的一段文字。
- **文字槽位**：类型是 `text` 的槽位，是正文；其他类型的槽位是元信息。
- **可省略段**：模板里用 `(?:` 和 `)` 包住的一段，这一项里可以整段没有；元信息槽位都写在可省略段里。
- **未知的项**：模板对不上，或者槽位的值不符合类型的项。

## 业务

- **声明项的格式**：文档类型怎样声明段落里每一项的格式，声明写错时怎样失败。
- **读出元信息**：按声明读出每一项的槽位，读不出时怎样记、怎样报告，读出的结果怎样导出。
