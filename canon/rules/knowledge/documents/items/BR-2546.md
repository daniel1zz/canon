## 规则

文档类型可以在 `items` 下按段落名（不带 `## `）声明这一段每一项的格式（D-144）：

- `format`：模板，由原样出现的文字、槽位 `{名字}` 和可省略段 `(?:…)` 组成；可省略段不能嵌套。
- `slots`：模板里每个槽位的类型：`text`（非空的任意文字）、`id`（一个文档编号，如 `BR-12`）、`ids`（用 `,`、`，` 或 `、` 隔开的一个或多个文档编号）、`enum`（`values` 里的一个值）、`pattern`（整段符合 `pattern` 给的正则）；元信息槽位可以加 `required: true`，表示这一项必须写它。
- `children`：可选，缩进子项的声明，写法同上（`format`、`slots`），不能再有 `children`。
- `on_mismatch`：读不出的项怎样处理，`note`（提示）或 `finding`（报告），默认 `note`（BR-2549）。
- `none`：可选，一个正则：一段里只有一项、而且整项符合它时，这一段没有项（例如教训只写 `无`，BR-2547）。

`pattern` 和 `none` 按 RE2 的语法写（D-153）：canon 用不回溯的引擎匹配它们，任何写法都不会让读文档的命令卡住（BR-2547），代价是不能用向前或向后查找（`(?=`、`(?!`、`(?<=`、`(?<!`）和反向引用（`\1`），码位写成 `\x{4e00}` 而不是 `\u4e00`，`\s`、`\S`、`\d`、`\w` 只认 ASCII 字符。

文字槽位是正文，必须写在可省略段外面；其他类型的槽位是元信息，必须写在可省略段里面，而且一个可省略段里不能有文字槽位。内置类型的声明写在 canon 里；项目在 `canon/config.yaml` 的 `types.<类型>.items` 里给自己声明的类型写，也可以给内置类型还没有声明的段落写。

下面任何一种都是配置错误，所有命令按 BR-2045 以退出码 2 失败，错误写明类型、段落和原因：模板里的槽位没在 `slots` 里，或 `slots` 里的槽位模板里没有；同一个槽位出现两次；两个槽位之间没有文字隔开；可省略段嵌套或没有闭合；文字槽位在可省略段里，或元信息槽位在可省略段外；类型不认识；`enum` 没有 `values`；`pattern` 或 `none` 不是合法的 RE2 正则（信息还写出这个正则的原文和 RE2 给的原因）；`required` 用在文字槽位上；`on_mismatch` 不是 `note` 或 `finding`；给内置类型已经声明过的段落再声明。

## 例子

- 项目类型 `adr` 声明 `items: {教训: {format: "{text}(?: → {dest})", slots: {text: text, dest: text}}}` → 配置错误，`dest` 是文字槽位却写在可省略段里
- 项目类型 `adr` 声明 `items: {选项: {format: "(?:[{verdict}] ){text}", slots: {verdict: {enum: [采用, 否决], required: true}, text: text}}}` → 配置有效
- 同上，`format` 写成 `"{verdict}{text}"` → 配置错误，两个槽位之间没有文字，而且 `verdict` 写在可省略段外
- `slots` 里有 `id: {pattern: "S\\d+("}` → 配置错误，正则不合法
- `slots` 里有 `id: {pattern: "(?=S)S\\d+"}` → 配置错误，退出码 2，信息含 `canon/config.yaml`、`types.adr.items.教训.slots.id.pattern`、`"(?=S)S\\d+"` 和 RE2 不支持 `(?=` 的原因
- `none: "^(无)\\1$"` → 配置错误，信息含 `types.adr.items.教训.none` 和正则原文，反向引用 RE2 不支持
- `slots` 里有 `tag: {pattern: "(a+)+"}` → 配置有效：这种写法在回溯引擎里会卡住，在 canon 用的引擎里不会（BR-2547）
- `on_mismatch: warn` → 配置错误
- 内置的变更已经声明了 `教训` 的项（BR-2551），项目在 `types: {change: {items: {教训: …}}}` 里再写 → 配置错误；项目给变更的 `陷阱和假设` 段写声明 → 有效
