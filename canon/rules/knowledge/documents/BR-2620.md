## 规则

新建文档的命令（`canon rule new`、`canon decision new`、`canon change new`、`canon work start --title`、`canon note new`、`canon release new`、`canon feature new`、`canon quality new`、`canon doc new`）都接受 `--set <字段>=<值>`（可以写多次，列表值用逗号隔开），内置字段另有同名参数（BR-2623 列出，例如 `--owner-gate`、`--advances`、`--business`、`--amends`）。类型声明了 `due: create` 的字段（BR-2619），命令没拿到、或值不符合声明的格式时，以退出码 2 失败，不分配编号、不建文件、不建分支，信息写明缺哪个字段、参数怎么写、允许的格式（`none` 字段写明可以写 `none: <理由>`）；规则的 `business` 另列出它的领域 README 里的业务（D-159）。拿到的值照原样写进 front matter。`--set` 给了类型没声明的字段，或同一个字段给了两次，也是退出码 2。可选字段可以给也可以不给，给了就按声明校验。

## 例子

- `canon work start --title "x"` 没给 `--owner-gate` → 退出码 2，没有新编号，信息写 `--owner-gate "<what the owner approves>"` 或 `--owner-gate "none: <reason>"`
- `canon work start --title "x" --owner-gate "none: 内部工具" --advances "none: 修 bug"` → 照常开工，front matter 有这两项
- `canon rule new --domain work/land --title "x"` 没给 `--business` → 退出码 2，列出 work/land 的业务
- `canon rule new … --business "不存在的业务"` → 退出码 2，同上列出
- `canon decision new --title "x" --amends "none: 新的选择"` → 照常
- `--owner-gate "none:"`（理由空）→ 退出码 2
- `--set reviewer=x` 给了没声明的字段 → 退出码 2
