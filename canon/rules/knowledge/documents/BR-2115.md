---
id: BR-2115
title: canon rule domain 建领域：子领域要建在已有领域下，只有没有 code_root 的顶层领域写 --code
status: active
---

## 规则

`canon rule domain <名字>` 建出 `canon/rules/<名字>/README.md`。名字的每一段都只能是小写字母、数字和连字符，否则退出码 2。`<领域>/<子领域>` 只在外层领域已经存在时建出，外层领域不存在时以退出码 3 拒绝，什么也不建。只有没有配置 `code_root` 时的顶层领域写 `--code <路径>`，并且必须写；子领域给了 `--code`、配置了 `code_root` 时给了 `--code`、没有 `code_root` 的顶层领域没给 `--code`，都以退出码 2 拒绝，什么也不建。不带 `--code` 建出的 README 没有 front matter（BR-2117）。

## 例子

- 没有 `code_root`，执行 `canon rule domain billing --code src/billing` → 建出 README，front matter 是 `code: [src/billing]`
- 没有 `code_root`，执行 `canon rule domain billing` → 退出码 2
- billing 已存在，执行 `canon rule domain billing/refunds` → 建出 `canon/rules/billing/refunds/README.md`，没有 front matter
- billing 已存在，执行 `canon rule domain billing/refunds --code src/billing/refund.ts` → 退出码 2，没有新文件
- 没有 billing，执行 `canon rule domain billing/refunds` → 退出码 3，没有新文件
- `code_root: src`，执行 `canon rule domain billing` → 建出 README，提示代码目录是 `src/billing`；加 `--code src/billing` → 退出码 2
- 执行 `canon rule domain Billing/x` → 退出码 2
