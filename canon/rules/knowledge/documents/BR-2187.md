## 规则

`canon rule new`、`canon decision new`、`canon change new`、`canon note new`、`canon doc new` 的 `--title` 去掉首尾空白后为空时，退出码 2，不分配编号，不写文件。要写的文件已经存在时（例如 `canon work start` 给定的编号和标题对应的文件已经在了），退出码 5，已有的文件不改动。

## 例子

- `canon note new --title "   "` → 退出码 2，`canon/notes/` 下没有新文件
- `canon note new --title "Refunds"` → 退出码 0，建出 `canon/notes/N-1-refunds.md`
- 已有 `canon/decisions/D-1-x.md`，用给定编号 `D-1`、标题 `x` 再建一次 → 退出码 5，原文件内容不变
