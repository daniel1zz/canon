title: canon doc status 只接受声明的状态
status: active
---

## 规则

`canon doc status <编号> <状态>` 把声明类型的文档改成给出的状态；状态不在这个类型声明的 `statuses` 里时退出码 2，文件不变；编号不是声明类型的文档时退出码 3。

## 例子

- `canon doc status SP-1 approved` → `SP-1` 的状态变为 approved
- `canon doc status SP-1 done` → 退出码 2，`SP-1` 不变
- `canon doc status C-1 done` → 退出码 3
