## 规则

`canon work start` 建好或接手 worktree、提交变更文件、拿到认领之后，在这个 worktree 里依次运行 `hooks.after_start` 的命令，环境变量有 `CANON_EVENT=after_start`、`CANON_CHANGE`、`CANON_WORKTREE`、`CANON_BRANCH`、`CANON_ACTOR`，输出打印出来。命令退出码非 0 时打印提示，开始仍然成功，worktree 和认领都保留。

## 例子

- `after_start: 'echo "$CANON_CHANGE" > started.txt'`，执行 `canon work start --title X` → worktree 里的 `started.txt` 内容是 `C-1`
- `after_start: "exit 4"` → 开始仍然成功，`C-1` 仍被认领
