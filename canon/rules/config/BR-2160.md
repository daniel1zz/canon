## 规则

`canon/config.yaml` 可以写 `test_command`：运行一个测试文件的 shell 命令，必须含 `{file}`，运行时换成测试文件的路径（加单引号转义）。`test_command` 不是字符串、不含 `{file}`，或者以路径开头而那个文件不存在时，所有命令都以退出码 2 失败（BR-2045）。没写 `test_command` 时，别的命令照常执行，`canon work test` 以退出码 2 失败，提示要写这一项并给出例子，不猜测项目用什么测试工具。

## 例子

- `test_command: "bun test {file}"` → 选出 `src/a.test.ts` 时运行 `bun test 'src/a.test.ts'`
- `test_command: "npx vitest run {file}"` → 照常执行
- `test_command: "bun test"` → 所有命令退出码 2，提示必须含 `{file}`
- `test_command: 3` → 退出码 2
- `test_command: "scripts/missing.sh {file}"`，文件不存在 → 退出码 2
- 没写 `test_command` → `canon check` 照常，`canon work test` 退出码 2，提示写 `test_command: "bun test {file}"` 这样的一项
