title: 声明类型的文档状态必须是声明的状态之一
status: active
---

## 规则

声明类型的文档 front matter 里的 `status` 不在这个类型声明的 `statuses` 里时，`canon check` 报 `file-invalid`。`canon doc status <编号> <状态>` 只接受声明的状态，否则退出码 2，文件不变。

## 例子

- `spec` 只声明了 draft、approved，`SP-1` 写着 `status: done` → 报 `file-invalid`
- `canon doc status SP-1 approved` → `SP-1` 的状态变为 approved
- `canon doc status SP-1 done` → 退出码 2，`SP-1` 不变
