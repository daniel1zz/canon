title: 后台的 after_land 命令各在自己的子 shell 里运行，互不影响
status: active
---

## 规则

一次合入在后台运行的那批 `after_land` 命令（BR-2030）由同一个 `sh` 依次运行，每条命令放在自己的子 shell 里：前一条命令改变的工作目录、设的 shell 变量、调用的 `exit` 都不带到后一条，后一条照样从主 checkout 开始运行。每条命令的标准输出和标准错误按写出的顺序写进这批的日志，命令结束后紧接着写一行 `[hook <序号>/<总数> exited <退出码>]`（序号从 1 开始）。前一条失败不影响后一条运行。

## 例子

- 两条命令 `cd / && X=1 && exit 3` 和 `pwd; echo "x=$X"` → 第一条退出码 3；第二条照样运行，输出主 checkout 的路径和 `x=`，退出码 0
- 两条命令 `echo one` 和 `echo two >&2` → 日志依次是 `one`、`[hook 1/2 exited 0]`、`two`、`[hook 2/2 exited 0]`
