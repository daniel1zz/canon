## 规则

`canon doc list --type <名字>` 按编号列出这个声明类型的全部文档（编号、状态、标题），不按状态过滤；加 `--json` 时输出 JSON。`--type` 没给，或者不是一个声明的类型（包括内置类型）时退出码 2。

## 例子

- 声明了 `spec`，有 draft 的 `SP-1` 和 approved 的 `SP-2` → 两条都列出
- `canon doc list --type rule` → 退出码 2，提示用 `canon rule list`
- 没有声明任何类型时 `canon doc list --type spec` → 退出码 2
