## 规则

`canon doc list --type <名字>` 按编号列出这个声明类型的全部文档（编号、状态、标题），不按状态过滤。`--type` 找不到对应的类型时退出码 3（和 `canon doc new` 一致）；没给 `--type`，或给的是内置类型时退出码 2，并提示对应的命令。

## 例子

- 声明了 `spec`，有 draft 的 `SP-1` 和 approved 的 `SP-2` → 两条都列出
- 没有声明任何类型时 `canon doc list --type spec` → 退出码 3
- `canon doc list --type rule` → 退出码 2，提示用 `canon rule list`
