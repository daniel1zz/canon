---
id: BR-2045
title: 配置写错时所有命令都以退出码 2 失败
status: active
---

## 规则

`canon/config.yaml` 有下列任何一种错误时，所有 `canon` 命令都不执行，以退出码 2 失败，并指出出错的 key：不是合法的 YAML 或不是 mapping；有未知的 key（包括已经挪走的顶层 `after_land`，提示改成 `hooks.after_land`）；值的类型不对，或数值不大于 0；命令以路径开头（含 `/`）而这个文件不存在；`canon/templates/` 里有一个不对应任何文档类型的模板；类型声明不合法（名字、前缀或目录格式不对或和别的类型重复、默认状态不在状态列表里、给内置类型声明了 `fields` 和 `sections` 以外的 key、`fields` 用了 canon 自己的字段名、`sections` 不合法（见 BR-2092））；`code_root` 或 `shared` 不合法（见 BR-2116）。没有 `canon/config.yaml` 时全部用默认值。

## 例子

- 写成 `claim_lease_hour: 12`（拼错）→ `canon show C-1` 退出码 2，提示 unknown key
- 顶层写 `after_land: "bun run build"` → 退出码 2，提示改成 `hooks.after_land`
- `review: scripts/missing.sh`，文件不存在 → 退出码 2
- `review: claude -p` → 不检查 PATH，命令照常执行
- 有 `canon/templates/spec.md`，但没有声明 `spec` 类型 → 退出码 2
- `types: {rule: {prefix: R}}` → 退出码 2
- `claim_lease_hours: 0` → 退出码 2
- 没有 `canon/config.yaml` → 命令照常执行，用默认值
