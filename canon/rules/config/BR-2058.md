## 规则

`canon work stop` 记录 handoff（加了 `--release` 时也释放认领）之后，在当前 worktree 里依次运行 `hooks.after_stop` 的命令，环境变量有 `CANON_EVENT=after_stop`、`CANON_CHANGE`、`CANON_NEXT`（记录的下一步）。某条命令退出码非 0 时，后面的命令照样运行；退出码不影响 stop 的结果。

## 例子

- `after_stop: 'echo "$CANON_NEXT" > next.txt'`，执行 `canon work stop --next "land it"` → `next.txt` 内容是 `land it`
- `after_stop` 是两条命令 `exit 9` 和 `echo "$CANON_NEXT" > next.txt` → 第二条照样运行，stop 仍然成功，handoff 已记录
