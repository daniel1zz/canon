## 规则

`canon config` 按固定顺序列出 canon 认识的每个配置项，一项一段：第一行是键名和值，下面一行是说明。这个 checkout 的 `canon/config.yaml` 里写了这个键时，值是文件里写的值（JSON 写法）；没写时，有默认值的显示默认值并标 `(default)`，没有默认值的显示 `(unset)`。默认值用文件里的写法和单位（`claim_lease_hours` 是小时数，不是毫秒）。输出第一行写明读的是哪个文件，并说明改它要走合入。`canon/config.yaml` 第一行没有指向 schema 的 modeline 时，最后一行提示加哪一行注释。加 `--json` 时输出数组，每项含 `key`、`set`、`value`、`default`、`doc`。配置写错时和别的命令一样以退出码 2 失败（BR-2045），所以退出码 0 也说明当前配置能被读通。

## 例子

- 配置里写了 `floor: "bun test"`，没写 `claim_lease_hours` → 有一行 `floor = "bun test"`，有一行 `claim_lease_hours = 12 (default)`，退出码 0
- 没写 `floor` → `floor = (unset)`
- 写了 `land_batch_max: 4` → `land_batch_max = 4`，不带 `(default)`
- `--json` → `claim_lease_hours` 那项是 `{"key":"claim_lease_hours","set":false,"value":null,"default":12,...}`
- 配置里有未知键 `bogus: 1` → 退出码 2，错误写明 `unknown key`
- `canon/config.yaml` 第一行是 `# yaml-language-server: $schema=../.canon/config.schema.json` → 不输出 modeline 提示；没有这行 → 最后一行提示加它
