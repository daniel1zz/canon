## 规则

`canon guide` 不带参数时，每个主题输出一行：主题名，加上什么时候该读它；最后一行是 `read one: canon guide <topic>`。`canon guide <主题>` 输出这个主题的全文。不存在的主题报错，退出码 3，信息列出所有主题名。主题写在 canon 程序里，和 `canon brief` 的工作说明（BR-2090）同一个来源，两个主题重名是 canon 的 bug。

主题放的是只在某个时刻才用得上的细节；工作说明里对应的那一行写明那个时刻和 `canon guide <主题>`。会让 main 出错或丢数据的约束不挪进主题，留在工作说明里（D-169）。

## 例子

- `canon guide` → 每行一个主题和它的时机，比如 `land` 那一行写着合入时等待、设优先级、合入后跟进；最后一行 `read one: canon guide <topic>`
- `canon guide land` → 合入等待、优先级和 `canon work after-land --wait <C-n>` 的全文
- `canon guide nope` → 退出码 3，信息列出 evidence、findings、human 等全部主题名
- 工作说明里合入那一行 → 写着 `canon guide land`，不再写合入等待和优先级的细节
