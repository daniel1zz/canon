## 规则

`canon <命令…> --help` 输出到 stdout、退出码 0，用法行和“更多信息”一行里的程序名是 `canon` 加上命名这个命令的那些词，不论 canon 是编译后的二进制还是用 `bun src/invocation/main.ts` 运行；不出现可执行文件或脚本的路径。

## 例子

- `canon rule --help` → 用法行是 `USAGE canon rule new|list|retire|domain|domains`，并有 `Use canon rule <command> --help`；没有 `/$bunfs/` 或 `main.ts`
- `canon rule new --help` → 用法行以 `USAGE canon rule new` 开头
- `canon --help` → 用法行以 `USAGE canon init|` 开头
