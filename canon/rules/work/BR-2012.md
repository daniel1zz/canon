---
id: BR-2012
title: 开始一个变更时，它会得到自己的 worktree、分支、变更文件和认领
status: active
---
`canon work start --title <标题>` 分配变更编号，在主 checkout 旁边的 `<checkout>.worktrees/<C-n>`（在所有 checkout 之外）基于 main 建新分支 `change/<C-n>-<slug>`（标题里有非 ASCII 字符时为 `change/<C-n>`），在那里提交变更文件，并让这个 worktree 认领该变更。`canon work start <C-n>` 对 main 上已有的未完成变更做同样的事。
