## 规则

`canon work start --title <标题>` 分配变更编号，在 worktree 目录（BR-2047）下的 `<C-n>` 基于 main 建新分支 `change/<C-n>-<slug>`（标题含非 ASCII 字符时为 `change/<C-n>`），在那里提交变更文件，并由这个 worktree 认领该变更。

## 例子

- 在 `~/p/app` 执行 `canon work start --title "Refund window"` → 建出 `~/p/app.worktrees/C-1`，分支 `change/C-1-refund-window`，变更文件已提交，`C-1` 被它认领
- 标题为 `中文变更` → 分支 `change/C-2`
