## 规则

`canon check` 看 `canon/proposals/` 下每个变更目录（BR-2524）：目录里有 `.md` 文件，而这个编号的变更在当前树上不是 `open`（已完成、放弃，或者没有这个变更）时，对这个目录报 `proposal-unapplied`，信息写明变更编号、它的状态和没套用的规则编号，提示设计负责人 `canon rule apply <C-n>` 或删掉（D-135）。`open` 的变更的提议是正常的，不报。

## 例子

- `canon/proposals/C-1/BR-1.md` 存在，`C-1` 是 `open` → 不报
- 同上，`C-1` 是 `done` → 报 `proposal-unapplied`，信息是 `C-1 is done but still has rule proposals not applied: BR-1; its design owner applies them (canon rule apply C-1) or deletes them`
