## 规则

`canon work delegate <C-n>` 成功之后，`C-n` 的 `rules:` 里每个带 `will_amend` 的计划中的规则，对它要修订、而 main 上的文字还没有提到这条计划中的规则的每条规则（新文字还没写），输出一行：`design not settled: <BR-p> will amend <BR-t>, whose text does not name <BR-p> yet`，并写明 worker 不能改这条规则的文字（D-128），实现时会交回由设计负责人应用（BR-2524），所以也可以由主会话自己做这个变更（D-156）。只是提醒：派发照常成功、退出码不变。没有这样的规则时不输出。

## 例子

- `C-662` 的 `BR-2604` 要修订 `BR-2148`，main 上的 `BR-2148` 没提到 `BR-2604` → 一行 `design not settled: BR-2604 will amend BR-2148, …`；派发照常
- 设计负责人已经把 `BR-2148` 的新文字发布到 main，文字里提到 `BR-2604` → 不输出
- 开工（`canon work start`）→ 不输出这一种
- `C-5` 的计划中的规则没有 `will_amend` → 不输出
