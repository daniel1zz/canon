## 规则

一个变更契约里的规则是它 `rules:` 列出的规则，加上其中计划中的规则 `will_amend` 列出的规则。`canon work start <C-n>` 和 `canon work delegate <C-n>` 成功之后，对每个正在进行、契约里的规则和 `C-n` 有交集的别的变更（有活着的认领，或派发还在，且没关闭），在标准错误写一行：`C-n shares <规则…> with <C-m> (<谁在做>)`，并写明后合入的那个可能要按先合入的文字返工：可以排成先后（`depends_on`），或者由一个会话一起做（D-156）。只是提醒：退出码、认领和派发都不因此改变。没有交集时不输出。

## 例子

- `C-661` 的契约有 `BR-2527`，正在做的 `C-662` 的契约也有 `BR-2527`；派 `C-661` → 一行写共用 `BR-2527`、`C-662` 由谁在做；派发照常成功
- `C-5` 和已经关闭的 `C-3` 共用 `BR-9` → 不输出
- 没有交集 → 不输出
