## 规则

`canon change list` 每个没关闭的变更都写出档位（`P0` 到 `P3`）；不是默认 `P2` 的，再写谁定的（`owner` 或 `main agent`）。`--json` 里每个变更有 `priority`（档位）和 `priority_by`（`owner`、`main-agent`、`fix-main` 或 `null`）。`canon work status` 在 `Priorities:` 一节列出每个不是默认档位、还没关闭的变更：档位、谁定的、什么时候、理由或原话；没有时没有这一节。已经合入或放弃的变更的档位不再列出，也不起任何作用（D-155）。

## 例子

- `C-5` 是主 agent 定的 `P1` → `canon change list` 那一行有 `P1 main agent`；`canon work status` 的 `Priorities:` 有它和理由
- `C-6` 没设过 → `canon change list` 写 `P2`，`Priorities:` 里没有它
- 修复 main 的变更 `C-9` → 写 `P0 fix-main`
- `C-5` 合入了 → 两处都不再列它的档位
