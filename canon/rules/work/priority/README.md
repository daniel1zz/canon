# work/priority

变更的优先级：每个变更在 `P0` 到 `P3` 里的档位，谁能设、存在哪、怎样显示（D-155）。档位怎样影响开工顺序、合入顺序和打断，写在 `knowledge/changes`、`work/land/queue` 和 `work/reminders` 各自的规则里；这里不管那些顺序本身。

## 术语

- **档位**：`P0` 必须立刻做、`P1` 紧急、`P2` 普通（默认）、`P3` 有空再做。
- **谁定的**：负责人（经 `--relayed` 转述）、主 agent（带 `--reason`），或修复 main 的变更自带的 `P0`。

## 业务

- **设定档位**：谁能把变更设成哪一档、什么时候被拒绝、负责人定的怎样压过主 agent。
- **看到档位**：列表和状态里怎样写出档位和谁定的。
