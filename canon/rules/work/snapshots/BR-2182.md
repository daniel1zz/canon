title: Bash 调用前，canon snapshot take 把 worktree 未提交的工作存成快照

## 规则

`canon snapshot take` 对当前目录所在的 git worktree 做快照；带 `--hook` 时从标准输入读 Claude Code 的 PreToolUse 输入，对其中 `cwd` 所在的 worktree 做（读不出 `cwd` 时用当前目录），并且对同一个仓库里认领表中持有者是本会话的其他 worktree 也做：持有者是 `agent:<会话>` 或它的子 agent `agent:<会话>:<名字>`，会话取输入里 `session_id` 的前 8 个字符（没有时取环境变量 `CLAUDE_CODE_SESSION_ID`）。这样 `cwd` 是会话的起始目录（常是主 checkout）、命令却 `cd` 进了 `canon work start` 建的 worktree 时，那个 worktree 的工作也有快照。别的会话认领的 worktree 不做；不看命令里写了什么目录；不带 `--hook` 时只做当前目录的那一个。每个 worktree 各自按下面的条件判断，没有改动的什么都不写。只在这个 worktree 是 canon 项目（根目录有 `canon/config.yaml`）、并且 `git status --porcelain` 不为空时才做；内容和这个 worktree 最近一个快照相同、或和 HEAD 相同时不新建。

快照包含跟踪文件的改动（包括删除）和没被 git 忽略的未跟踪文件；被忽略的文件不包含。改动过或未跟踪的文件大于 5 MB 时不放进快照（跟踪文件保留 HEAD 的版本），提交说明里写明留下了哪些。做快照不改 worktree 的文件，也不改它自己的索引：`git status` 前后一样，索引文件一个字节都不变，也不拿索引的锁（`.git/index.lock`），所以同时在这个 worktree 里运行的 git 命令不会因为锁被占而失败。

带 `--hook` 成功时什么都不输出、退出码 0；出错时退出码非 0、错误写到标准错误，hook 命令里的 `|| echo` 接着输出一条给用户看的 `systemMessage`（BR-2185），Bash 调用照常进行。不带 `--hook` 时输出一行：做了快照就写 ref，没做就写原因。

## 例子

- 改了跟踪文件 `a.txt`、新建了未跟踪的 `new.txt`、`.env` 被忽略 → 新快照里 `a.txt` 是改过的内容，有 `new.txt`，没有 `.env`；之后 `git status --porcelain` 和之前一样
- 快照之后 `git checkout a.txt` → `git show <ref>:a.txt` 仍是改过的内容
- 工作区干净 → 不新建快照，不带 `--hook` 时输出 `no snapshot: nothing uncommitted`
- 什么都没再改，又调用一次 → 不新建快照（`same as the last snapshot`）
- 删除了跟踪文件 `b.txt` → 快照里没有 `b.txt`
- 未跟踪的 `big.bin` 有 6 MB → 快照里没有它，提交说明有 `left out` 和 `big.bin`；`small.txt` 照常在快照里
- `--hook`，标准输入是 `{"cwd":"<另一个 worktree>"}` → 快照的是那个 worktree
- 跟踪文件 `app.txt` 内容没变、修改时间变了（索引里的 stat 信息过时），又有别的未提交改动 → 做完快照，`.git/index` 的内容和做之前完全一样
- `--hook`，`cwd` 是主 checkout，会话 `abcd1234…` 认领了 worktree `C-11`（持有者 `agent:abcd1234`）和 `C-12`（持有者 `agent:abcd1234:worker`），两个都有未提交改动 → 两个都有新快照
- 同上，另有认领的 `C-13` 没有改动 → `C-13` 没有新快照
- 同上，`C-21` 由会话 `ffff0000` 认领、有未提交改动 → 没有快照；持有者 `agent:abcd1234x`（只是前缀相同）的 `C-22` 也没有
- `--hook`，`cwd` 就是已认领的 worktree `C-31` → 它只做一个快照
- 不带 `--hook`，当前目录是主 checkout，别的 worktree 被本会话认领并有改动 → 只做主 checkout 的
- 目录不在 git 仓库里，或仓库里没有 `canon/config.yaml` → 不做快照，退出码 0
