## 规则

`canon snapshot list` 列出当前 worktree 的快照，最新的在前，每个一行：ref、创建时间、和当时 HEAD 相比改了哪些文件；留下了大文件的快照下一行写明留下了哪些。最后一行写找回文件的命令。没有快照时输出一行说明。加 `--json` 时输出数组，每项含 `ref`、`commit`、`tree`、`at`、`files`、`leftOut`。不在 git 仓库里时退出码 4。

## 例子

- 先改 `a.txt` 做一个快照，再改 `b.txt` 做一个 → 两行，第一行是 `b.txt` 那个（含 `a.txt` 和 `b.txt`），第二行只含 `a.txt`；最后一行有 `git show <ref>:<path>`
- 没有快照 → `no snapshots of <worktree 路径>`，退出码 0
- `--json` → 数组长度 2，第一项的 `files` 是 `["a.txt","b.txt"]`
