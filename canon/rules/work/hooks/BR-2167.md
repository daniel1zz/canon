## 规则

`canon work after-land --wait` 反复读这批命令的日志和同一次合入的合入后评审（BR-2166），直到每条命令都已结束、评审已完成或失败，或者日志不见了，或者等满超时，然后像 BR-2166 那样输出并给出退出码。有一条命令先失败时仍然等其余命令和评审结束。第一次读到哪一批、哪次评审，之后一直读它们：等待期间别的变更合入、出现了更新的一批，也不换过去。评审进程没有在运行时，它按 BR-2441 启动一个。超时默认 20 分钟，`--timeout <分钟>` 可以改，必须是正数；不加 `--wait` 时给 `--timeout` 是用法错误，退出码 2。等满超时仍有命令没结束或评审没完成时，退出码 75，并多输出一行，写明等了多少分钟、可以再运行一次 `--wait`。

## 例子

- 第一条命令 0.3 秒后以 0 结束 → `--wait` 等它结束后输出，退出码 0
- 第一条以 2 退出，第二条在 0.3 秒后以 0 结束 → 等到第二条结束才输出，两条都显示退出码，退出码 1
- 一条命令一直不结束，`--wait --timeout 0.01` → 约 0.6 秒后输出 `still running` 和 `still running after 0.01 min`，退出码 75
- `--timeout 0` 或 `--timeout abc` → 退出码 2
- 不加 `--wait`，`--timeout 5` → 退出码 2
- 不带变更编号等 `C-5` 那批时，`C-6` 合入并且它那批很快全部以 0 结束，之后 `C-5` 的命令以 1 退出 → 报告的是 `C-5` 那批，退出码 1
