id: BR-2064
title: 放弃一个不会丢工作的变更时直接删除它的 worktree 和分支
status: active
---

## 规则

`canon work drop <C-n>` 放弃一个变更正在进行的工作：删除它在 worktree 目录（BR-2047）下的 worktree、它的变更分支、认领和 handoff，写一条 `drop.done` 事件，退出码 0。只有在不会丢任何东西时才直接执行：分支上没有不在 main 上的提交，worktree 没有未提交的改动，也没有别的操作者持有有效的认领。变更文件的状态不改；它在 main 上仍是 open 时，提示用 `canon change drop` 标记。在要删除的 worktree 里执行时退出码 2；既没有 worktree 也没有分支时退出码 3。

## 例子

- `C-1` 已经全部合入，worktree 干净 → 直接删除 worktree 和分支，退出码 0
- 只剩分支 `change/C-2`，上面的提交都已在 main 上 → 删除分支，退出码 0
- 在 `C-1` 自己的 worktree 里执行 `canon work drop C-1` → 退出码 2
- `canon work drop C-99`，没有对应的 worktree 和分支 → 退出码 3
