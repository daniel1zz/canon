id: BR-2111
title: 合入时核对决策方案的来源
status: active
---

## 规则

合入时，在 `canon check` 之后、移动 main 之前核对决策的来源（拒绝原因 `source`）。本次新增的决策文件，`## 方案` 里至少要有一条来源。本次新增或改动的决策里，main 上同一决策还没有的每条来源都要核对：文件路径要在将成为 main 的那棵树里是一个文件，且内容包含摘录；网址要能打开（2xx），且页面去掉标签和脚本后的文字包含摘录；比较前把连续空白合并成一个空格。任何一条不成立都拒绝合入；网址打不开（超时、DNS 失败）也拒绝，因为没核对过的摘录不能进入 main。main 上已有的来源不重复核对。`canon check` 在这一步之前运行，没被取代的决策里不是文件的路径（BR-2110）和文件里没有摘录的来源（BR-2252）已经由它报出，这时拒绝原因是 `check`，不是 `source`。

## 例子

- 新决策 `D-9` 的方案里没有任何来源 → 拒绝，原因 `source`
- 来源 `src/a.ts “function refund(”`，文件里确实有这段 → 通过
- 已接受的新决策，来源 `src/a.ts “function refund(item)”`，文件里没有这段 → 拒绝，原因 `check`（`source-quote-missing`，BR-2252）
- 来源网址返回 404 → 拒绝
- 来源网址能打开，但页面里没有这段摘录 → 拒绝
- 只改了 `D-2` 某个方案的措辞，没有新增来源 → 不核对，也不要求来源
- 网络不通，本次没有新增来源 → 照常合入
