## 规则

**还没人修**指：有“main 没通过”的记录，自动撤回已经有了结果（BR-2601），还没有修复变更。这时 `canon brief`、`canon work land` 的结果（BR-2306）和 `canon work test`（BR-2600）对主会话的提示一律写成：看到这条的会话去开修复变更（`canon work start --fix-main`），手上有认领的变更也一样，先停下它（`canon work stop`）或派出去，修复合入后再回来（D-155）。在变更 worktree 里仍写明这些失败不是这个变更造成的、不要在这个变更里修，但不再暗示由别的会话去修。worker（BR-2468）收到的提示是把这件事告诉派它的主会话，不让它开修复变更（它不能新建变更）。

自动撤回还在定位或撤回时，提示写“正在自动撤回，先别开修复变更”，因为有修复变更时 BR-2535 不再定位。

## 例子

- main 没通过，自动撤回已经记了 `revert.skip`，没有修复变更，手上认领着 `C-5` 的主会话运行 `canon brief` → 提示里有 `canon work start --fix-main`，没有“没有认领变更的会话”这几个字
- 同样的情况，在 `C-5` 的 worktree 里 → 还写明这些失败不是 `C-5` 造成的，不要在 `C-5` 里修
- 自动撤回还没有结果 → 提示写正在自动撤回，没有 `--fix-main`
- worker 运行 `canon brief` → 提示让它告诉派它的主会话，没有 `--fix-main`
- 已经有修复变更 `C-9` → 提示写正在 `C-9` 里修，同 BR-2220
