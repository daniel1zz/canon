title: canon work status 和 canon brief 在有没测过的合入时显示个数和下一次测试的时间
status: active
---

## 规则

`floor_timing: after` 下 main 上有没测过的合入（BR-2311 数的那些）时，`canon work status` 和 `canon brief` 各输出一行 `main: N landing(s) not yet tested`，后面写下一次测试的时间：还没到点时是 `next run in ~M min, or when K more landings are in; \`canon floor watch --now\` runs it at once`（M 取到最早的到点时间的分钟数，向上取整，至少 1），已到点时是 `the test is due now: <原因>`。`canon work status --json` 的 `untested` 是这些行。没有没测过的合入、`floor_timing` 不是 `after`、或只剩 `floor_skip_paths` 能跳过的提交时不输出。

## 例子

- 基线已测，合入 3 个，现在是 main 最近一次移动后 5 分钟，quiet 20、max 10 → 两个命令都输出 `main: 3 landings not yet tested (next run in ~15 min, or when 7 more landings are in; ...)`
- 没有没测过的合入 → 两个命令都不出现 `not yet tested`
