id: BR-2062
title: 两个进行中的变更改了同一个文件时，开始和合入会提示
status: active
---

## 规则

`canon work start` 和 `canon work land` 把当前变更分支相对 main 改过的文件（`git diff --name-only main...<分支>`，只看已提交的改动）和 worktree 目录（BR-2047）下其他每个变更分支改过的文件对比；有重叠时，对每个重叠的变更打印一行提示（哪个变更、哪些文件），并写一条 `overlap.notice` 事件（时机、对方变更、文件）。提示不拦截任何操作，不改变退出码。

## 例子

- `C-1` 和 `C-2` 都提交了对 `src/a.ts` 的改动，`C-1` 合入 → 打印 `overlap: C-2 also changes src/a.ts`，事件表多一条 `overlap.notice`，合入照常进行
- `C-1` 改了 `src/a.ts`，`C-2` 改了 `src/b.ts` → 不提示
- `C-2` 对 `src/a.ts` 的改动还没提交 → 不提示
- 新建的变更还没有任何提交 → 开始时不提示
