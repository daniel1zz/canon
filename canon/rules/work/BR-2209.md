## 规则

需要协调数据库的命令打不开它（例如 git 公共目录下的 `canon` 是一个普通文件、建不了目录）时，以退出码 4（环境错误）失败，错误信息写明 `cannot open coordination DB at <路径>`，不做命令本来要做的事。

## 例子

- `.git/canon` 是一个普通文件 → `canon events` 退出码 4，stderr 含 `cannot open coordination DB at` 和 `.git/canon/state.db`，stdout 为空
- `.git/canon` 不存在 → 自动建出来，`canon events` 退出码 0
