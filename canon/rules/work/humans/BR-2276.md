status: active

## 规则

agent 用 `canon human answer <编号> <回答> --relayed "<原话>"` 记下转述的回答时（BR-2021），canon 找这个操作者（BR-2023）最近的一条 `human.asked` 事件（BR-2275；只有两边认出的操作者相同才对得上，比如记录时设置了 `CANON_ACTOR`、转述时没有设置，就对不上），只看最近的一条：原话去掉首尾空白后，和其中某个问题的回答、人自己打的回答或某条备注（各自去掉首尾空白）完全相同，就标为“和 Claude Code 的记录一致”，否则（包括没有这样的事件）标为“没有对应记录”。标记存进这个问题，也写进 `human.answer` 事件（`witness` 是 `match` 或 `none`）。不一致不拦截，回答照样记下，退出码 0。`canon human pending --all` 在转述的回答后面显示 ` [matches Claude Code's record]` 或 ` [no matching Claude Code record]`；人直接回答的、以及这条规则之前记下的回答不显示标记。

## 例子

- 会话 `agent:x` 最近的 `human.asked` 里 `Ship it?` 的回答是 `yes`，`agent:x` 执行 `canon human answer 1 yes --relayed " yes "` → 退出码 0，原话按 BR-2021 去掉首尾空白后保存和显示，`canon human pending --all` 显示 `→ yes (agent:x relaying the human: "yes") [matches Claude Code's record]`
- 同样的记录，`--relayed "好的，发吧"` → 退出码 0，显示 `[no matching Claude Code record]`
- `agent:x` 没有任何 `human.asked`，或只有 `agent:y` 的 → 标 `[no matching Claude Code record]`
- `agent:x` 先有一条回答是 `yes` 的记录，后来又有一条回答是 `no` 的，`--relayed "yes"` → 标 `[no matching Claude Code record]`（只看最近的一条）
- 记录里 `response` 是 `先别发`，`--relayed "先别发"` → 标 `[matches Claude Code's record]`
- 记录里的备注是 `周五再发`，`--relayed "周五再发"` → 标 `[matches Claude Code's record]`
- `human:dz` 在终端里直接回答 → 不对照，`canon human pending --all` 不显示标记
- 记录是在设置了 `CANON_ACTOR=agent:k` 的环境里写的（操作者 `agent:k`），转述的是 `agent:3d606482` → 标 `[no matching Claude Code record]`；转述时也是 `agent:k` → 按原话对照
