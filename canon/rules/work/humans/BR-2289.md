## 规则

`canon human pending --all` 在转述的回答那一行后面，按问题存下的对照结果（BR-2276）显示一段说明：

- `match` → ` [matches Claude Code's record]`
- `differs` → ` [differs from Claude Code's record of this question]`
- `record-failed` → ` [Claude Code's record failed in this session]`
- `unasked` → ` [this question is not in Claude Code's records of this session]`
- `no-hook` → ` [no Claude Code record: the record hook is not installed]`
- `no-record` → ` [no Claude Code record in this session]`
- `no-session` → ` [no Claude Code session to check against]`
- D-45 时期存下的 `none` → ` [no matching Claude Code record]`

人直接回答的、以及 D-45 之前记下的回答（没有对照结果）不显示任何说明。

## 例子

- 转述的回答对照结果是 `match` → 显示 `→ yes (agent:x relaying the human: "yes") [matches Claude Code's record]`
- 对照结果是 `differs` → 显示 ` [differs from Claude Code's record of this question]`
- 对照结果是 `no-session` → 显示 ` [no Claude Code session to check against]`
- 旧数据里对照结果是 `none` → 显示 ` [no matching Claude Code record]`
- `human:dz` 直接回答的 → `→ yes (human:dz)`，后面没有说明
