---
id: BR-2021
title: "给人的问题由人回答，或由 agent 转述人的原话并如实记录"
status: active
---
## 规则

`canon human answer <编号> <回答>` 有两种合法的回答方式：`human:` 操作者在交互式终端里直接回答；或者 agent 用 `--relayed "<人的原话>"` 转述人在它的会话里说的话，记录为转述（回答者是这个 agent，并保存原话）。其他情况都以退出码 2 拒绝，并写一条 `human.answer.refuse` 事件，原因各不相同（BR-2026）：`human:` 操作者带 `--relayed`（原话是空的也算带了）→ `human-relayed`；`human:` 操作者没有 TTY → `no-tty`；agent 不带 `--relayed`，或原话去掉首尾空白后是空的 → `not-human-no-relay`（agent 有没有 TTY 都一样）。`canon human pending --all` 把转述的回答显示成 `<agent> relaying the human: "<原话>"`，和人直接回答的区分开。这些检查在查找问题之前，所以回答方式不合法时，即使问题不存在或已经回答，也是退出码 2 和上面的原因，不是 3 或 5（BR-2040）。canon 不能从技术上分辨转述和编造，所以不假装能阻止，而是如实记录（D-6）。例外是问题带选项（`canon human ask --option`）时，agent 转述的回答按原话分两种情况检查，不满足的都以退出码 1 拒绝，不写入回答，写一条原因为 `option-mismatch` 的 `human.answer.refuse` 事件。选项本身不含逗号（`--option` 按逗号分开选项）。原话按半角逗号 `,` 分开后（全角逗号 `，` 不分；问题没有 `--multi` 时也这样分），没有不是选项的非空部分（每个不为空的部分都是某个选项，去掉首尾空白、不分大小写；原话只有逗号和空白时也算这一种），就算选项回答：记录的回答必须和原话是同一个选项，这样负责人在提问工具里选了 `no`，agent 就记不成 `yes`。原话里有不是任何选项的部分（人没选选项、自己打字回答，提问工具里的“Other”），就算自由回答：记录的回答必须和原话一字不差（只去掉首尾空白，区分大小写），agent 不能把人的话改写成某个选项；`canon human pending` 在这种回答后面标 `[not one of the options]`。问题没有选项时，回答和原话不比较（BR-2289 把两者并排显示）。问题用 `--multi` 提问（BR-2075）时，选项回答可以是一个或多个选项，用逗号分隔（提问工具记录多选的格式，如 `A, B`）：回答和原话各自的每一部分（去掉首尾空白、不分大小写）都必须是某个选项，不能重复，并且两边说的是同一组选项（顺序不限）；不满足就和上面一样以退出码 1 拒绝，不写入回答。原话里有不是选项的部分的，按上面的自由回答处理，不做这一段的检查。没有 `--multi` 的问题收到多个选项的回答，同样以退出码 1 拒绝、原因 `option-mismatch`，提示这个问题不是用 `--multi` 提的。原话仍按 BR-2276 和提问工具的记录比较。人在终端直接回答不受这条限制。已经回答过的问题仍是退出码 5（BR-2040）。

## 例子

- agent 会话（没有 TTY）执行 `canon human answer 1 yes` → 退出码 2，提示要么在终端回答，要么用 `--relayed`
- agent 执行 `canon human answer 1 yes --relayed "好的，发吧"` → 回答成功，显示 `→ yes (agent:x relaying the human: "好的，发吧")`
- `human:dz` 在终端里执行 `canon human answer 1 yes` → 回答成功，显示 `→ yes (human:dz)`
- `human:dz` 加了 `--relayed` → 退出码 2，原因 `human-relayed`
- `human:dz` 没有 TTY，执行 `canon human answer 1 yes --relayed ""` → 退出码 2，原因 `human-relayed`，问题仍然没有回答
- agent 没有 TTY，执行 `canon human answer 1 yes` → 退出码 2，事件表多一条原因为 `not-human-no-relay` 的 `human.answer.refuse`
- `human:dz` 没有 TTY，执行 `canon human answer 1 yes` → 退出码 2，原因 `no-tty`
- agent 不带 `--relayed` 回答一个已经回答过的问题 1 → 退出码 2，原因 `not-human-no-relay`，原来的回答不变
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 yes --relayed "yes"` → 回答成功
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 yes --relayed "no"` → 退出码 1，原因 `option-mismatch`，问题仍然没有回答
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 no --relayed "yes"` → 退出码 1，原因 `option-mismatch`
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 yes --relayed " YES "` → 回答成功（去掉首尾空白、不分大小写）
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 yes --relayed "好的，发吧"` → 退出码 1，原因 `option-mismatch`（原话是自由回答，回答必须就是原话）
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 "先等 C-428 合入再发" --relayed "先等 C-428 合入再发"` → 回答成功，`canon human pending --all` 在这个回答后面标 `[not one of the options]`
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 no --relayed "不发"` → 退出码 1，原因 `option-mismatch`（不能把自由回答改写成选项）
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 "Yes, Please" --relayed "yes, please"` → 退出码 1（自由回答区分大小写）
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 "yes，no" --relayed "yes，no"` → 回答成功，记成自由回答（全角逗号不分开）
- 问题带选项 `yes,no`，agent 执行 `canon human answer 1 "," --relayed ","` → 退出码 1，原因 `option-mismatch`（没有非空部分，算选项回答，又不是任何选项）
- 问题带选项 `yes,no`，`human:dz` 在终端里执行 `canon human answer 1 yes` → 回答成功，不受选项检查限制
- 问题带选项 `yes,no` 且已回答，agent 再用 `--relayed "no"` 回答 `yes` → 退出码 5，不是 1
- 问题用 `--multi` 带选项 `A,B,都不做`，agent 执行 `canon human answer 1 "A, B" --relayed "A, B"` → 回答成功，记录 `A, B`
- 同一个问题，agent 执行 `canon human answer 1 "B, A" --relayed "a,b"` → 回答成功（顺序不限、不分大小写）
- 同一个问题，agent 执行 `canon human answer 1 "A, C" --relayed "A, C"` → 回答成功，记成自由回答（C 不是选项，原话照录）
- 同一个问题，agent 执行 `canon human answer 1 "A, B" --relayed "A, C"` → 退出码 1，原因 `option-mismatch`（自由回答必须和原话一字不差）
- 同一个问题，agent 执行 `canon human answer 1 "A, " --relayed "A, "` → 退出码 1，原因 `option-mismatch`（不为空的部分都是选项，算选项回答，有一部分是空的）
- 同一个问题，agent 执行 `canon human answer 1 "A, B" --relayed "A"` → 退出码 1，原因 `option-mismatch`（两边不是同一组选项）
- 同一个问题，agent 执行 `canon human answer 1 "A, A" --relayed "A, A"` → 退出码 1，原因 `option-mismatch`（重复）
- 问题没有用 `--multi` 提问，带选项 `A,B`，agent 执行 `canon human answer 1 "A, B" --relayed "A, B"` → 退出码 1，原因 `option-mismatch`，提示这个问题不是用 `--multi` 提的
- 问题没有选项，agent 执行 `canon human answer 1 yes --relayed "好的，发吧"` → 回答成功，不做这个检查
