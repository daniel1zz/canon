## 规则

配置了 `code_root` 和 `shared` 时，`canon stats` 在最后多输出一行 `shared code: <共享行数> of <总行数> lines under <code_root> (<百分比>%)`：只算 git 跟踪的文件，共享行数是 `shared` 各项下文件的行数，总行数是 `code_root` 下全部文件的行数。一个文件的行数是它的换行符个数，最后一行没有换行符时再加一；空文件是 0 行；不区分文本和二进制文件。总行数是 0 时百分比按 0 算。共享代码没有任何领域的规则描述，比例超过 20% 时，这一行后面接着提示把只服务一个领域的代码挪进那个领域的目录。这只是提示，不影响任何检查和合入；`--json` 的输出不变。没有 `code_root` 或 `shared` 时没有这一行。

## 例子

- `src` 共 1000 行，`src/kernel` 150 行 → `shared code: 150 of 1000 lines under src (15.0%)`，没有提示
- `src/kernel` 200 行 → 20.0%，没有提示
- `src/kernel` 250 行 → 这一行后面接 `above 20%; move code that serves one domain into that domain's directory`
- 一个文件内容是 `a\nb`（最后没有换行）→ 算 2 行；空文件算 0 行
- `src` 下跟踪的文件都是空文件 → `shared code: 0 of 0 lines under src (0.0%)`
- 没有 `shared` → 没有这一行
