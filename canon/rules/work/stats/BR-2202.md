## 规则

`canon stats --json`（不加 `--since`）输出一个数组，按 `CHECKS` 的顺序每个检查一项（BR-2067），每项正好有这些字段：`check`（检查名）、`runs`、`refused`、`outcomes`（五种去向的次数，BR-2068）、`review`（复审日期，没有时为 null）、`due`（是否到期，BR-2069）、`kinds`（BR-2095）。没有任何事件时每项照样出现，次数都是 0。加 `--since` 时这个数组放在对象的 `checks` 里（BR-2155）。

## 例子

- 没有任何事件、没有 `check_reviews` → 数组的第一项是 `{"check":"on-main","runs":0,"refused":0,"outcomes":{"changed":0,"same":0,"abandoned":0,"pending":0,"unknown":0},"review":null,"due":false,"kinds":null}`，最后一项的 `check` 是 `setup`
- `check_reviews: {floor: "2026-01-01"}`，今天是 2026-11-03 → `floor` 那一项 `review` 是 `"2026-01-01"`、`due` 是 true；`check` 那一项 `review` 是 null、`due` 是 false
