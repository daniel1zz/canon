id: BR-2203
title: 认领和 setup 的拒绝不分去向
status: active
---

## 规则

去向（BR-2068）只对合入检查的拒绝有意义。认领（`claim`）和 setup（`setup`）的拒绝不分去向：表格里这两行的 changed、same、abandoned、pending、unknown 各列都是 `-`，`--json` 里它们的 `outcomes` 是 null，到期时“Due for review”下只写运行次数和拒绝次数（BR-2069）。合入检查即使没有拒绝，这几列也是数字 0，`outcomes` 是全为 0 的对象。

## 例子

- 认领被拒 1 次 → `claim` 那一行各去向列是 `-`，JSON 里 `outcomes` 是 null
- 没有任何 `floor` 拒绝 → `floor` 那一行各去向列是 `0`，JSON 里 `outcomes` 是 `{"changed":0,"same":0,"abandoned":0,"pending":0,"unknown":0}`
