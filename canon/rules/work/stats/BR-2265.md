## 规则

`canon usage` 读会话记录目录 `<配置目录>/projects`，配置目录是 `CLAUDE_CONFIG_DIR`（去掉首尾空白后有值时），否则是 `~/.claude`。只读其中属于本项目的子目录：名字等于主 checkout 路径的编码，或者以变更 worktree 目录（BR-2047）路径的编码加 `-` 开头，或者以 git 公共目录下 `canon` 目录路径的编码加 `-` 开头；路径的编码是把每个字母和数字以外的字符换成 `-`。在主 checkout 的子目录里启动的会话（目录名是主 checkout 的编码加 `-` 再加子目录）不读：编码后它和名字以主 checkout 名字加 `-` 开头的另一个项目分不开。读这些子目录里（包括更深的子目录）所有 `.jsonl` 文件的每一行；不是 JSON 的行跳过并计数。列出之后、读到之前被删掉的文件或目录（例如另一个会话启动时清理旧记录）跳过，不算进文件数，不报错；目录数是列出时找到的本项目目录数，之后被删掉的照样算在里面；列出时有本项目的目录、读的时候全被删掉了，退出码 0，文件数是 0。统计三种使用，每种按名字记次数和最近一次的时间（记录的 `timestamp`）：`type` 为 `assistant` 的记录里 `message.content` 中 `type` 为 `tool_use` 的块，`name` 为 `Skill` 时算 skill `input.skill` 用了一次，`name` 以 `mcp__` 开头时算 MCP 服务（`mcp__` 和下一个 `__` 之间的部分）用了一次，`name` 为 `Agent` 或 `Task` 时算子 agent 类型 `input.subagent_type`（没有时记为 `(unspecified)`）用了一次；`type` 为 `user` 的记录里的 `<command-name>/<名字></command-name>`，名字是可用 skill（BR-2266）或者被 `Skill` 调用过的 skill 时，算这个 skill 用了一次；可用清单随 `--days` 的窗口变化，所以同一条斜杠命令在不同的 `--days` 下可能算也可能不算。同一个 `tool_use` 的 `id`、同一条用户记录的 `uuid` 不管出现几次只算一次。输出写明读了几个目录、几个文件、跳过了几行，然后按种类列出每个名字的次数和最近一次时间，次数多的在前，次数相同按名字排；加 `--json` 时输出对象。一个属于本项目的子目录都没有时退出码 3，信息写明找的目录和编码后的名字。这个命令不写任何文件，不改任何配置。

## 例子

- 主 checkout 是 `/w/p`，`<配置目录>/projects/-w-p/s1.jsonl` 里有一次 `Skill`（`input.skill` 为 `canon-design`）→ `canon-design` 1 次，最近一次时间是那条记录的 `timestamp`
- 同一个 `tool_use`（同一个 `id`）出现在两行里 → 算 1 次
- `mcp__serena__find_symbol` 用了 2 次、`mcp__serena__read_file` 用了 1 次 → MCP 服务 `serena` 3 次
- `Agent` 的 `input` 没有 `subagent_type` → 记为 `(unspecified)`
- 用户记录里 `<command-name>/canon-design</command-name>`，`canon-design` 是可用 skill → 算一次；`<command-name>/model</command-name>` → 不算
- 50 天前输入的 `<command-name>/foo</command-name>`，`foo` 只在 50 天前的会话里注入过、从没被 `Skill` 调用过 → `--days 60` 时 `foo` 算 1 次，`--days 30` 时不算
- `-w-p-src/s5.jsonl`（在主 checkout 的 `src` 子目录里启动的会话）→ 不读
- `-w-p-worktrees-C-1/s2.jsonl`（变更 worktree 里的会话）和 `-w-p/s1/subagents/agent-x.jsonl` → 都读；`-w-px/s3.jsonl`（别的项目）→ 不读
- 一行不是 JSON → 跳过，输出里跳过的行数是 1
- 列出了 `s1.jsonl` 和 `s2.jsonl`，读 `s2.jsonl` 之前它被删掉了 → 退出码 0，文件数是 1；列出之后整个 `-w-p-worktrees-C-1` 目录被删掉 → 同样跳过，目录数仍是 2
- 只有 `-w-p` 一个目录，列出之后它被整个删掉 → 退出码 0，文件数是 0，目录数是 1
- 设置 `CLAUDE_CONFIG_DIR=/c` → 读 `/c/projects`
- `/c/projects` 下没有本项目的目录 → 退出码 3
- 运行前后会话记录目录里每个文件的内容和修改时间不变
