## 规则

`canon events` 列出协调数据库事件表里的事件，每条一行：编号、时间、执行者、worktree、事件种类、对象、详情（JSON），按编号从小到大，最新的在最后。可以加条件，几个条件同时满足才列出：

- `--since <n>`：只列编号大于 `n` 的；`n` 必须是 0 或正整数，否则以退出码 2 拒绝；不加时列出全部；
- `--kind <种类>`：只列这个种类，可以重复写，列出其中任一种类的事件；
- `--subject <对象>`：只列对象等于它的，例如一个变更编号。

加 `--json` 时输出这些事件的数组，每个元素有 `id`、`ts`、`actor`、`worktree`、`kind`、`subject`、`detail`，`detail` 是对象而不是字符串。没有符合条件的事件时输出 `(no events)`，`--json` 时输出空数组，退出码都是 0。

## 例子

- 事件 1 是 C-1 的 `land.turn`，2 是 C-2 的 `land.ok`，3 是 C-1 的 `land.ok` → `canon events --since 1 --kind land.ok` 列出 2、3 两行，2 在前
- 同样的事件，`--kind land.ok --kind land.turn --subject C-1` → 列出 1、3
- `--since 3` → 输出 `(no events)`，退出码 0
- `--since -1` 或 `--since abc` → 退出码 2
- `--json` → 第一个元素的 `detail` 是对象，例如 `{"entry": 7, "waited_ms": 1000}`
