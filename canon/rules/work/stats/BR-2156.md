## 规则

`canon events` 列出协调数据库事件表里的事件，每条一行：编号、时间、执行者、worktree、事件种类、对象、详情（JSON），没有 worktree 或对象的写 `-`，按编号从小到大，最新的在最后。可以加条件，几个条件同时满足才列出：

- `--since <n>`：只列编号大于 `n` 的；`n` 必须是 0 或正整数，否则以退出码 2 拒绝；不加时列出全部；
- `--kind <种类>`：只列这个种类；要几个种类就在一个 `--kind` 里用逗号隔开（`--kind land.ok,land.refuse`），列出其中任一种类的事件，逗号两边的空格不算，逗号之间的空项跳过（`--kind land.ok,` 等于 `--kind land.ok`）；`--kind` 写了两次按 BR-2382 拒绝；逗号隔开后一个种类也没有（`--kind ""`、`--kind ,`）以退出码 2 拒绝，不列出全部事件；
- `--subject <对象>`：只列对象等于它的，例如一个变更编号。

加 `--json` 时输出这些事件的数组，每个元素有 `id`、`ts`、`actor`、`worktree`、`kind`、`subject`、`detail`，`detail` 是对象而不是字符串。没有符合条件的事件时输出 `(no events)`，`--json` 时输出空数组，退出码都是 0。加 `--follow` 时不同，见 BR-2357。

## 例子

- 事件 1 是 C-1 的 `land.turn`，2 是 C-2 的 `land.ok`，3 是 C-1 的 `land.ok` → `canon events --since 1 --kind land.ok` 列出 2、3 两行，2 在前
- 同样的事件，`--kind land.ok,land.turn --subject C-1` → 列出 1、3
- 同样的事件，`--kind "land.ok, land.turn"` → 列出 1、2、3
- 同样的事件，`--kind land.ok,,` → 列出 2、3，和 `--kind land.ok` 一样
- `--kind ,` → 退出码 2，不列出全部事件
- `--since 3` → 输出 `(no events)`，退出码 0
- `--since -1` 或 `--since abc` → 退出码 2
- 一条没有 worktree（BR-2131 之前写的）也没有对象的事件 → 文字输出里这两列都是 `-`；`--json` 里是 null
- `--json` → 第一个元素的 `detail` 是对象，例如 `{"entry": 7, "waited_ms": 1000}`
