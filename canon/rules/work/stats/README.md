# 检查统计（work/stats）

`canon stats` 从事件表算出每个检查运行了多少次、拒绝了多少次、拒绝之后发生了什么，用来判断一个检查值不值得留（P6）；`canon check` 的拒绝按发现种类拆开。`canon stats --since <事件编号>` 只看某个编号之后的事件，并给出这段时间的并发摘要；`canon events` 列出原始事件。两者用来核对一次并发运行，不靠 agent 自己报的数字。

## 术语

- **去向**：一次拒绝之后的结果：改了再合入、原样合入、放弃、还没结果、无法判断。
- **复审日期**：每个检查需要重新判断是否保留的日期。
- **事件窗口**：编号大于某个事件编号的全部事件，`--since` 指定。
