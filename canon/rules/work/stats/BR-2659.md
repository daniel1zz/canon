## 规则

`canon stats`（带不带 `--since` 都一样，只数范围内的事件）在文字输出里加一节 `Duplicate reminders`，按阶段（`new`：新建时，BR-2656；`land`：合入时，BR-2657）各一行，从 `duplicate.remind` 和 `duplicate.answer` 事件（BR-2658）算出（D-171、P6）：

`  <阶段>: reminded <n> pair(s), answered <a> (same <s>, not <t>), unanswered <u>, precision <百分比>%, one side dropped since <d>`

- `<n>` 是范围内这一阶段提醒过的不同的变更对（不分先后）；
- 每一对的回应取它所有 `duplicate.answer` 里最新的一条（不限范围）；`<s>` 是最新回应是「是它」的对数，`<t>` 是「不是它」的，`<a> = <s> + <t>`，`<u> = <n> - <a>`；
- 准确率 = `<s> / <a>`，四舍五入到整数；`<a>` 为 0 时写 `precision -`；
- `<d>` 是这些对里现在有一方的主状态是 `dropped`（BR-2571）的对数。

范围内两个阶段都没有 `duplicate.remind` 时不输出这一节；某个阶段没有时不输出那一行。这一节只在文字输出里，`--json` 的字段不变（BR-2202）。

## 例子

- 新建时提醒了 4 对，回应 3 对：2 对是它、1 对不是 → `  new: reminded 4 pair(s), answered 3 (same 2, not 1), unanswered 1, precision 67%, one side dropped since 0`
- 同一对先答「不是它」后改答「是它」→ 算 `same`
- 合入时同一对被提醒过但从没回应 → `answered 0 (same 0, not 0), unanswered 1, precision -`
- 提醒过的一对里 `C-5` 后来被放弃了 → `one side dropped since 1`
- 范围内没有 `duplicate.remind` → 没有这一节
- `--json` → 和以前一样
