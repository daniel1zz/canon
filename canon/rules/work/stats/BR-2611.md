## 规则

`canon stats`（带 `--since` 时只看窗口内的事件）在文字输出里加一节 `Execution`，`--json` 里有同样内容的 `execution`：窗口内合入的变更按做法分三组——主会话自己做的（没有派发）、派出去由 worker 合入的、派出去后由主会话合入的（交回或收回过）——每组写变更数、从开工（自己做）或派发（派出去）到第一次合入的分钟数中位数、平均被拒次数、跑 `canon work test` 次数的中位数，以及代码改动行数的中位数（不算 `canon/` 下的文件），让主 agent 判断哪种做法更合适时有数据（D-156）。只算有开工或派发事件的变更；一组没有变更时写 0，不省略。

## 例子

- 窗口内 3 个自己做的、2 个 worker 合入的、1 个交回后主会话合入的 → `Execution` 三行，各写变更数、时长中位数、平均被拒次数、测试次数中位数、改动行数中位数
- 窗口内没有派出去的 → 后两组写 0
