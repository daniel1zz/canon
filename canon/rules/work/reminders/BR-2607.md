## 规则

主会话议程（BR-2527）里能开工的那一组（BR-2581 的可派一组，改为“能开工”），每个能开工的变更（BR-2571 的 `ready-delegatable` 或 `ready-self`）一项，按 BR-2604 的顺序，写出：

- 档位（BR-2603）；
- 两种做法：`canon work start <C-n>`（自己做）和 `canon work delegate <C-n> --to <名字>`（派出去）；不能派的（`ready-self`）只写第一种，并写明为什么不能派；
- 判断要用的事实：和正在进行的变更共用契约里的哪些规则（BR-2608），设计有没有没定的地方（BR-2609）。没有时不写。

这一组的标题写出机器还能派几个（BR-2526），并写明由主 agent 决定自己做还是派出去，canon 不给默认做法（D-156）。`canon work watch` 输出可开工的变更时用同样的写法（BR-2528）。

## 例子

- `C-5` 能派、`P2`、没有牵连 → 一项写 `P2`、`canon work start C-5` 和 `canon work delegate C-5 --to <名字>`，没有事实行
- `C-6` 和正在做的 `C-4` 都要改 `BR-12` → 这一项多一行写和 `C-4` 共用 `BR-12`
- `C-7` 是 `ready-self` → 只写 `canon work start C-7`，并写明不能派的原因
- 机器忙、不能再派 → 标题写忙，两种做法照样列出
