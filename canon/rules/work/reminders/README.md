# 提醒（work/reminders）

把会话现在该处理的事送到会话面前（D-136）。“该处理什么”只在一处算：待办清单。送达有三条路：长期运行的 `canon work watch`，宿主用 Monitor 之类的工具挂着它；`canon brief`；`canon work start`。这里的事只提醒，不挡任何工作。

不管：保证 main 正确的拒绝（work/land）、派发时的容量限制（work/delegation，BR-2526）、原始事件流 `canon events --follow`（work/stats，BR-2357）。

## 术语

- **待办**：调用者现在该处理的一件事，例如一条未处理的评审意见、一个停滞的派发、一个问到自己的设计请求。每件有一个稳定的键，有开始的时间，还有下一步命令。
- **主会话视角 / worker 视角**：按调用者的执行者身份（BR-2023）决定看哪些待办；worker 只看和自己的变更有关的。

## 业务

- **待办清单**：现在该处理哪些事，每件开了多久，下一步运行什么。
- **持续提醒**：长期运行的命令怎样只输出变化、按间隔重复，并且在宿主到期重挂时不丢事件。
