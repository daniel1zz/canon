## 规则

主会话（不是 worker 的执行者）运行的 `canon work land` 或 `canon chore land` 合入成功后，在合入本身的输出之后、main 没通过时的两行（BR-2306）和 `lessons:` 提醒（BR-2163）之前，那两样仍在输出末尾：

1. 议程摘要：和 `canon brief` 的一样（BR-2529），反映合入之后的状态（刚合入的变更已不在可派、要判断的事里，因它合入而满足依赖的变更出现在可派的活里）。
2. 和刚合入的变更有关的未处理意见单独一节，第一行 `Findings on what <C-n> touched:`，每条一行（BR-2527 的格式），缩进两个空格。有关是指：意见点名的文档里有这个变更 `rules:` 列出的规则，或这个变更的文件本身；杂务看它合入的提交改到的规则和决策文件。这些意见在摘要里照常计数，这里只是另外列出全文。

议程为空、也没有有关的意见时，什么都不加。合入被拒、超时时不输出这些。

worker 合入时不输出：它的主会话靠 `canon work watch` 看到这次合入和因此可以开始的变更（BR-2528）。

只提醒，不改合入的退出码；议程算不出来时输出一行 `agenda unavailable: <原因>`，合入的退出码仍是 0。

依据：D-151 第三部分第 7 条。

## 例子

- 主会话合入 `C-7`（`rules: [BR-3]`），意见 #12 点名 `BR-3`，还有一条和它无关的 #13 → 合入输出后有议程摘要（`judge: 2`），再有 `Findings on what C-7 touched:` 和 `finding:12 …`，没有 #13 的全文
- `C-8` 依赖 `C-7`，`C-7` 合入后 `C-8` 的设计已在 main → 摘要的可派一组有 `C-8`
- 议程为空，也没有有关的意见 → 合入输出之后什么都不加
- main 没通过，主会话 `canon work land --finish` 合入成功，议程里有 `red-main` → 先是议程摘要，再是 `main is failing floor since …` 两行，最后一行是 `lessons:` 提醒
- worker 合入 → 没有议程摘要
- 合入被拒 → 没有议程摘要
