## 规则

主会话议程（BR-2527）的 `red-main` 项，在这条“main 没通过”的记录开始以后有了自动撤回的结果才出现：记了 `revert.skip`（不定位或不撤回，BR-2535、BR-2536），或者撤回之后 main 仍没通过。有结果以前议程里没有这一项，`canon work watch` 在它出现的那一刻输出一行（BR-2528）。它是判断组第一档，下一步是 `canon work start --fix-main`（BR-2598）。

`canon work handled red-main` 用 `--defer` 或 `--not-doing` 时以退出码 1 拒绝，写明 main 没通过不能推后，只能修（交给修复变更 `--to <C-n>` 照常可以）；拒绝记 `reminder.handled.refuse`，原因 `red-main`（D-155）。

## 例子

- main 刚记下没通过，自动撤回正在探测 → 议程里没有 `red-main`
- 自动撤回记了 `revert.skip` → 议程有 `red-main`，`canon work watch` 输出一行
- `canon work handled red-main --defer "later" --for 1h` → 退出码 1，`reminder.handled.refuse` 原因 `red-main`
- `canon work handled red-main --to C-9` → 照 BR-2583 记下
