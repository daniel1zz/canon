title: 规划中的规则改成生效，必须由在 rules 里列出它的变更来做
status: active
---

## 规则

合入时（加不加 `--finish` 都一样），在 main 上是规划中、在合入的树里是生效的每条规则，都必须列在这次合入所属变更（合入的树里那份变更文件）的 `rules:` 里；有一条不在，或者这次合入不属于任何变更，就拒绝合入，原因 `activate`，信息列出这些规则的编号，main 不动。新建时就是生效的规则、从生效改成作废的规则、一直是规划中的规则都不受这条限制。

## 例子

- main 上 `BR-1` 是 `planned`，变更 `C-1` 把它改成 `active`，`C-1` 的 `rules: [BR-1]` → 不因这条拒绝
- 同上，但 `C-1` 的 `rules: []` → 拒绝，原因 `activate`，信息含 `BR-1`
- `C-1` 新建 `BR-2`，一开始就是 `active`，没列进 `rules:` → 不因这条拒绝
- `C-1` 只改了规划中 `BR-3` 的例子，状态仍是 `planned` → 不因这条拒绝
