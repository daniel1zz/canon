## 规则

关闭提交的通过记录是在 rebase 之前、在变更分支上算的。加 `--finish` 的合入 rebase 到 main 之后，正在关闭的变更 `rules:` 里列出的、以及它记了通过记录的每条规则，如果在合入的树里的状态或行为哈希和变更分支上 rebase 之前的不同（别人先合入改了它的 `## 规则`、`## 例子` 或状态），或者有记录的规则在合入的树里已经不是生效的、哈希和记录不同，就拒绝合入，原因 `rule-changed`，关闭提交照常被撤回（BR-2018）；信息点名这条规则，提示 `git rebase main`，按新的文字重新验证（改测试或验收行），再合入。只改了别的规则、或只改了这条规则的标题时不拒绝。

## 例子

- `C-1` 执行 `BR-1`，排队时 `C-2` 合入改了 `BR-1` 的一个例子 → `C-1` 被拒，原因 `rule-changed`，信息含 `BR-1` 和 `git rebase main`，`C-1` 还是 `open`
- `C-1` 的 `rules:` 列出 `BR-1`，它的哈希已有 `C-0` 的记录，`C-1` 不写它的记录；排队时 `C-2` 合入改了 `BR-1` 的一个例子 → `C-1` 被拒，原因 `rule-changed`
- `C-1` 执行 `BR-1`，排队时 `C-2` 只改了 `BR-1` 的标题 → 不因这条拒绝
- 同上，但 `C-2` 改的是 `BR-5` → 不因这条拒绝
- `C-2` 把 `BR-1` 改成了 `retired` → `C-1` 被拒，原因 `rule-changed`
