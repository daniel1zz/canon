## 规则

一条要执行的规则没有测试证据和验收证据时（BR-2241），canon 在工作树的 git 历史里（跟随移动）从新到旧找这个规则文件以前的版本，取第一个行为哈希等于某个已完成变更的通过记录的版本。这个版本的 `## 例子` 段和现在的相同（空白统一后比较，同 BR-2236），只有 `## 规则` 段不同时，记一条 `<现在的哈希> <那条记录的方式> wording`；合入后的措辞判断复核它，没确认为措辞修改时在这条规则上记一条未处理的评审意见，不撤回这条记录、不拒绝合入（BR-2239、D-141）。`## 例子` 改过、找不到这样的版本时，没有这种证据。

## 例子

- `BR-1` 的旧版本有 `C-0` 的记录 `… test`，`C-1` 只把 `## 规则` 里的“必须”改成“一定要”→ `C-1` 的记录是 `<新哈希> test wording`
- 同上，旧记录的方式是 `acceptance` → 新记录是 `<新哈希> acceptance wording`
- `C-1` 同时改了 `## 规则` 和 `## 例子` 里的一行 → 没有这种证据，没有测试或验收证据时不写记录，按 BR-2241 以待重新执行合入
- `BR-1` 从来没有通过记录 → 没有这种证据
- `BR-1` 在 `C-1` 里从 `canon/rules/a/BR-1.md` 移到 `canon/rules/a/b/BR-1.md`，同时只改了 `## 规则` → 仍找到旧版本，记 `… wording`
