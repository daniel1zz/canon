## 规则

`canon progress` 按 BR-2246 的四种执行状态汇报规则：

- 不带参数：每个领域和子领域一行（按 `canon rule domains` 的顺序），`<领域>  规划中 <n>  已通过 <n>  待 main 测试 <n>  待重新执行 <n>`，只数这个领域直接包含的规则；最后一行 `合计  规划中 <n>  已通过 <n>  待 main 测试 <n>  待重新执行 <n>`。
- `canon progress <领域>`：这个领域和它下面每个子领域各一段，第一行同上，下面每种个数不为 0 的状态一行，`  <状态>: <编号>, …`，已通过和待 main 测试的编号后带 `(C-n)`，编号按数字排序。
- `canon progress <C-n>`：一段，第一行是 `<C-n>` 和它 `rules:` 里不是作废、存在的规则的四个个数，下面同上。

参数既不是领域也不是存在的变更时退出码 3（BR-2022），标准输出为空。

## 例子

- billing 有规划中 `BR-2`、已通过（C-1）的 `BR-1`，auth 没有规则 → `canon progress` 输出 `billing  规划中 1  已通过 1  待 main 测试 0  待重新执行 0`、`auth  规划中 0  已通过 0  待 main 测试 0  待重新执行 0` 和 `合计  规划中 1  已通过 1  待 main 测试 0  待重新执行 0`
- `canon progress billing` → 第一行同上，下面 `  规划中: BR-2` 和 `  已通过: BR-1 (C-1)`，没有待 main 测试和待重新执行的行
- `canon progress C-1`，`C-1` 的 `rules: [BR-1, BR-2]` → 第一行 `C-1  规划中 1  已通过 1  待 main 测试 0  待重新执行 0`
- `canon progress nosuch` → 退出码 3，标准输出为空
- `canon progress C-999`（不存在）→ 退出码 3
