## 规则

`canon work test --all` 不按改动挑选，`tests` 配置（BR-2046）找到的每个测试文件都运行，仍然每个文件单独运行一次（BR-2158），同时运行几个和不带 `--all` 时一样由 BR-2302 决定，输出第一行写明运行的是全部测试文件和文件数。

## 例子

- 项目有 3 个测试文件，本变更只改了其中一个导入的文件 → 不带 `--all` 运行 1 个，带 `--all` 运行 3 个
- 本变更什么都没改 → 不带 `--all` 输出 `nothing to run`，带 `--all` 仍运行全部
- `test_jobs: 1`，带 `--all` → 全部文件一次一个；没写 `test_jobs`、8 个 CPU、每次量到 6 个空闲 CPU，带 `--all` → 最多同时 4 个，和不带 `--all` 相同
