## 规则

`canon work test`（加不加 `--all` 都一样）在 `canon check` 那一行之后，对本变更改到的每一个规则或决策的每一条未处理评审建议（BR-2145，和 `canon context` 列出的是同一批）输出一行 `Open review note on <编号>: <建议> (<得到建议的变更>, <日期>)`，前面先输出一行说明：这些建议只是提示，在这个变更里处理。改到的规则是 BR-2157 里的“碰到的规则”：和 main 的分叉点相比改动过（含新建、删除）的规则文件，以及改动过的变更文件 `rules:` 里列出的规则；改到的决策是改动过（含新建、删除）的决策文件。只作提示：有没有建议都不影响退出码和 `work.test` 事件里的结果。改到的文档都没有未处理建议时不输出这一段。

## 例子

- 变更改了 `BR-1` 的文件，`BR-1` 上有一条未处理的建议“例子缺少边界另一侧”，选出的测试都通过 → 输出 `Open review note on BR-1: 例子缺少边界另一侧 (C-1, 2026-11-04)`，退出码 0
- 变更文件的 `rules:` 列出 `BR-1`，但没改 `BR-1` 的文件 → 同样列出 `BR-1` 的建议
- 变更改了决策 `D-1` 的文件，`D-1` 上有未处理的建议 → 列出它
- `BR-2` 上有未处理的建议，但本变更既没改 `BR-2` 的文件，`rules:` 里也没有它 → 不列
- 改到的规则和决策上都没有未处理的建议 → 不输出 `Open review note` 这一段
- 选出的测试有一个失败，同时有未处理的建议 → 退出码 1（因为测试失败），建议照样列出
