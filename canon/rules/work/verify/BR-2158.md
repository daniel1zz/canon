## 规则

`canon work test` 对每个选出的测试文件单独运行一次 `test_command`（BR-2160），`{file}` 换成这个文件的路径，在 worktree 根目录下依次运行。每个文件结束时打印一行：`pass` 或 `FAIL`、用时、路径，失败的还有退出码和它输出的最后 40 行。最后打印汇总：文件数、通过数、失败数、总用时，有失败时再列出失败的文件。有任何文件失败时退出码 1，全部通过时 0。一个文件都没选出时打印 `nothing to run`，不运行命令，退出码 0。每次运行在事件表里记一条 `work.test`，带文件数、失败数和用时。

## 例子

- 选出 2 个文件，都通过 → 两行 `pass`，汇总 `2 file(s): 2 passed, 0 failed, …`，退出码 0
- 选出 2 个文件，第二个失败 → 第二行 `FAIL … (exit 1)` 和它输出的最后几行，汇总 `1 passed, 1 failed`，`failed: <文件>`，退出码 1
- 选出 2 个文件 → `test_command` 运行两次，每次只带一个文件
- 一个都没选出 → `nothing to run`，退出码 0
