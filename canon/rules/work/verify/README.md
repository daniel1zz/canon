# 合入前的验证（work/verify）

合入前在变更的 worktree 里验证改动：`canon work test` 挑出和本变更相关的测试文件，一个文件一次地运行，把要等 floor 才发现的失败提前到合入之前。

不管：合入时的 floor 和检查（`work/land`），规则和测试名的对应（`knowledge/check`）。

## 术语

- **相关的测试文件**：本变更改过的测试文件、通过相对导入用到改过文件的测试文件、测试名写了本变更碰过的规则的测试文件（BR-2157）。
- **test_command**：项目配置的、运行一个测试文件的命令（BR-2160）。
