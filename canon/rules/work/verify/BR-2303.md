---
id: BR-2303
title: 和别的文件同时运行时失败的测试文件，最后单独再运行一次，以单独运行的结果为准
status: active
---

## 规则

`canon work test` 里一个测试文件失败了，而从它开始到结束之间本次运行有别的测试文件也在运行（BR-2302），这个文件的结果先不算，叫“同时失败的文件”。所有文件都结束后：

- 同时失败的文件不超过 3 个：先打印一行 `rerunning alone <n> file(s) that failed while other files ran`，再按选出的顺序一个一个单独运行一次，期间不运行别的测试文件。单独运行的结果行在路径后加 ` (alone)`，格式和别的结果行一样（BR-2158），失败的同样带最后 40 行输出。这个文件的结果以单独运行为准：通过就算通过，不计入失败数和退出码；仍失败就算失败。汇总里列出单独运行通过的文件：`failed alongside other files, passed alone: <文件>, …`。
- 同时失败的文件超过 3 个：一个也不重跑，打印一行 `not rerunning alone: <n> files failed while other files ran (more than 3), so they count as failed`，它们都算失败。多半是机器出了问题或改动弄坏了很多测试，一个一个重跑只会多等几十个文件的时间。
- 运行期间一直没有别的文件同时运行的文件失败了：不重跑，直接算失败。

`work.test` 记 `rerun`（单独重跑的文件数）、`rerunFiles`（这些文件的路径）、`passedAlone`（其中单独运行通过的个数）、`passedAloneFiles`（这些文件的路径）和 `rerunSkipped`（因为超过 3 个而没有重跑的个数，没有时为 0）。汇总和 `work.test` 的文件数里每个文件只算一次，单独重跑不增加文件数（BR-2158）。

## 例子

- 同时运行的 `a.test.ts` 和 `b.test.ts`，`a` 失败、`b` 通过；`a` 单独运行通过 → 先打印 `FAIL … a.test.ts (exit 1)` 和它的输出，最后打印 `rerunning alone 1 file(s) …` 和 `pass … a.test.ts (alone)`，汇总 `2 file(s): 2 passed, 0 failed, …` 加一行 `failed alongside other files, passed alone: a.test.ts`，退出码 0（类型检查和 `canon check` 也通过时），`rerun` 1，`rerunFiles` 和 `passedAloneFiles` 都是 `["a.test.ts"]`，`passedAlone` 1
- 同样情况，`a` 单独运行仍失败 → `FAIL … a.test.ts (alone) (exit 1)` 和它的最后几行，汇总 `2 file(s): 1 passed, 1 failed`，`failed: a.test.ts`，退出码 1，`rerun` 1，`passedAlone` 0，`passedAloneFiles` 为空
- 57 个文件，50 个在同时运行时失败 → 不重跑，打印 `not rerunning alone: 50 files failed while other files ran (more than 3), so they count as failed`，失败数 50，`rerun` 0，`rerunSkipped` 50
- 3 个文件同时失败 → 重跑 3 个；4 个同时失败 → 一个也不重跑，`rerunSkipped` 4
- `test_jobs: 1`，`a.test.ts` 失败 → 不重跑，没有 `rerunning alone` 这一行，失败数 1，`rerun` 0
- 机器忙满，`a.test.ts` 运行时一直只有它自己在跑，失败 → 不重跑
- `a.test.ts` 开始时 `b.test.ts` 还在跑，`b` 先结束，`a` 之后失败 → 重跑（运行期间有过别的文件）
- 两个同时失败的文件 `b.test.ts`、`a.test.ts` → 按选出的顺序先单独运行 `a` 再单独运行 `b`，两次单独运行不重叠
- 没有文件失败 → 没有 `rerunning alone` 这一行，`rerun` 0，`rerunFiles` 为空
