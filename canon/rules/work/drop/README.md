# 放弃变更（work/drop）

`canon work drop C-n` 删除一个不再做的变更的 worktree 和分支。不会丢东西时直接删；会丢东西时（未合入的提交、未提交和未跟踪的文件、不能重新生成的被忽略文件），先存档到 `refs/canon/archive/<C-n>/<时间>`，读回校验后才删，并打印恢复命令，不问人（D-13）。

## 术语

- **存档 ref**：保存被删内容的提交，父提交是分支最新提交。
- **可重新生成**：配置 `regenerable` 里列出的被忽略目录或文件（如 `node_modules`、`dist`），删除时不算丢东西。

## 业务

- **删除和存档**：放弃时怎样删除 worktree 和分支，会丢东西时怎样先存档、存档失败时什么都不删。
- **放弃之后的协调数据**：放弃一个变更时，它留在协调数据库里的派发怎样随之结束，不再被当成有人在做或停滞。
