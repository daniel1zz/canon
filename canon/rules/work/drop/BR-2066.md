## 规则

已退役：负责人选择存档后直接删除，不再问人（D-13），由 BR-2102、BR-2103 取代。以下是退役前的内容。

为 `canon work drop <C-n>` 提的问题由 `human:` 操作者回答、或由 agent 转述人的原话（BR-2021）回答 `yes`（或 `y`、`同意`、`是`，不区分大小写）之后，再次执行且会丢掉的东西和提问时完全一样，才真正删除，并在 `drop.done` 事件里记下丢掉的内容。回答是别的内容，或者是 agent 不带转述的回答，都算不同意：不删除，写一条原因为 `declined` 的 `drop.refuse` 事件，退出码 1。提问之后会丢的东西变了（例如又多了一个提交），就当作新的情况重新提问。

## 例子

- `human:dz` 回答 `yes`，`C-1` 没有变化 → 再次 `canon work drop C-1` 删除 worktree 和分支，退出码 0
- `human:dz` 回答 `no` → 再次执行不删除，退出码 1
- agent 用 `--relayed "删吧"` 转述回答 `yes` → 再次执行删除，`drop.done` 里能看到这是转述
- 回答之后 `C-1` 又多了一个提交 → 再次执行提出新问题，退出码 1
