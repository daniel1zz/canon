## 规则

主会话（不是 worker 的执行者，BR-2023）在主 checkout 或没有认领的 worktree 里运行 `canon brief` 时，在 BR-2024 列出的内容之后，按 BR-2527 的格式列出它现在的待办，标题行是 `Due now (canon work due):`。没有待办时不输出这一节。

运行在 Claude Code 里（`CLAUDECODE=1`）时，还要输出一行，有没有待办都输出：

`Keep canon work watch running under Monitor (timeout 30 min); when it expires, re-arm with --since <the last event number it printed>.`

Codex 和别的宿主不输出这一行，因为它们没有 Monitor；它们只靠这里列出的待办和 `canon work start` 的提醒（BR-2530）。

认领了变更的 worktree 里的 brief 不变（BR-2024），worker 也一样：worker 是无界面运行的会话，挂不了 Monitor。

依据：D-136。

## 例子

- Claude Code 主会话，有一条开了 2 小时的意见 #12 → 输出含 `Due now (canon work due):` 和 `finding:12 2h00m …`，以及 `Keep canon work watch running under Monitor …`
- Claude Code 主会话，没有待办 → 没有 `Due now`，仍有 `Keep canon work watch running …`
- Codex 主会话，有意见 #12 → 有 `Due now` 和 `finding:12`，没有 `Monitor` 那一行
- 在认领了 `C-1` 的 worktree 里 → 两者都没有
- worker（`agent:s:w1`）→ 两者都没有
