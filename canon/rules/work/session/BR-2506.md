## 规则

在没有认领变更或杂务的地方，`canon brief` 在工作说明之后、交接之前，先打印整体进度摘要（D-129，取自 `canon overview` 的 `## 当前版本` 和 `## 历史`，BR-2505），第一行是 `Overall progress (canon overview):`，后面缩进两个空格：

- 每个进行中的版本一行：BR-2505 的状态行，后面两个空格再接它的成功标准计数行；不算规则的执行状态：那要读每条规则的通过记录，大项目里要几秒，每个会话开头都付不起，规则的数量看 `canon overview`。因为没有 `active` 才取的 `planned` 版本，那一行末尾加 `  (no release is active: the lowest planned one)`。没有进行中的版本时一行 `no release in progress`。
- 有 BR-2505 历史大纲里的目标改动时一行 `goal changed in the last 7 days: <提交号前 9 位，逗号分隔> (canon overview --history)`。
- 没有质量标准或有方面没覆盖时一行 `quality: …`，文字按 BR-2558；其他时候不输出。

等负责人的事、停滞的派发和可派的活不在这里：它们是议程的内容，brief 在后面的议程摘要里给出（BR-2529）。

没有进行中的版本、没有最近的目标改动、也没有质量标准的提醒时，整个摘要都不打印，brief 照 BR-2024 只有工作说明。认领了变更或杂务的 worktree 里不打印，理由同 BR-2024：别的工作的情况会把这个会话拉离它自己的变更。摘要读不出来（例如 main 上的文档读不了）时说一行原因，brief 照样输出其余内容。

在 agent 会话（Claude Code 或 Codex，BR-2518 认会话的办法）里，有进行中的版本（不是“没有生效的版本、取最低的计划版本”那种）而这个会话还没开目标模式时，摘要后面多一行 `  goal mode is off for this session: canon goal start keeps it working toward these success criteria (canon goal stop ends it)`；开了目标模式、不在 agent 会话里、或没有进行中的版本时没有这一行（D-132、BR-2648）。

依据：D-129、D-131；去掉计划、等负责人和停滞的行按 D-151 第三、四部分。

## 例子

- Claude Code 会话，`R-5` 进行中，这个会话没开目标模式 → 摘要后面有 `  goal mode is off for this session: …`；`canon goal start` 之后、或在普通终端里运行 → 没有这一行

- 主 checkout，`R-3` active，4 条成功标准各一种状态 → `Overall progress (canon overview):` 下面一行 `R-3  active  <标题>  成功标准 4 条：已满足 1  未满足 1  待负责人 1  未证明 1`
- 有计划 `C-5` 做了 2/4 → 摘要里没有计划的行
- 1 个问题等回答 → 摘要里没有它，议程摘要的 `owner:` 一组有它
- 没有版本、没有最近的目标改动，质量标准都有着落（BR-2558 的情况 3）→ 不出现 `Overall progress`
- 没有版本，也没有 `canon/quality/` → `Overall progress (canon overview):`、`  no release in progress`、`  quality: no quality standards yet (canon/quality): research them with the canon-product skill, then canon quality new --title "<standard>"`
- `R-3` 和 `R-5` 都 active → 两行，`R-3` 在前
- `R-3` 自己 1 条成功标准，它的模块 `F-1` 有 2 条 → `成功标准 3 条：…`
- 没有 active，`R-2` planned、没有成功标准 → 第一行 `R-2  planned  <标题>  成功标准 0 条：已满足 0  未满足 0  待负责人 0  未证明 0  (no release is active: the lowest planned one)`
- 在认领了 C-9 的 worktree 里 → 不出现 `Overall progress`
