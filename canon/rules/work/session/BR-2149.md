id: BR-2149
title: 在主 checkout 里，canon brief 按待办顺序列出未完成的变更并标出已被认领的
status: active
---

## 规则

在主 checkout 或没有认领的 worktree 里，main 上有未完成（`open`）的变更时，`canon brief` 输出一行 `Open changes in the owner's order`，按 BR-2148 的顺序（待办清单读 main 上的 `canon/backlog.md`）列出它们的编号，被认领的编号后面加 `(claimed)`，并提示没有任务时取第一个没被认领的。main 上没有未完成的变更时不输出这一行；在认领了变更的 worktree 里不输出这一行（BR-2024）。

## 例子

- main 上有 `C-1`、`C-2`，清单是 `- C-2`，`C-2` 被认领 → 输出 `Open changes in the owner's order (canon change list); with no task, take the first unclaimed one: C-2 (claimed), C-1`
- main 上没有未完成的变更 → 没有这一行
- 在认领了 `C-1` 的 worktree 里 → 没有这一行
