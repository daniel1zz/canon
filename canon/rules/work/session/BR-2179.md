---
id: BR-2179
title: 清理或放弃 worktree 时，canon 生成的 .canon 目录总算可以重建
status: active
---

## 规则

`canon work clean`（BR-2019）和 `canon work drop`（BR-2064）判断被 git 忽略的文件算不算工作时，路径里有一段是 `.canon` 的文件总算可以重新生成，不管 `canon/config.yaml` 的 `regenerable` 怎么写：这个目录只放 canon 自己生成、随时能重建的文件（BR-2176）。

## 例子

- `regenerable: [node_modules]`（不含 `.canon`），已合入的 worktree 里只有被忽略的 `.canon/config.schema.json` → `canon work clean` 删除它
- 同样配置下 `canon work drop` 一个已合入、只有 `.canon/config.schema.json` 的变更 → 直接删除，不存档
- 同一个 worktree 里还有被忽略的 `.env` → clean 保留它并列出 `.env`，不列 `.canon`
