## 规则

在认领了变更的 worktree 里，`canon brief` 对每个和当前变更改了同一文件的其他变更输出一行 `Overlap: <变更> also changes <文件>`（判定同 BR-2062）；没有重叠时不输出这一行。比较时 git 出错（列不出 worktree，或算不出某个分支相对 main 的改动），对每个出错的地方输出一行 `Overlap check failed: <哪个分支和错误>`，不当作没有重叠，也不改变退出码。重叠提示只是输出：`brief` 不写 `overlap.notice` 事件（它会写别的东西，见 BR-2137 的 hook 事件和 BR-2176 的 schema 文件）。

## 例子

- `C-1` 和 `C-2` 都改了 `src/a.ts`，在 `C-1` 的 worktree 里执行 `canon brief` → 输出包含 `Overlap: C-2 also changes src/a.ts`
- 两个变更改的文件不重叠 → 没有 `Overlap` 行
- `C-1` 和 `C-2` 有重叠，在 `C-1` 的 worktree 里执行 `canon brief` → 事件表里没有新的 `overlap.notice`
- `C-2` 的 worktree 签出的分支和 main 没有共同祖先 → 输出 `Overlap check failed: cannot compare <C-2 的分支> with main: …`
