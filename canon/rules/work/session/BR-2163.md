## 规则

`canon work stop` 记下 handoff 之后，以及 `canon work land --finish` 合入成功并关闭变更之后，输出的最后一行是同一句提醒：`lessons: ...`，说这次工作对流程或工具的、可能做成超出本变更的机制（规则、检查或命令）的认识要写进变更文件的 `## 教训`，固化成机制之前先问负责人（D-24），并说明本变更为自己的功能或修复写的规则、测试和检查不是教训（D-78）。没有 `--finish` 的合入、被拒绝的合入不输出这一行。

## 例子

- `canon work stop --next "写测试"` 成功 → 最后一行以 `lessons:` 开头，含 `## 教训` 和 `ask the owner`，也含 `not lessons`
- `canon work land --finish` 合入成功 → 最后一行是同一句提醒
- `canon work land --finish` 还输出了合入后评审的排队说明（BR-2441）和 after_land 的日志路径，`canon work stop` 还输出了 after_stop 的结果 → 这些都在 `lessons:` 这一行之前
- `canon work land`（不加 `--finish`）合入成功 → 输出里没有 `lessons:`
