id: BR-2385
title: canon work start --step 遇到已有变更在做的步骤时提示，照常开工
status: active
---

## 规则

`canon work start --title ... --plan C-n --step <步骤名>` 开工成功后（BR-2376），对每个给出的步骤，如果已经有别的变更在做它（front matter 的 `plan` 是 `C-n`、`steps` 含这一步，包括只在自己分支上的变更），并且那个变更既没有放弃（`dropped`），也没有以 `done` 合入 main，就输出一行 `step <步骤名> is already being done by <变更编号>[, <变更编号>…]`。这只是提示：照常开工，退出码 0（D-77：一步可以由几个变更做）。做这一步的变更都已放弃、都已合入，或者没有别的变更做这一步时，不输出这一行。

## 例子

- 计划 `C-1` 的步骤 `2` 有开着的变更 `C-300` 在做，`canon work start --title "x" --plan C-1 --step 2` → 新变更照常开工，退出码 0，输出含 `step 2 is already being done by C-300`
- 步骤 `2` 只有已放弃的 `C-301` 和已合入、`done` 的 `C-302` 做过 → 不输出这一行
- 步骤 `2` 的 `C-303` 是 `done` 但只在自己的分支上、还没合入 → 输出 `step 2 is already being done by C-303`
- 没有别的变更做步骤 `2` → 不输出这一行
- `--step 2,3`，只有 `3` 有 `C-300` 在做 → 只输出 `step 3 is already being done by C-300`
