## 规则

`canon work clean` 删掉一个 worktree（BR-2019）之后，用 `git branch -d` 在主 checkout 里删掉这个 worktree 签出的分支。`git branch -d` 只删已经合进主 checkout 当前签出的提交（或分支的 upstream）的分支；git 拒绝删时分支留下，clean 不报错、不列出，worktree 照样算已删除，退出码不变。保留下来的 worktree 的分支不动。

## 例子

- 主 checkout 签出 main，C-1 已合入，`canon work clean` → C-1 的 worktree 和分支 `change/C-1-x` 都没了
- C-2 有一个没合入的提交，被保留 → 分支 `change/C-2-y` 还在
- 主 checkout 签出的是另一个分支 `other`，它不含 C-3 合入的提交，C-3 已合入 main → C-3 的 worktree 被删，分支 `change/C-3-z` 留下，输出只有 `removed …`，退出码 0
