title: "新 worktree 的 setup 失败时不留下半成品"
status: active
---
## 规则

新建 worktree 后执行配置里的 `setup`；退出码非 0 时，刚建的 worktree 和新分支被删除，认领被释放，退出码 1，再次 `canon work start` 会从头开始并重新执行 setup。`--title` 新建变更时，写或提交变更文件失败（例如 git 的 pre-commit hook 拒绝提交）也一样：刚建的 worktree 和新分支被删除，认领被释放，退出码按失败的原因（BR-2022，git 失败是 4）。

## 例子

- `setup: test -e .ok` 失败 → 没有新 worktree、没有 `change/*` 分支、没有认领
- 接着把 `setup` 改成 `touch ../ran`，再 `canon work start --title` → 成功，setup 又执行了一次
- pre-commit hook 拒绝提交，`canon work start --title "X"` → 退出码 4，没有新 worktree、没有 `change/*` 分支、没有认领
