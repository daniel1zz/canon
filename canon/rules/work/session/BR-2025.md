## 规则

`canon work stop --next <下一步>` 为当前 worktree 认领的变更记录 handoff（下一步、可选备注、操作者、时间），覆盖同一变更之前的 handoff；默认保留认领，加 `--release` 时释放；当前 worktree 没有认领时退出码 3；当前 worktree 正被一次 `canon work clean` 或 `canon work drop` 删除（它的占位还有效，BR-2019、BR-2064）时，退出码 5，提示写明这个 worktree 正在被删除，不记 handoff；那次 clean 或 drop 已经被杀掉、占位失效时，按没有认领处理（退出码 3）。

## 例子

- 先 stop `--next "write the test"`，再 stop `--next "land it"` → handoff 只剩“land it”，认领还在
- 在主 checkout（没有认领）执行 stop → 退出码 3
- `canon work drop C-1` 正在删除 `C-1` 的 worktree 时，在那个 worktree 里执行 stop → 退出码 5，提示里有 `being deleted`，没有新的 handoff
- 占住 `C-1` 的那次 drop 已经被杀掉 → 在那个 worktree 里执行 stop 退出码 3
