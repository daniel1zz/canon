## 规则

`canon work start <C-n>` 读取 main 上的变更（main 上没有时见 BR-2107）（从签出了 main 的 worktree，没有时直接从 git 读），为它建 worktree、分支和认领；读取时不受主 checkout 当前签出哪个分支影响。变更不是 `open` 状态时拒绝，退出码 2。

## 例子

- 主 checkout 签出的是别的分支，那个分支上没有 `canon/changes` → `canon work start C-1` 仍然成功，新 worktree 的代码和 main 一致
- `C-3` 状态是 `done` → 拒绝，退出码 2，提示它已完成
