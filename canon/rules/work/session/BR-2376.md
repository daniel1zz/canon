title: canon work start --plan C-n --step 步骤名 新建变更并把它记为那个计划的这几步
status: active
business: 按计划开工

## 规则

`canon work start --title "<标题>" --plan C-n --step <步骤名>` 新建变更时，在变更文件的 front matter 写 `plan: C-n` 和 `steps: [<步骤名>]`（BR-2371），随开工的第一个提交一起进分支，所以变更一开工，`canon plan status` 就把这一步算作进行中（BR-2372）。`--step` 可以写几个，用 `,` 隔开。`--plan` 和 `--step` 必须一起给，并且只能和 `--title` 一起用，不能和已有变更的编号或 `--fix-main` 一起用，否则用法错误（退出码 2）。`C-n` 必须是 main 上有合格计划的变更，每个步骤名必须是那个计划里的步骤，否则退出码 3，信息说明哪里不对；这些都在分配变更编号、建 worktree 之前检查，被拒绝的开工不留下任何东西。

## 例子

- `--title "做接口" --plan C-1 --step 2`，`C-1` 的计划有步骤 `2` → 新变更的 front matter 有 `plan: C-1` 和 `steps: ["2"]`，开工的提交里就有
- `--step 2,3` → `steps` 有两项
- `--plan C-1` 没有 `--step` → 退出码 2
- `--step 2` 没有 `--plan` → 退出码 2
- `canon work start C-7 --plan C-1 --step 2`（已有变更）→ 退出码 2
- `--plan C-9`，`C-9` 不存在 → 退出码 3，没有 worktree，没有分配编号
- `--plan C-1 --step 9`，`C-1` 的计划里没有 `9` → 退出码 3，没有 worktree，没有分配编号
- `--plan C-1`，`C-1` 没有计划 → 退出码 3
