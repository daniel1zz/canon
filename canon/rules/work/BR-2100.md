---
id: BR-2100
title: 认领者的会话进程已经不在，认领可以立刻被接手
status: active
---

## 规则

在 Claude Code 里认领变更时，认领记下这个会话的 Claude Code 进程（环境变量 `CLAUDE_PID`，只有它确实是当前进程的祖先时才采用；记 pid 和进程启动时间，启动时间一律按 UTC 读取，所以时区设置不同的会话读到的是同一个值）；同一个执行者之后的工作命令把它更新为当时的进程。另一个执行者认领这个变更时，如果记下的进程已经不在（没有这个 pid，或 pid 被启动时间不同的进程占用），即使租约（BR-2011）还没到期也可以立刻接手。认领没有记下进程（不在 Claude Code 里，或 `CLAUDE_PID` 不是祖先），或者读不到进程表时，只按租约判断。

## 例子

- agent:a 在会话进程 P 下认领 `C-1`，随后关掉了这个 Claude Code（P 退出），租约还剩 11 小时 → agent:b 认领 `C-1` 成功
- P 还在运行 → agent:b 认领被拒绝，退出码 5
- P 还在运行，agent:b 的 shell 设了 `TZ=UTC` 而 agent:a 的没有 → 读到的启动时间相同，agent:b 仍被拒绝
- 人在普通终端里认领 `C-1`（没有 `CLAUDE_PID`）→ 只按租约判断
- 环境里的 `CLAUDE_PID` 指向一个不是当前进程祖先的进程 → 不记进程，只按租约判断
- 同一个 Claude Code 会话的两个子 agent 共用进程 P → 这个探测分不开它们，P 在就算在
