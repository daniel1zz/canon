title: "一个变更同一时间只由一个 worktree 和一个执行者持有"

## 规则

认领把一个变更绑定到一个 worktree 和认领它的执行者（`CANON_ACTOR`，Claude Code 里是会话 id，见 BR-2023）。租约默认 12 小时（配置 `claim_lease_hours`），这个 worktree 里的 `canon work start`、`canon work land` 和不带 `--release` 的 `canon work stop` 都会把它从当时起重新计算。租约有效期内，另一个 worktree 或另一个执行者认领同一个变更都会被拒绝（退出码 5），提示里写明持有者；同一个执行者在同一个 worktree 里再次 `canon work start` 照常成功；租约过期后可以接手。

## 例子

- `C-1` 由 agent:a 在 worktree A 认领 1 小时前，agent:b 在 worktree B 认领 `C-1` → 拒绝，退出码 5，提示持有者
- `C-1` 由 agent:a 认领 1 小时前，agent:b 运行 `canon work start C-1`（得到的是同一个 worktree 路径）→ 拒绝，退出码 5，认领仍归 agent:a
- agent:a 自己再次运行 `canon work start C-1` → 成功，回到同一个 worktree
- agent:a 用 `canon work stop --release` 放开 `C-1` 后，agent:b 认领 → 成功
- A 的租约 13 小时前到期，B 认领 `C-1` → 成功
- A 13 小时前认领 `C-1`，3 小时前执行过 `canon work stop` → 租约从那次 stop 起重新计算，还剩 9 小时，B 认领被拒绝
- 配置 `claim_lease_hours: 1`，A 两小时前认领后没再执行工作命令 → B 认领成功
