## 规则

`canon human answer` 只能由 `human:` 操作者（BR-2023）在交互式终端里执行：没有 TTY，或者操作者不是 `human:`（例如 agent 用伪终端套着执行），都以退出码 2 拒绝；操作者不是 `human:` 时（不论有没有 TTY）写一条 `human.answer.refuse` 事件。

## 例子

- agent 会话（没有 TTY）执行 `canon human answer 1 yes` → 退出码 2，提示要由人在终端回答
- agent 用 `script` 套一层伪终端执行 `canon human answer 1 yes`（操作者 `agent:x`）→ 退出码 2，问题仍未回答，多一条 `human.answer.refuse`
- `human:dz` 在终端里执行 → 回答成功
