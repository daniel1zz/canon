---
id: BR-2104
title: 只有认领的持有者能在它的 worktree 里续期、停下、放开或合入
status: active
---

## 规则

在一个被认领的 worktree 里运行 `canon work land`、`canon work stop`（带或不带 `--release`）时，执行者不是认领的持有者、而这个认领仍然有效（租约没到期，且记下的会话进程还在，BR-2100）→ 拒绝，退出码 5，提示写明持有者；认领、交接记录和 main 都不变，事件表记一条 `claim.refuse`（算进 `canon stats` 的 `claim` 检查，不算合入检查）。认领已经失效时，这个执行者接手认领（记 `claim.take`），命令照常执行。持有者自己运行时照常续期。边界：执行者只到会话一级（BR-2023），所以同一个会话的任何 agent 进入别的 agent 的 worktree，在那里都算持有者，可以续期、停下、放开和合入；canon 假设 agent 互相配合、照 BR-2011 的提示去做别的变更，不阻止这种情况（D-18）。

## 例子

- agent:a 认领 `C-1`，agent:b 进入 `C-1` 的 worktree 运行 `canon work stop --release --next x` → 退出码 5，认领仍归 agent:a，没有新的交接记录
- 同样情形下 agent:b 运行 `canon work land --finish` → 退出码 5，main 不动，变更没有被关闭
- agent:a 的租约已经过期，agent:b 在那里运行 `canon work stop --next x` → 成功，认领归 agent:b
- agent:a 自己运行 `canon work stop --release --next x` → 成功，认领被放开
- agent:a 认领 `C-1`，同一个会话的另一个子 agent（执行者也是 agent:a）进入那个 worktree 运行 `canon work stop --next x` → 成功，认领仍归 agent:a，租约续期
