## 规则

启动 worker 会话的工具（派发方）可以在 worker 的环境里设 `CANON_SUBAGENT=<worker 名>`，名字只含字母、数字、`-`、`_`；两侧的空白去掉，空值或全是空白按没设。设了它的会话里，执行者按 BR-2023 的顺序确定，`CANON_SUBAGENT` 在其中当作 `--as <worker 名>`；认领、合入、事件和它转述的负责人回答（BR-2275）都记在这个名字下（D-125）。

- 命令带了 `--as`（例如 worker 自己起的原生子 agent 带的 agent id）→ 按 BR-2023 用这个 `--as`，canon 命令本身不核对它，核对交给下面的 hook；Codex 子线程 → 用它自己的线程身份。两种都比 worker 名具体，优先；
- 同时设了 `CANON_ACTOR` → 用法错误（退出码 2），说明派发方只设 `CANON_SUBAGENT`；
- 名字含别的字符 → 用法错误，信息写出拿到的值；
- 不在 Claude Code 或 Codex 会话里 → 用法错误，同 BR-2023 对 `--as` 的要求。

每次 Bash 前的快照 hook（BR-2182）在没有原生 `agent_id` 时，也按 worker 名找它认领的 worktree 补拍快照。

canon 运行生命周期 hook 时，hook 命令的环境里有完整的 `CANON_ACTOR`（BR-2199），不再带 `CANON_SUBAGENT`，所以 worker 的 hook 里也能运行 `canon`。

`canon work check-as --hook`（BR-2340）在 hook 进程的环境里看到合法的 `CANON_SUBAGENT`、调用又没有 `agent_id` 时，不读进程表，按这个名字判断认领命令：不带 `--as` 或带相同的 `--as` → 放行；带别的 `--as` → 拒绝，reason 写 `started with CANON_SUBAGENT=<名字>`；命令前面设了 `CANON_ACTOR=` → 按 BR-2340 拒绝；`take`、`unstall` → 拒绝，同 BR-2468。名字不合法 → 拒绝，reason 写出拿到的值。有 `agent_id` 的调用是 worker 的原生子 agent，照 BR-2340 要求它带自己的 agent id。没设 `CANON_SUBAGENT` 的 worker 仍按 BR-2468 认。

## 例子

- 会话 `a69bb94c-570e-4fcb` 的环境里 `CANON_SUBAGENT=worker-w6`，不带 `--as` → 执行者是 `agent:a69bb94c:worker-w6`；值是 `  worker-w6 ` 时也一样；值是 `  ` 时是 `agent:a69bb94c`
- 同上，`--as worker-w6` → `agent:a69bb94c:worker-w6`；`--as agent7` → `agent:a69bb94c:agent7`
- Codex 会话 `CODEX_SESSION_ID=root`、子线程 `CODEX_THREAD_ID=native-child`，`CANON_SUBAGENT=worker-w6`，不带 `--as` 或 `--as native-child` → `agent:codex-root:native-child`
- 会话 `a69bb94c-570e-4fcb`、`CANON_SUBAGENT=worker-w6` 里记下的负责人回答 → 执行者 `agent:a69bb94c:worker-w6`
- `CANON_SUBAGENT=worker-w6` 和 `CANON_ACTOR=agent:x` 都设了 → 用法错误，信息含 `both name the actor`
- `CANON_SUBAGENT=a:b` → 用法错误，信息含 `CANON_SUBAGENT="a:b"`
- 不在会话里（没有 `CLAUDECODE`），`CANON_SUBAGENT=w1` → 用法错误，信息含 `CANON_SUBAGENT is only for workers`
- 环境里 `CANON_SUBAGENT=worker-w6` 时运行的 hook 命令 → `$CANON_SUBAGENT` 为空，`$CANON_ACTOR` 是 canon 算出的执行者
- hook 环境里 `CANON_SUBAGENT=worker-w6`、没有 `agent_id`：`canon work land --finish` → 放行；`canon work land --as worker-w6` → 放行；`canon work land --as w1` → 拒绝，reason 含 `started with CANON_SUBAGENT=worker-w6`；`CANON_ACTOR=agent:x canon work land` → 拒绝，reason 含 `do not set CANON_ACTOR`；`canon work take C-5 --from x` → 拒绝，reason 含 `canon work take is for the main session only`
- 同样的环境，`agent_id` 是 `agent7`，`canon work land --as agent7` → 放行
- hook 环境里 `CANON_SUBAGENT=a:b`，`canon work land` → 拒绝，reason 含 `CANON_SUBAGENT="a:b"`
- 会话 `abcd1234-…`、`CANON_SUBAGENT=worker-w6`、hook 输入没有 `agent_id`，`agent:abcd1234:worker-w6` 认领了 `C-17` 的 worktree、`agent:abcd1234` 认领了 `C-18` → 快照 hook 只补拍 `C-17`
