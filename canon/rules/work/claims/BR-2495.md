---
id: BR-2495
title: 派发方给 worker 设 CANON_SUBAGENT 时，canon 按这个名字把它记成子 agent，worker 不用自己带 --as
status: active
business: 子 agent 的认领
---

## 规则

启动 worker 会话的工具（派发方）可以在 worker 的环境里设 `CANON_SUBAGENT=<worker 名>`，名字只含字母、数字、`-`、`_`。设了它的会话里，每条 `canon` 命令都当作带了 `--as <worker 名>`：执行者按 BR-2023 是 `agent:<会话>:<worker 名>`，认领、合入和事件都记在这个名字下（D-125）。

- 命令另带的 `--as` 和它相同 → 照常；不同 → 用法错误（退出码 2），信息写出两个值，说明不带 `--as` 或带 `--as <worker 名>`；
- 同时设了 `CANON_ACTOR` → 用法错误，说明派发方只设 `CANON_SUBAGENT`；
- 名字含别的字符 → 用法错误，信息写出拿到的值；
- 不在 Claude Code 或 Codex 会话里 → 用法错误，同 BR-2023 对 `--as` 的要求。

`canon work check-as --hook`（BR-2340）在 hook 进程的环境里看到合法的 `CANON_SUBAGENT`、调用又没有 `agent_id` 时，不读进程表，按这个名字判断认领命令：不带 `--as` 或带相同的 `--as` → 放行；带别的 `--as` → 拒绝，reason 写 `started with CANON_SUBAGENT=<名字>`；`take`、`unstall` → 拒绝，同 BR-2468。名字不合法 → 拒绝，reason 写出拿到的值。没设 `CANON_SUBAGENT` 的 worker 仍按 BR-2468 认。

## 例子

- 会话 `a69bb94c-570e-4fcb` 的环境里 `CANON_SUBAGENT=worker-w6`，不带 `--as` → 执行者是 `agent:a69bb94c:worker-w6`
- 同上，`--as worker-w6` → 执行者是 `agent:a69bb94c:worker-w6`；`--as w1` → 用法错误，信息含 `does not match CANON_SUBAGENT=worker-w6`
- `CANON_SUBAGENT=worker-w6` 和 `CANON_ACTOR=agent:x` 都设了 → 用法错误，信息含 `both name the actor`
- `CANON_SUBAGENT=a:b` → 用法错误，信息含 `CANON_SUBAGENT="a:b"`
- 不在会话里（没有 `CLAUDECODE`），`CANON_SUBAGENT=w1` → 用法错误，信息含 `CANON_SUBAGENT is only for workers`
- hook 环境里 `CANON_SUBAGENT=worker-w6`：`canon work land --finish` → 放行；`canon work land --as worker-w6` → 放行；`canon work land --as w1` → 拒绝，reason 含 `started with CANON_SUBAGENT=worker-w6`；`canon work take C-5 --from x` → 拒绝，reason 含 `canon work take is for the main session only`
- hook 环境里 `CANON_SUBAGENT=a:b`，`canon work land` → 拒绝，reason 含 `CANON_SUBAGENT="a:b"`
