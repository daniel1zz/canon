## 规则

`canon work check-as --hook`（BR-2340）遇到没有 `agent_id` 的调用、命令里又有认领命令时，读一次进程表：从 hook 进程往上找，在第一个名字是 `claude` 的进程（这个会话自己的进程）之上还有名字是 `claude` 的进程，这个会话就是别的会话启动的 worker（名字取可执行文件路径的最后一段，要完全等于 `claude`）。worker 的调用按子 agent 处理，名字由它自己定：

- `start`、`land`、`stop`、`drop` 没有 `--as`，或有几个不同的 `--as`，或值不只含字母、数字、`-`、`_` → 拒绝，reason 写 `Re-run the same command with --as <your worker name> appended`，有值时写出拿到的值；
- 只有一个合法的 `--as` 值（可以出现多次）→ 放行，执行者按 BR-2023 是 `agent:<会话>:<名字>`，所以 BR-2454 的连续被拒和 BR-2455 对它照常生效；
- `take`、`unstall` 带不带 `--as` 都拒绝，同 BR-2340 对子 agent 的拒绝。

`CANON_ACTOR` 的拒绝按 BR-2340，不读进程表。有 `agent_id` 的调用、没有认领命令的命令不读进程表。进程表读不出来时放行，按 BR-2341 记 `hook.skip`。只在 hook 里认 worker：`canon` 命令本身照 BR-2023 不验证 `--as`。

## 例子

- 进程链 主会话 `claude` → `zsh` → worker 的 `claude` → `sh` → hook，命令 `canon work land --finish` → 拒绝，reason 有 `--as <your worker name>`
- 同一条链，`canon work land --finish --as worker-w6` → 放行
- 进程链里只有一个 `claude`（主会话），`canon work land --as w1` → 按 BR-2340 拒绝，reason 有 `--as is only for subagents`
- 上面的进程叫 `Claude`（桌面应用）或 `claude-helper` → 不算，仍是主会话
- worker 运行 `canon work land --as w1 --as w2` → 拒绝，reason 有 `Got --as 'w1', 'w2'`；`--as a:b` 或 `--as ''` → 拒绝
- worker 运行 `canon work take C-5 --from x --as w1` 或 `canon work unstall C-5 --reason x` → 拒绝，reason 有 `is for the main session only`
- worker 运行 `canon work test --as w1` → 不是认领命令，放行，不读进程表
- 没有 `agent_id`、`ls; canon work test`，或有 `agent_id` 的 `canon work land` → 不读进程表
- 进程表读不出来，`canon work land --as w1` → 放行，`hook.skip` 的 `reason` 是 `process-table`，`sub` 是 `land`
