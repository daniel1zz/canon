---
id: BR-2129
title: 主会话可以显式放开自己子 agent 的认领
status: active
---

## 规则

在一个 worktree 里，认领由子 agent `agent:<s>:<id>` 持有且仍然有效时，同一个会话的主会话 `agent:<s>`（BR-2023）可以运行 `canon work stop --release --takeover --next "<下一步>"` 放开它：记下交接记录（执行者是 `agent:<s>`），删除认领，事件表记一条 `claim.release`（带 `from: <子 agent>`、`reason: takeover`），退出码 0。原因：子 agent 和主会话是同一个进程，子 agent 结束了，进程探测（BR-2100）也放不开它的认领。不带 `--takeover` 时照 BR-2104 拒绝（退出码 5），提示里写明可以用 `--takeover`。别的执行者（同一会话的其他子 agent、别的会话、人）带 `--takeover` 也被拒绝（退出码 5，记 `claim.refuse`）；认领是自己的、已经失效或没有认领时，`--takeover` 不起作用，按普通的 `stop --release` 处理。`--takeover` 不带 `--release` 是用法错误（退出码 2）。主会话不能替子 agent 续期、停下而保留认领或合入。

## 例子

- `agent:3d606482:aaa` 认领 `C-1`，`agent:3d606482` 在那个 worktree 里运行 `canon work stop --release --takeover --next x` → 退出码 0，`C-1` 没有认领，交接记录的执行者是 `agent:3d606482`
- 同样情形，`agent:3d606482` 只运行 `canon work stop --release --next x` → 退出码 5，提示里有 `--takeover`，认领仍归 `agent:3d606482:aaa`
- 同样情形，`agent:3d606482:bbb`（兄弟子 agent）运行 `canon work stop --release --takeover --next x` → 退出码 5，认领不变
- 同样情形，`agent:ffffffff`（别的会话）带 `--takeover` → 退出码 5
- `agent:3d606482` 运行 `canon work stop --takeover --next x`（没有 `--release`）→ 退出码 2
- 同样情形，`agent:3d606482` 运行 `canon work land --finish` → 退出码 5，main 不动
