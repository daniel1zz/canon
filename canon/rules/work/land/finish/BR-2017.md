## 规则

`canon work land` 移动 main 时，以本次 rebase 使用的 main 提交为比较并交换的基准：main 仍是这个提交时才移到合入的提交；已经变了时不覆盖它，合入被拒绝，原因 `main-moved`，退出码 1，提示重新合入。比较并交换不以 floor 已运行作为前提；floor 的运行或省略条件由 BR-2014、BR-2218、BR-2164 定义。

## 例子

- 先测再合，floor 通过且 main 仍是本次 rebase 使用的 main 提交 → main 移到合入的提交
- 按 BR-2218 先合后测、或按 BR-2164 跳过 floor 的合入，其余步骤通过且 main 未变 → main 移到合入的提交
- floor 运行期间 main 被移走 → 原因 `main-moved`、退出码 1，提示重新合入，main 保持别人移到的位置
- 先合后测，`before_land` 执行期间 main 被移走 → 同样以 `main-moved`、退出码 1 拒绝，main 保持别人移到的位置
