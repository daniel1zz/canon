title: 测过的提交才能成为 main：合入过程中 worktree 变了就拒绝
status: active
---

## 规则

`canon work land` 在 rebase 之后记下 HEAD 的提交，floor、`canon check`、规则评审和 `before_land` 都针对这个提交（`CANON_HEAD` 就是它）。移动 main 之前再看一次 worktree：HEAD 不再是这个提交，或者有未提交、未跟踪的改动（包括 floor 自己写出、没有被 git 忽略的文件）→ 不移动 main，拒绝，原因 `moved-during-land`，退出码 1，提示写明 HEAD 从哪个提交移到了哪个提交、多出来的提交和未提交的文件。

## 例子

- floor 跑的时候有人在这个 worktree 里提交了 `sneaky` → 原因 `moved-during-land`，提示里有 `sneaky`，main 不动
- floor 在 worktree 里写出没有被忽略的 `stray.txt` → 原因 `moved-during-land`，提示里有 `uncommitted: ?? stray.txt`
- floor 结束后 HEAD 还是 rebase 后的提交、worktree 干净 → 合入的正是这个提交
