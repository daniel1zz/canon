## 规则

等待合入的条目先按变更的档位轮到（BR-2602）：`P0` 最先（修复 main 的变更总是 `P0`，同是 `P0` 时它在负责人定的 `P0` 前面），然后 `P1`、`P2`、`P3`；同一档里按原来的顺序（BR-2232、BR-2363、BR-2399）；`canon backlog urgent` 标的就是负责人定的 `P1`，所以只出现在 `P1` 里。档位在每次查看轮次时重读，设了之后的下一次轮次就生效。正在合入的条目不被打断（BR-2178），一起测取成员按同样顺序（BR-2172）。杂务没有档位，算 `P2`（D-155）。

## 例子

- 队列里依次是 `C-1`（`P2`）、`C-2`（`P3`）、`C-3`（主 agent 定的 `P1`）→ 轮次 `C-3`、`C-1`、`C-2`
- 修复 main 的 `C-9` 和负责人定为 `P0` 的 `C-4` 都在等 → `C-9` 先
- `C-5` 是 `P2`，在 `优先合入` 一节里；`C-6` 是 `P2`、不在 → `C-5` 先
- `C-1` 正在合入时 `C-3` 被调成 `P1` → `C-1` 不被打断，下一个是 `C-3`
