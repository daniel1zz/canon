## 规则

`canon backlog urgent` 标记和 `--clear` 撤销都必须带非空白的 `--relayed "<负责人的原话>"`：没有或者只有空白时退出码 2，数据库不变，事件表记 `urgent.refuse`，原因 `no-relayed`。成功的标记记 `urgent.set`，成功的撤销记 `urgent.clear`，事件里都有原话，操作者是执行命令的那个人或 agent（BR-2023）。原话只用于事后查，canon 不核对它（D-6）。命令的帮助写明：agent 只在负责人在对话里要求时才用，不为催自己的变更用；`canon brief` 的工作说明里有同样的一句。

## 例子

- agent 执行 `canon backlog urgent C-2` → 退出码 2，没有标记，事件表有 `urgent.refuse`（`no-relayed`）
- agent 执行 `canon backlog urgent C-2 --relayed "  "` → 退出码 2，同上
- agent 执行 `canon backlog urgent C-2 --relayed "C-2 先合"` → 成功，事件表有 `urgent.set`，里面有 `C-2 先合` 和这个 agent 的操作者
- `canon backlog urgent C-2 --clear`（没带原话）→ 退出码 2，标记仍在
- 没有被标过的 C-2 执行 `--clear`（没带原话）→ 退出码 2，不是 3：先检查原话，再看有没有标记
- `canon backlog urgent --help` 的输出里有“only when the owner asked”的说明；`canon brief` 的输出里有 `canon backlog urgent` 一句
