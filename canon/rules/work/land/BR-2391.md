title: 前台收到 SIGINT、SIGTERM 或 SIGHUP 只脱离，后台合入继续
status: active
---

## 规则

跟随后台合入的 `canon work land`（BR-2390、BR-2392）收到 SIGINT、SIGTERM 或 SIGHUP 时只脱离：把已经写出的输出打印完，在标准错误说明合入在后台继续（写出后台合入的进程号）、怎么接上（在这个 worktree 再运行 `canon work land`）、怎么停止（`canon work land --stop`），以 75 退出。后台合入不受影响：不在前台的进程组里，收不到前台的信号，照常合入、记下自己的结果。要停止合入用 `canon work land --stop`（BR-2393）或直接向后台合入进程发信号（BR-2099）（D-80）。

## 例子

- 合入在跑 floor 时前台收到 SIGTERM → 前台退出码 75，标准错误有 `detached`；之后后台合入照常合入，事件表有 `land.ok`，没有 `land.killed`
- 前台收到 SIGINT（Ctrl-C）→ 同上，退出码 75，不是 130
- 前台没有收到信号 → 不打印脱离的说明，退出码是合入的退出码
