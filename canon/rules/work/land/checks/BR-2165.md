id: BR-2165
title: floor_skip_paths 不能覆盖决定合入怎么跑的文件
status: active
---

## 规则

`floor_skip_paths` 是仓库内的相对路径列表（目录或文件，不以 `/` 开头、不含 `.` 或 `..` 段、不以 `/` 结尾）。有一项等于 `canon`、`canon/config.yaml` 或 `canon/templates`，或者在 `canon/templates` 目录下 → 所有命令以退出码 2 失败，提示这一项会让改动 floor 命令或文档模板的合入不跑 floor。不是字符串列表、有一项格式不对 → 同样退出码 2。没写这个 key 时是空列表，合入总是跑 floor（BR-2164）。格式对、但测试会读其中的文件时，由 `test_select_command` 在合入时发现，floor 照常运行（BR-2164），不在读配置时拦。列表不为空而没有配 `test_select_command`（或是空串）→ 同样退出码 2，提示里有 `test_select_command`：只改这些路径的合入跳过 floor，靠的就是它说没有测试读这些路径。

## 例子

- `floor_skip_paths: [canon/rules, canon/decisions]` → 正常读取
- `floor_skip_paths: [canon]` → 退出码 2，提示里有 `canon/config.yaml`
- `floor_skip_paths: [canon/templates/rule.md]` → 退出码 2
- `floor_skip_paths: [/abs/docs]` 或 `[canon/rules/]` 或 `canon/rules`（不是列表）→ 退出码 2
- 没写 `floor_skip_paths` → 空列表
- `floor_skip_paths: [canon/rules]`，没写 `test_select_command` → 退出码 2，提示里有 `floor_skip_paths` needs `test_select_command`
