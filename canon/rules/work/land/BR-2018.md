## 规则

`canon work land --finish` 在一个随工作一起合入的提交里把变更状态设为 `done`，合入成功后释放认领，并删除这个变更的 handoff。只放开仍由自己在这个 worktree 里持有的认领，也只在放开了它时删除 handoff：合入期间认领已被别的会话接手（例如合入者的会话进程退出后按 BR-2100 接手）时，别人的认领和 handoff 都保持不变，输出里写明 `claimed by another session now`。

## 例子

- `canon work land --finish` 成功 → main 上 `C-1` 的状态是 `done`，`canon work status` 里没有 `C-1` 的认领和 handoff
- 合入等待期间 `C-1` 的认领被 agent:b 接手、agent:b 写了 handoff → 合入成功、`C-1` 是 `done`，但认领仍归 agent:b，handoff 还在
