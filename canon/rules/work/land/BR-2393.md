## 规则

`canon work land --stop` 向这个 worktree 正在运行的合入（最近一条 `land.start` 没有结果、进程还在，BR-2308）的进程发 SIGTERM，合入按 BR-2099 让出轮次、撤回关闭提交并记 `land.killed`；它等这个进程结束，带 `run` 时打印它的输出（并记下 `seen`），然后说明已经停止、以 0 退出。这个 worktree 没有正在运行的合入 → 退出码 3，信息写明没有在跑的合入；进程发不了信号（例如属于别的用户）→ 退出码 4。`--stop` 只能和 `--as` 一起用，带 `--finish` 或 `--timeout` → 退出码 2，什么都不做（D-80）。

## 例子

- 合入在跑 floor 时 `canon work land --stop` → 退出码 0；排队条目失败、结果 `killed`；事件表有 `land.killed`；后台合入进程已经不在
- 没有在跑的合入时 `canon work land --stop` → 退出码 3
- `canon work land --stop --finish` → 退出码 2，不发信号
- 记下的合入进程属于别的用户（例如 pid 1），发信号被拒绝 → 退出码 4，信息写明发不了信号
