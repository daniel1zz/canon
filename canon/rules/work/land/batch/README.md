# 一起测（work/land/batch）

配了 `land_batch_max` 时（`floor_timing` 为 `after` 时不一起测），轮到的合入者把紧跟在后面等着的几个合入一起测：在临时 worktree 里组成一条提交链，每个变更自己的步骤各跑一次，floor 只在链顶跑一次，全部通过就一次把 main 移到链顶（D-26）。没有整体通过时成员回到队列，各自单独合入，不会因为别人被拒；和成员无关的原因（建不了临时 worktree、领头失去轮次）不标单独合入。成员被合入后，它自己的分支和文件跟上 main 上的提交，跟不上时保持原样。

不管：每个变更自己的步骤查什么（`work/land/checks`）、排队顺序和轮次（`work/land/queue`）、移动 main 的比较并交换（`work/land/finish`）。

## 术语

- **领头**：拿到轮次、组织这一批的合入者。
- **成员**：被领头拉进这一批的、排在后面等着的合入。
- **提交链**：成员按顺序逐个 rebase 到前一个之上组成的提交序列，链顶成为 main。
- **锁定**：领头在移动 main 之前把全部成员锁住，之后成员被信号终止也不放弃自己的条目。
- **单独合入（solo）**：一起测失败后成员带上的标记，之后只能自己单独合入。
