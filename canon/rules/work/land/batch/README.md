# 一起测（work/land/batch）

配了 `land_batch_max` 时（`floor_timing` 为 `after` 时不一起测），轮到的合入者把紧跟在后面等着的几个合入一起测：在临时 worktree 里组成一条提交链，每个变更自己的步骤各跑一次，floor 只在链顶跑一次，全部通过就一次把 main 移到链顶（D-26）。没通过时只有出问题的成员受影响：自己的步骤不过的成员回到队列，floor 不过时按前缀二分找出让它失败的那个变更并拒绝它，前面通过的照常合入（D-42）。成员被合入后，它自己的分支和文件跟上 main 上的提交，跟不上时保持原样。

不管：每个变更自己的步骤查什么（`work/land/checks`）、排队顺序和轮次（`work/land/queue`）、移动 main 的比较并交换（`work/land/finish`）。

## 术语

- **领头**：拿到轮次、组织这一批的合入者。
- **成员**：被领头拉进这一批的、排在后面等着的合入。
- **提交链**：成员按顺序逐个 rebase 到前一个之上组成的提交序列，链顶成为 main。
- **锁定**：领头在移动 main 之前把全部成员锁住，之后成员被信号终止也不放弃自己的条目。
