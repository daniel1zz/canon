title: 每次协调写入都记录是谁做的，agent 永远不会被记成人
status: active
---
每条事件、认领、handoff 和问题都记录操作者，按以下顺序确定：

1. `CANON_ACTOR`，有值且不为空时使用。在 Claude Code 会话里（`CLAUDECODE=1`），它必须以 `agent:` 开头；其他值会以退出码 2 拒绝，什么都不写。
2. 在 Claude Code 会话里：`agent:` 加上 `CLAUDE_CODE_SESSION_ID` 的前 8 个字符；该变量没有设置或为空时，用 `agent:unknown`。
3. 其他情况：`human:<操作系统用户名>`。
