## 规则

操作者按顺序确定：`CANON_ACTOR` 有值时用它（在 Claude Code 会话里必须以 `agent:` 开头，否则退出码 2、什么都不写）；否则在 Claude Code 会话里（`CLAUDECODE=1`）用 `agent:` 加 `CLAUDE_CODE_SESSION_ID` 的前 8 个字符，该变量为空时用 `agent:unknown`；其他情况用 `human:<操作系统用户名>`。子 agent 的 Bash 调用由 `canon hook pre-bash` 设成 `CANON_ACTOR=agent:<会话前 8 个字符>:<agent_id>`（BR-2127），所以每个子 agent 是一个单独的执行者，和主会话 `agent:<会话前 8 个字符>`、和兄弟子 agent 都不同；事件表、认领、交接记录和 `canon work status` 记的都是这个完整的值。在 Claude Code 会话里（`CLAUDECODE=1` 且 `CLAUDE_CODE_SESSION_ID` 不为空），`CANON_ACTOR` 形如 `agent:<x>:<y>`、而 `<x>` 不是本会话 id 的前 8 个字符时（从别的会话继承或复制来的值），以退出码 2 拒绝，什么都不写。

## 例子

- Claude Code 会话，会话 ID `89d45e3f-b9c5` → `agent:89d45e3f`
- Claude Code 会话里设置 `CANON_ACTOR=human:alice` → 退出码 2
- 普通终端，用户 `apple` → `human:apple`
- 会话 `3d606482-8b99` 的子 agent，`CANON_ACTOR=agent:3d606482:add88b47` → `agent:3d606482:add88b47`；它认领的变更在 `canon work status` 里显示 `agent:3d606482:add88b47`
- 会话 `3d606482-8b99` 里 `CANON_ACTOR=agent:89d45e3f:add88b47` → 退出码 2
- 普通终端（没有 `CLAUDECODE`）里 `CANON_ACTOR=agent:89d45e3f:add88b47` → 照用
- 会话 `3d606482-8b99` 里 `CANON_ACTOR=agent:x`（不是子 agent 的形式）→ 照用
