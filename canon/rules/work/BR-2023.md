## 规则

操作者按顺序确定：`canon work start`、`stop`、`land`、`drop` 带 `--as <名字>` 时是 `agent:` 加会话 ID 前 8 个字符再加 `:<名字>`（名字就是 Claude Code 给子 agent 的 `agent_id`；名字只含字母、数字、`-`、`_`，不在 Claude Code 会话里、或 `CANON_ACTOR` 也有值时退出码 2，什么都不写）；否则 `CANON_ACTOR` 去掉首尾空白后有值时用它（在 Claude Code 会话里必须以 `agent:` 开头，否则退出码 2、什么都不写）；否则在 Claude Code 会话里（`CLAUDECODE=1`）用 `agent:` 加 `CLAUDE_CODE_SESSION_ID` 的前 8 个字符，该变量为空时用 `agent:unknown`；其他情况用 `human:<操作系统用户名>`。不带 `--as` 的调用，同一个会话的主会话和所有子 agent 是同一个执行者 `agent:<会话>`；子 agent 带 `--as <自己的 agent_id>` 时是 `agent:<会话>:<agent_id>`，和主会话分得开，主会话不带名字（D-62，装了 hook 的项目里由 hook 强制，BR-2340）。canon 不给子 agent 注入身份，也不验证 `--as` 的值是不是它的 `agent_id`（事件里记的 worktree 见 BR-2131）。`CANON_ACTOR` 的值是一个不透明的名字，`agent:x:y` 这种含冒号的值也照原样使用，不解析。

## 例子

- Claude Code 会话，会话 ID `89d45e3f-b9c5` → `agent:89d45e3f`
- Claude Code 会话里设置 `CANON_ACTOR=human:alice` → 退出码 2
- 普通终端，用户 `apple` → `human:apple`
- `CANON_ACTOR` 只有空格 → 当作没有设置，按后面的顺序确定
- 会话 `3d606482-8b99` 的子 agent 不带 `--as`（环境和主会话一样）→ `agent:3d606482`，和主会话相同
- 会话 `3d606482-8b99` 的子 agent `a1b2` 运行 `canon work start C-1 --as a1b2` → `agent:3d606482:a1b2`，认领的持有者是它；主会话 `agent:3d606482` 在那个 worktree 运行 `canon work land` → 退出码 5
- `--as a1b2` 和 `CANON_ACTOR=agent:x:y` 同时给 → 退出码 2，没有认领、没有事件
- `--as 'a b'`、`--as ''`、`--as a:b` → 退出码 2，什么都不写
- 普通终端（没有 `CLAUDECODE`）里 `canon work start C-1 --as a1b2` → 退出码 2
- 子 agent 第二次运行 `canon work land` 忘了 `--as` → 执行者是 `agent:3d606482`，不是持有者 `agent:3d606482:a1b2`，退出码 5
- Claude Code 会话 `3d606482-8b99` 里设置 `CANON_ACTOR=agent:89d45e3f:add88b47` → 照用 `agent:89d45e3f:add88b47`
