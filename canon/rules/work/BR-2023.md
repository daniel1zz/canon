## 规则

操作者按顺序确定：`CANON_ACTOR` 有值时用它（在 Claude Code 会话里必须以 `agent:` 开头，否则退出码 2、什么都不写）；否则在 Claude Code 会话里（`CLAUDECODE=1`）用 `agent:` 加 `CLAUDE_CODE_SESSION_ID` 的前 8 个字符，该变量为空时用 `agent:unknown`；其他情况用 `human:<操作系统用户名>`。

## 例子

- Claude Code 会话，会话 ID `89d45e3f-b9c5` → `agent:89d45e3f`
- Claude Code 会话里设置 `CANON_ACTOR=human:alice` → 退出码 2
- 普通终端，用户 `apple` → `human:apple`
