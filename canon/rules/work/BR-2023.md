## 规则

操作者按顺序确定：`CANON_ACTOR` 去掉首尾空白后有值时用它（在 Claude Code 会话里必须以 `agent:` 开头，否则退出码 2、什么都不写）；否则在 Claude Code 会话里（`CLAUDECODE=1`）用 `agent:` 加 `CLAUDE_CODE_SESSION_ID` 的前 8 个字符，该变量为空时用 `agent:unknown`；其他情况用 `human:<操作系统用户名>`。执行者只到会话一级：同一个会话的主会话和所有子 agent 是同一个执行者，canon 不给子 agent 注入单独的身份，一个 agent 在哪个变更上工作由它所在的 worktree 决定（D-18，事件里记的 worktree 见 BR-2131）。`CANON_ACTOR` 的值是一个不透明的名字，`agent:x:y` 这种含冒号的值也照原样使用，不解析。

## 例子

- Claude Code 会话，会话 ID `89d45e3f-b9c5` → `agent:89d45e3f`
- Claude Code 会话里设置 `CANON_ACTOR=human:alice` → 退出码 2
- 普通终端，用户 `apple` → `human:apple`
- `CANON_ACTOR` 只有空格 → 当作没有设置，按后面的顺序确定
- 会话 `3d606482-8b99` 的子 agent（环境和主会话一样）→ `agent:3d606482`，和主会话相同
- Claude Code 会话 `3d606482-8b99` 里设置 `CANON_ACTOR=agent:89d45e3f:add88b47` → 照用 `agent:89d45e3f:add88b47`
