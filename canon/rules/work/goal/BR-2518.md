## 规则

目标按会话身份记在协调数据库里（D-132）：Claude Code 会话是 `agent:<会话 id 前 8 位>`，Codex 会话是 `agent:codex-<会话 id>`，和 canon 在这些会话里认出的身份相同。不在 Claude Code 或 Codex 的会话里运行（认不出会话）时，三个命令都退出码 2，提示目标模式只给 agent 会话用。

- `canon goal start [<版本编号>...]` 开启目标模式：给了版本编号时目标就是这些版本，每个都必须存在（否则退出码 3）且不是 `shipped` 或 `dropped`（否则退出码 1）；没给时取进行中的版本（BR-2505 的选法），一个也没有时退出码 1，提示先用 `canon release new` 或 `canon release start`。这个会话已经有目标时换成新的。输出 `goal: <版本编号，逗号分隔>`，再每个版本一行：`<编号>  <状态>  <标题>  成功标准 <总数> 条：…`（同 BR-2506 的那一行），退出码 0。
- `canon goal stop` 结束这个会话的目标模式，输出 `goal stopped`；没有目标时输出 `no goal`，都是退出码 0。
- `canon goal`（不带子命令）输出这个会话的目标，格式同 `start` 的输出；没有时输出 `no goal`，退出码 0。`--json` 输出 `{"releases": [...], "started_at": "<时间>"}`，没有时 `null`。

## 例子

- Claude Code 会话里 `canon goal start`，`R-5` active → `goal: R-5` 和 `R-5` 那一行，退出码 0
- `canon goal start R-6`，`R-6` planned → 目标是 `R-6`
- `canon goal start R-1`，`R-1` 已发布 → 退出码 1
- `canon goal start R-99` → 退出码 3
- 没有进行中的版本，`canon goal start` → 退出码 1
- 已有目标 `R-5`，再 `canon goal start R-6` → 目标换成 `R-6`
- `canon goal stop` 之后 `canon goal` → `no goal`
- 普通终端里（不在 agent 会话里）`canon goal start` → 退出码 2
- 两个会话各自开启 → 互不影响，各自 `canon goal` 只看到自己的
