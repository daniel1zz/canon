## 规则

停下时的调度检查（BR-2655）默认对每个主会话都开着，不用开启（D-170）。`canon goal dispatch [on|off]` 只在 agent 会话里运行，会话身份同 BR-2518 的算法；不在 agent 会话里时退出码 2，提示同 `canon goal start`。

- `canon goal dispatch off`：记下这个会话关了调度（重复运行不报错），记一条 `dispatch.off` 事件，输出 `dispatch check: off for this session (canon goal dispatch on turns it back on)`，退出码 0。用于负责人要求暂停时：关掉之后这个会话停下时不再因为待办清单被拦下，目标模式（BR-2519）不受影响。
- `canon goal dispatch on`：删掉这条记录（本来就开着也不报错），记了才记一条 `dispatch.on` 事件，输出 `dispatch check: on`，退出码 0。
- `canon goal dispatch`：输出 `dispatch check: on` 或 `dispatch check: off for this session (canon goal dispatch on turns it back on)`，退出码 0。
- 给了 `on`、`off` 以外的参数 → 退出码 2。

开关只属于运行它的会话：别的会话照常被检查。

## 例子

- 会话 A 运行 `canon goal dispatch off` → 输出 `dispatch check: off …`；A 停下时调度检查放行，会话 B 停下时照常检查
- A 再运行 `canon goal dispatch` → `dispatch check: off for this session …`
- A 运行 `canon goal dispatch on` → `dispatch check: on`，之后 A 停下时又会被检查
- 在 agent 会话之外运行 `canon goal dispatch off` → 退出码 2
- `canon goal dispatch pause` → 退出码 2
