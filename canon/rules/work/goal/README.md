# 目标模式（work/goal）

会话主动开启目标模式之后，canon 让它朝进行中版本的成功标准一直做下去：会话要停下时，Stop hook 看目标达成了没有，还有能做的就让它接着做，并提醒它最近的工作有没有偏离目标（D-132）。不开目标时，主会话要停下前，Stop hook 也会把待办清单里它现在能做的事拦下来提醒一次（D-170）。

不管：成功标准的状态和编号（`knowledge/releases`）、总览怎么算（`work/overview`）；hook 怎么装进项目（`install`）。

## 术语

- **目标**：一个会话开启目标模式时选定的版本，包括它们的模块；目标没达成，是指其中还有未满足或未证明的成功标准。
- **没有进展**：两次拦下之间，main 的提交、这个工作树的提交和它没提交的改动都没变。

## 业务

- **开启和结束**：会话怎么开启、结束和查看自己的目标模式，怎么关掉和打开停下时的调度检查。
- **停下时的判断**：会话要停下时，什么情况让它接着做（目标没达成、待办清单里有它现在能做的事）、说些什么，什么情况放行。
