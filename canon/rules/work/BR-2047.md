## 规则

变更的 worktree 建在 worktree 目录下的 `<C-n>`。worktree 目录默认是主 checkout 的路径加上 `.worktrees`；配置了 `worktrees` 时用它，相对路径按主 checkout 解析。`canon work clean` 只处理这个目录下的 worktree。

## 例子

- 没配置，主 checkout 是 `~/p/app` → 建在 `~/p/app.worktrees/C-1`
- `worktrees: ../wt`，主 checkout 是 `~/p/app` → 建在 `~/p/wt/C-1`
- `worktrees: ../wt` 时，`~/p/app.worktrees/` 下留着的旧 worktree → `canon work clean` 不处理它
