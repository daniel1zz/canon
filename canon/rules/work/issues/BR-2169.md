## 规则

一个提交的标题或正文满足下面任一条，就算写明修复了 issue `#n`：GitHub 的关闭关键字（`close`、`closes`、`closed`、`fix`、`fixes`、`fixed`、`resolve`、`resolves`、`resolved`，不分大小写，后面可以有冒号）后面紧跟 `#n`；或者在一对括号（半角或全角）里，同时写了一个变更编号和 `#n`。`canon work start` 开变更时做的提交（标题以 `canon: open ` 开头）只说明这个变更针对哪个 issue，不算修复。只写 `#n`、不在上面两种写法里的，也不算。

## 例子

- `Take the close commit back by a compare-and-swap on HEAD (C-117, #34)` → 修复 #34
- `canon brief picks the latest background batch (C-105, fixes #28)` → 修复 #28
- `Fixes: #3` 写在正文里 → 修复 #3
- `canon: open C-117 撤回关闭提交时用比较并交换（#34）` → 不算
- `see #12 for background` → 不算
- `(#12)`，括号里没有变更编号 → 不算
