## 规则

`canon issues` 运行 `gh` 时，`gh` 不在 PATH 上，以退出码 4（环境错误）失败，提示 `gh (the GitHub CLI) is not installed or not on PATH`，并说明去哪里装、要运行 `gh auth login`。`gh issue list` 失败而 `gh auth status` 也失败时，以退出码 4 失败，提示 `gh is not authenticated: run gh auth login`。`gh issue list` 因别的原因失败（比如仓库没有 GitHub 远端）时，以退出码 4 失败并带上 gh 的错误信息。这几种情况都不输出任何 issue，不当作“没有开着的 issue”。

## 例子

- PATH 上没有 `gh` → 退出码 4，stderr 含 `not installed or not on PATH`，stdout 没有汇总行
- `gh issue list` 和 `gh auth status` 都以 1 退出 → 退出码 4，stderr 含 `gh auth login`
- `gh issue list` 以 1 退出、报 `no git remotes found`，`gh auth status` 成功 → 退出码 4，stderr 含 `no git remotes found`
