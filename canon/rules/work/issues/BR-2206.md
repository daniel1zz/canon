## 规则

`canon issues` 列出一个 issue 时，main 上每个写明修复了它的提交各占一行，按 main 上的提交顺序新的在前（BR-2168）。`--json` 输出一个数组，顺序和文字输出相同（编号从大到小），每项正好有 `number`、`title`、`url`、`fixedBy` 四个字段；`fixedBy` 是写明修复了它的提交，每个有 `sha`（完整编号）和 `subject`（标题），新的在前，没有时是空数组。

## 例子

- main 上先有 `Fix part (C-1, #5)`、后有 `Fix rest (C-2, #5)` → #5 下面先列 `Fix rest`、再列 `Fix part`；JSON 里 `fixedBy` 也是这个顺序
- #7 没有提交写明修复 → JSON 里它的 `fixedBy` 是 `[]`
