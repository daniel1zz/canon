title: gh issue list 的输出不是 issue 列表时 canon issues 以退出码 4 失败
status: active

## 规则

`gh issue list` 成功退出，但输出不是 JSON，或者是 JSON 却不是一个列表时，`canon issues` 以退出码 4（环境错误）失败，错误信息写明 gh 的输出不对（不是 JSON 时带上输出的前 200 个字符），不输出任何 issue，不当作“没有开着的 issue”。

## 例子

- `gh issue list` 输出 `<html>` 并以 0 退出 → 退出码 4，stderr 含 `not JSON`，stdout 没有汇总行
- `gh issue list` 输出 `{}` → 退出码 4，stderr 含 `did not print a list`
- `gh issue list` 输出 `[]` → 退出码 0，汇总 `0 open issue(s)`
