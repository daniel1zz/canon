| 工具 | 实测 | 处理 |

| context7 | 一次找到 citty 文档（228 个示例） | 保留，`alwaysLoad: true` |
| grep MCP | 返回带上下文的代码段、支持正则；`gh search code` 每处一行、不支持正则 | 保留，`alwaysLoad: true` |
| deepwiki | 回答了 bun:sqlite 并发写入时 `.immediate()` 与 `busy_timeout` 的行为，和 SQLite 已知行为一致 | 保留；回答需核实 |
