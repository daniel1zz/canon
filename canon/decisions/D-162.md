## 背景

D-128 按角色划线：设计（决策、规则、产品承诺、发布范围、项目声明的设计文件）只由设计负责人写，worker 只在派发时固定的设计版本里实现；BR-2498 不让 worker 开变更和杂务，BR-2501 第 1 项拒绝 worker 合入改了设计的变更。

负责人 2026-11-22 在 #304 定：划线按模型能力，不按角色。当初要的是设计质量（“我要最佳的设计”），Opus 级模型的 worker 可以设计并自己合入，弱一些的模型只执行。同一天经主会话转达补充：“变更也是。opus模型可以开”，即 Opus 级 worker 也可以自己开变更。现在主会话是瓶颈：每个还没设计的变更都要等主会话来写设计、开变更，机器有空、worker 的模型同样强也用不上。#305 的设计 worker 本身就因为不能开变更停下等主会话。

## 方案

- **采用：启动 worker 的工具在环境里设 `CANON_WORKER_PROFILE=<档案名>`，main 上的 `design_profiles` 列出能设计的档案；hook 拒绝命令里自己设这个变量。** 能力跟着启动 worker 时选的档案走（档案定了用哪个模型），由启动方写进环境，和 `CANON_SUBAGENT` 同一个来路（D-125）；名单从 main 读，worker 改自己分支上的配置不生效。能设计的 worker 可以开变更和杂务、合入设计，派给它的变更仍受设计负责人和代次管（BR-2633）。
   - 来源：canon/rules/work/claims/BR-2495.md “启动 worker 会话的工具（派发方）可以在 worker 的环境里设”
- **否决：canon 读 worker 会话实际用的模型名。** Claude Code 和 Codex 都没有给子进程一个稳定的、写明模型的环境变量，模型名也会随版本改；档案是启动方自己的名字，项目按档案列名单更稳。
- **否决：worker 开工时自己声明 `--design`。** 自己说了算就等于没有划线，负责人要的是按能力划。
- **否决：直接读 delegate 工具的 `CLAUDE_DELEGATE_PROFILE`。** 那是某一个启动工具的变量；Codex 或别的工具启动的 worker 认不出。canon 自己定一个变量，各启动工具去设，和 `CANON_SUBAGENT` 的做法一样。
   - 来源：canon/decisions/D-125.md “CANON_SUBAGENT”
- **否决：不改，设计只由主会话做。** 正是负责人指出的瓶颈。
   - 来源：canon/rules/work/delegation/BR-2498.md “新的工作由设计负责人建好再派发”

## 决定

能设计的 worker 由启动方设的 `CANON_WORKER_PROFILE` 和 main 上的 `design_profiles` 决定：它可以开变更和杂务、合入设计文档，派给它的变更仍受设计负责人和代次管；hook 拒绝命令里自己设这个变量（BR-2633）。

## 后果

- 实现时修改 BR-2498、BR-2501（新文字在 C-693 的提议里）和 BR-2495 的 hook 部分。

- `design_profiles` 不配置时一切照旧；项目要启用，先让启动 worker 的工具设 `CANON_WORKER_PROFILE`（canon 仓库之外的工作，例如 delegate 工具），再在 main 的配置里列档案。
- hook 只看命令文字，把变量写进脚本再运行能绕过；这和 `CANON_SUBAGENT` 的信任程度一样，刻意绕过属于不正常的动作（D-54），记为已知限制。
- #304 里“设计只在分支上的变更也能派给能设计的 worker”这一条不在本决定里：派发时 canon 还不知道接收的 worker 用哪个档案，要另定。
- 外部边界：启动工具没设 `CANON_WORKER_PROFILE`、设的档案不在名单里、或 `design_profiles` 没配，worker 都按普通 worker 处理（开变更被 BR-2498 拒绝，合入设计被 BR-2501 拒绝），不会误放行。名单只随合入 main 的配置改变：加一个档案或删掉一个档案，从下一条命令起生效；已经由能设计的 worker 合入的设计不撤回，照常留在 main 上接受规则评审。
- 什么结果说明这个选择错了：能设计的 worker 合入的规则和决策，合入后规则评审的拦截意见明显多于主会话合入的（按合入者和档案分开比，`land.ok` 记下合入者，`work.start` 记下档案）；或者负责人在总览里抽查时发现这些设计要返工。出现时收紧名单，或回到按角色划线。
