## 背景

#170：一个变更合入时因为和规则无关的原因被拒（floor 失败、超时、冲突），再合入时规则文字一个字没改，规则评审却又完整跑一遍。zhushenkongjian 一天里合入评审通过 130 次、拦下 32 次、沿用只有 4 次，真正合入 77 次；每次评审调 2 到 9 次模型、每次约 300 KB，用完了提供方的 5 小时额度。

原因：沿用的键是整份评审提示的哈希（D-70、BR-2361），提示里带着整个顶层领域和全部规则索引（BR-2009、BR-2036）；main 上只要又合入了别的规则或决策，键就变了。合入越频繁越难沿用。

D-72 定了不为省钱缩小评审上下文，理由是召回：只给改动文档和它引用的文档，会漏掉和同领域别的规则的矛盾。负责人 2026-11-09 把怎么改交给 agent 判断（原话“按照你的判断来”）。先做的是减少重新合入的次数：C-435（#154）、C-438（#161）、C-428（#156）都已合入。

## 方案

1. 改动文档没变就无条件沿用上一次通过的评审（#170 原来的提议）：否决。上一次评审之后 main 上合入的规则和决策没人跟改动对照过，和它们的矛盾会漏掉。
   - 来源：canon/decisions/D-72.md “规则审查继续按 BR-2009 给整个顶层领域”
2. 保持现状，只靠减少重新合入：否决。重新合入少了，但每次仍完整评审；冲突、floor 失败、超时这些和规则无关的拒绝仍然存在，每次都要再付一次完整评审。
   - 来源：canon/decisions/D-70.md “键就是评审实际会发给模型的全部字节”
3. 改动文档和上一次通过的完整评审逐字节相同时，只拿改动文档和那次评审之后 main 上新增或改过的生效规则、已接受决策做一次小评审，没有这样的文档就沿用：采用。上一次评审已经把改动和那时的整个领域对照过；之后变的只有新合入的文档，小评审正好补上这一块。召回只在“需要旧文档和新文档一起才看得出”的矛盾上可能更低，而这种矛盾在新文档自己合入时已经和旧文档对照过一次。
   - 来源：canon/decisions/D-72.md “要推翻它，需要按 D-67 的方法用真实拦截记录测出不低于现在的召回”
4. 小评审只看和改动同一个顶层领域的新文档：否决。完整评审通过规则索引看得到别的领域，小评审只给同领域会比完整评审看得更少。小评审把所有领域新合入的文档全文给出，比索引里的标题还多，所以不需要完整索引；旧文档已经在上次完整评审里对照过。新合入的文档通常只有几份，全部给也不大。
   - 来源：canon/rules/knowledge/review/BR-2036.md “以便发现跨领域的矛盾和与决策的矛盾”

## 决定

用方案 3：

- 合入的规则评审调用之前，先按 BR-2361 看整份提示的键能不能沿用；不能时，再看这个变更最近一次合入规则评审（`review.ok` 或 `review.block`）里改动文档的键（`docs_hash`：改动和删除的规则、决策、版本、领域 README 的路径和全文，加上架构总览这次的 diff、`review` 命令文字和预算）和现在的一样、结论是 `ok`、记下了评审时的 main（`base`）。
- 满足时：从那次的 `base` 到这次 rebase 后的 main，main 上新增或改过的生效或规划中规则和已接受决策（不含改动文档本身）没有 → 沿用（记 `review.reused`，`by: docs`）；有 → 小评审：提示只含改动文档（包括改动的领域 README）、这些新文档的全文和原来的评审要求，并说明这是增量评审；领域正文和索引也只含这些文档；结论照常决定合入，记 `review.ok` 或 `review.block`，带 `incremental`（沿用的事件号和新文档）。
- 不满足（改动文档变了、上次被拦下、没有记下 `base`、那次的 `base` 读不到、要判断措辞而上次没有确认）→ 完整评审。
- 完整评审和小评审的事件都记 `docs_hash` 和 `base`，所以小评审之后再重新合入，接着从这次的 `base` 算。
- 完整评审的上下文不变（D-72 仍然有效）；预览评审（`canon work review`）和常驻说明的重复评审不变。
- `canon stats` 分开数合入时的完整评审、小评审和沿用。

## 后果

- 规则文字没变的重新合入，只在 main 上有新文档时花一次小调用，没有时不调用。
- 小评审通过时，意见是上次完整评审的意见加这次的意见，合入照常把它们都记下（BR-2145）；措辞判断沿用上次的。
- 用 zhushenkongjian 的事件再量一次：小评审和沿用各占多少，拦下的比例是否和完整评审相当；拦下明显更少时重新考虑。
