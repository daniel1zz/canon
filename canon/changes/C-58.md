## 为什么

D-6 让 agent 用 `--relayed` 转述负责人的原话，并且明说防不住冒充。lore 的 SPEC-234 在提问工具（AskUserQuestion）返回后挂了一个只记录的 hook，直接从 Claude Code 返回的数据里记下人的选择，agent 改不了这份记录。D-6 的备选方案里没有考虑这种做法。

## 要改什么

- 在项目的 `.claude/settings.json` 里合并一条 PostToolUse hook（只记录、不拦截，符合 D-1），把提问工具的问题和人的选择写进事件表。
- `canon human answer --relayed` 记下时，对照最近的这类记录，标出“和 Claude Code 的记录一致 / 没有对应记录”；`canon human pending --all` 显示这个标记。
- 修改 D-6（或新决策），规则和测试。

## 陷阱和假设

- 证据偏弱：lore 的 90 个问题只用上了 22 个，原因没有核实。先确认 PostToolUse 拿得到提问工具的回答内容。
