## 为什么

负责人要求 canon 的 skill 都是项目级别的：项目装了 canon 才有，不污染用户的全局配置。原来（D-7、D-8）是链接到 `~/.claude/skills/`，对这台电脑上所有项目都生效。取舍见 D-9。

## 要改什么

- `skills/` 搬到 `.claude/skills/`，作为源头。
- 新模块 `src/skills/install.ts` 和命令 `canon skills install [--force]`；`canon init` 时安装；用清单保护项目里改过的文件（BR-2080 到 BR-2082）。
- CLAUDE.md、cli 领域 README、D-8 的说法同步。
- 合入后删除 `~/.claude/skills/canon-*` 的 9 个链接，并确认编译后的 `dist/canon` 能找到源头。

## 陷阱和假设

- 编译后的 `dist/canon` 靠自己的真实路径找到 canon 仓库，假设它一直在 canon 仓库的 `dist/` 里；拷到别处运行要设 `CANON_SKILLS_SOURCE`。
- 根目录 `.gitignore` 里的 `settings.json` 会忽略 `.claude/settings.json`，不影响 skill。
