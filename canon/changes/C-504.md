## 为什么

## 要改什么

README 的业务一节写出 5 个业务，13 条生效规则全部归属。只加 front matter 的 `business`，`## 规则` 和 `## 例子` 一字不动，行为哈希不变（BR-2236）。

- 先合后测（2）：BR-2218、BR-2224

## 陷阱和假设

- BR-2313（显示没测过的合入个数和下一次测试时间）归在「什么时候开始测」：它显示的就是那条判断的结果，判断改了这一行跟着改。
