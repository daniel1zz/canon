## 为什么

`code-layout` 只看领域的代码目录在不在磁盘上。空目录在工作树里存在，git 却不保存它：C-568 只 `mkdir` 了 `src/work/delegation`，工作树里检查和合入都通过，合入后 main 上的 `canon check` 报 `code-layout`（#236）。

## 要改什么

领域的代码目录要含有至少一个文件（不算点开头的名字）才算有，否则报 `code-layout`，提示目录存在但没有文件。BR-2118 加这一句和例子。


## 教训

- 检查看工作树的文件系统，而合入的是 git 提交：两者不一样的地方（空目录、被忽略的文件）检查会放过 → 本变更只修了空目录这一处，由 BR-2118 的例子保证。
