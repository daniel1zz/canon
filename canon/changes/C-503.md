## 为什么

继续给没划业务的领域划。knowledge/plans 9 条规则一条都没写业务。这个领域里是四摊事：计划表怎么写、变更怎样认领步骤、状态怎么算、算出来的进度在哪几个命令里怎么说。

## 要改什么

README 加业务一节，写出 4 个业务，9 条生效规则全部归属。只加 front matter 的 `business`，`## 规则` 和 `## 例子` 一字不动，行为哈希不变（BR-2236）。

- 计划表的写法（2）：BR-2369、BR-2370
- 变更做哪几步（2）：BR-2371、BR-2389
- 步骤的状态（1）：BR-2372
- 进度怎么报（4）：BR-2373、BR-2374、BR-2383、BR-2384

## 陷阱和假设

- 「步骤的状态」单独一个业务：四种状态怎么算是三个报告命令共用的那一份判断，改输出格式不动它，改判断就一处改、三处都变。
