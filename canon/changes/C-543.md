## 为什么

codex 对 zhushenkongjian 的审计：评审意见 `#272`、`#273`（`untestable`）让主 agent 删掉了负责人定的体验目标、自行定了难度分档（D-115 的背景）；`contradiction` 不要求指出矛盾在哪。负责人授权修这两条标准和结案提示。

## 要改什么

按 D-115：`untestable` 认人工验收、不许为可测删改目标（BR-2473）；`contradiction` 要引两段原文和同一输入下的两个结果（BR-2474）；合入后日志的结案提示（BR-2442）和工作说明加一句：修意见不扩缩负责人的目标，只能那样修时问负责人。代码在 `src/knowledge/review`（review.ts、landed.ts、guide.ts）。

总览不受影响：总览没写评审标准的具体文字。
