## 为什么

2026-11-04 到 05 的并行运行里，子 agent 把测试或合入放在后台、用监视器等，自己先结束回复：一次合入随子 agent 一起被杀掉，没有任何报错（C-273 空等约 1 小时 45 分）；另有三个子 agent 结束后仍挂在界面上，显示还在等自己的后台任务，最后由主 agent 逐个停掉。负责人确认把预防和兜底写进 canon-parallel。

## 要改什么

canon-parallel 第 3 节加一条说明要求：子 agent 在前台跑测试和合入，结束前停掉自己启动的所有后台命令和监视器。第 5 节加一步：主 agent 核对完每个子 agent 的结果后停掉它。不改规则和代码。

## 教训

- 子 agent 留着后台任务就结束 → 只靠文字：Claude Code 没有可用的办法在子 agent 留有后台任务时阻止它结束；canon 这边的被杀合入已由 BR-2307 到 BR-2310 检测。
