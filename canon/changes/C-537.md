## 为什么

#205：`delegate` 用 `claude -p` 启动的 worker 没有 `agent_id`，hook 把它当主会话，拒绝它带 `--as`；它不带 `--as` 时按自己的会话 ID 记，分得开，但 canon 不知道它是 worker，BR-2454、BR-2455 对它不生效（D-111 的背景）。

## 要改什么

按 D-111：hook 遇到没有 `agent_id` 的认领命令时读进程表，会话进程上面还有 `claude` 的就是 worker，按 BR-2468 要求它带自己定的 `--as`；BR-2340 的主会话改成“没有 `agent_id`、也不是 worker”；BR-2341 加 `process-table`；BR-2023 写明 worker 的名字。代码在 `src/work/claims`（as-check.ts、as-hook.ts、liveness.ts）。

## 陷阱和假设

- 假设启动 worker 的工具不把它从父进程脱离；脱离了就认不出，照旧当主会话（D-111 后果）。
- 进程名按可执行文件路径的最后一段比较；测试用指向 bun、名字叫 `claude` 的符号链接搭进程链。
