## 为什么

每个领域的 README 写着它管哪些代码目录，`canon context <路径>` 靠这个找规则。代码挪走或改名之后，README 里的目录不会自动更新，`canon context` 就会悄悄找不到规则；新加的代码也可能不属于任何领域，没有任何规则描述它。现在 `canon check` 不检查这两件事。

## 要改什么

- `canon check` 新增：领域 README 里列出的代码目录必须存在，否则报错。
- `canon check` 新增：`src/` 下（具体范围可配置）每个源文件至少属于一个领域，否则报出没有归属的文件；测试文件和生成文件按配置排除。
- 规则和测试。
