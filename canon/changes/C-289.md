## 为什么

C-287 在 canon-parallel 里写了“只在四种情况下先停下报告”。负责人 2026-11-04 指出“我们这样写死这四种情况会不会太绝对了？”：清单之外明显该停的情况（派发说明的前提不成立、修法要和已接受的规则或决策矛盾）会被漏掉。负责人选择“原则 + 四个例子 (推荐)”，并说明分工：“主agent理论上用opus更智能，上下文更全，且作为调度指挥和决策，subagent更多的是执行”。

## 要改什么

- `.claude/skills/canon-parallel/SKILL.md` 第 3 节那一条改成原则加常见例子：主 agent 做决策，subagent 执行派发说明；继续做下去要做出派发说明没定的选择、或很可能做出主 agent 不想要的东西时，先停下报告并给出建议；派发说明范围内的小选择不停，做完。
- 不改规则和代码：skill 是文字。
