## 为什么

C-383 用了 `@daniel1zz/canon`，但发布用的 npm 账号是 `danielzz`，只能往 `@danielzz` 这个 scope 下发布。负责人定的包名是 `@danielzz/canon`。

## 要改什么

`package.json` 的 `name` 改成 `@danielzz/canon`；规则不变。
