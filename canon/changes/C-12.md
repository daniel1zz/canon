## 为什么

PATH 上的 `canon` 二进制不会随 main 更新：C-10 合入后它仍是旧版本，导致 C-5、C-11 用旧的英文模板建立，说明一直空着，而 `canon check` 不检查变更文件里残留的模板。

## 改了什么

- canon 自己的配置加上 `after_land: "bun run build"`，每次合入后在主 checkout 重新构建 `dist/canon`。
- BR-2035 扩展到变更：变更的说明没填（残留模板占位行）就不能合入。
- 补写 C-5、C-11 的说明。
