## 为什么

上一次写进 canon-parallel 的要求是“子 agent 在前台跑测试和合入”，但这做不到：Claude Code 会把子 agent 跑了约 3 分钟的命令自动转到后台（C-273 那次的记录里有 `"timedOutAfterMs":180000,"subagentCapApplied":true`，C-332 的子 agent 也报告 `canon work test` 在 180 秒后被转到后台）。测试和合入通常都超过 3 分钟。

## 要改什么

canon-parallel 第 3 节那条改成：命令被转到后台后，子 agent 等它的完成通知，命令结束前不结束回复、不交最终汇报；不另起后台命令或监视器，起了的在汇报前停掉。不改规则和代码。

## 教训

- 写进说明的要求没有先核对工具能不能做到 → 只靠文字：这次改正有记录可查，没有可以自动核对说明是否可行的检查。
