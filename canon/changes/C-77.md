## 为什么

issue #19（C-73 合入后的代码评审）：从分支读 `canon/` 时，分支名被放进 `sh -c` 的命令里，只用 `JSON.stringify` 加了双引号。git 允许分支名里有 `$(...)`，双引号里它照样会被执行，所以 `canon work start C-n` 会运行分支名里藏的命令。

## 要改什么

- `git archive` 和 `tar` 分开直接运行，不经过 shell，归档内容通过管道交给 `tar`。
- 测试：分支名里带 `$(touch …)`，接着做这个变更时标记文件不会出现（修复前会出现）。BR-2107 补一个例子。
