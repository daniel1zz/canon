## 为什么

C-514 合入后的 #71–#132 共 62 条阻塞意见归为六个根因：旧的无 --as 身份退化说明未限定 Claude Code；安装参数检查与用户 hook 检查的先后文字冲突；启动输入拒绝条件含糊；override 示例遗漏旧管理段迁移；技能更新冲突被重复写错；skill 再次复述 brief 的 worktree 路径要求。

生效依据是 C-514 / D-101 新增的 Codex 自动子线程归属与显式安装目标，以及未被替代的 BR-2089 本地修改保护。校正过时的复述和示例，不改变负责人的 Codex 工作流目标。

- BR-2023、BR-2104、BR-2131、BR-2336：把共享执行者、忘记 --as 丢失身份的退化情形限定为 Claude Code，Codex 行为统一引用 BR-2023。
- BR-2023：明确 SessionStart 只需 session_id，SubagentStart 还需 agent_id。

- BR-2460：迁移时只保持 AGENTS.md 的用户文字，旧管理段必须移除；补已有管理段迁入、迁回的 CLI 场景。
- BR-2410：技能本地修改的更新冲突直接引用 BR-2089，不再复述强制覆盖条件。
- canon-parallel 的 worktree 路径要求改为指向 canon brief，原要求在工作流 guide 保留。
