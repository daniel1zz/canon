## 为什么

issue #4：`canon human answer` 只检查有没有 TTY，agent 用 `script` 套一层伪终端就能替人回答，回答者记成 `agent:x`。这违反 P7（留给人的决定只由人做）。BR-2023 已经保证 Claude Code 会话里的操作者不会被记成人，所以“操作者必须是 `human:`”是一个可靠的判断条件。

这是 P7 的直接要求，没有别的合理方案（只靠 TTY 已经被证明可以绕过），所以不另写决策。

## 要改什么

- `answer()` 拒绝非 `human:` 的操作者（退出码 2），写 `human.answer.refuse` 事件；TTY 检查保留。
- BR-2021 写明这一点；补测试。`canon work drop` 自己对回答者的检查保留，作为第二道保护。
