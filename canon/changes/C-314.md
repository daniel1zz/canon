## 为什么

C-297 起评审在 main 提交的临时 worktree 里运行（BR-2216、D-51），那里只有提交进 git 的文件。评审脚本要用 `node_modules`、`.env` 或本地配置的项目，评审会失败、合入被拒，而拒绝信息只有命令的错误输出，看不出原因。负责人选择保留在临时 worktree 里运行，只补这条提示。

## 要改什么

评审命令运行不了（非 0 退出、无效结论、超时）时，拒绝信息另起一行写明 main 的提交、临时 worktree 的路径，以及被 git 忽略的文件不在那里。BR-2216 加上这句和两侧例子；`review.test.ts` 补测试。
