## 要改什么

新领域 `knowledge/check/design-basis`：

- BR-2491：`design_signals` 配三类单向门路径（默认包清单和锁文件、`**/migrations/**`）；在 worktree 里改到它们而变更没写 `## 方案依据` 时，`canon check` 给提示，列出每一类要回答的问题；不拦截。
- BR-2492：这次工作新加的、修改或取代已有决策的决策要写 `revised_because`（premise / requirement / external / experience / implementation），否则 `decision-revision-reason`。
- BR-2493：规则评审的提示让评审对方案依据只给 note：沿用夹带新选择、缺最坏失败或证伪条件、证据答非所问。
- BR-2494：合入后记一条 `design.basis` 事件，`canon stats` 按类别统计有没有写依据，按 `revised_because` 统计决策被修改的原因和 7 天内的次数。

canon-design skill 的“先看 1 到 3 个成熟产品”改成按不可逆程度决定调研深度。架构总览补上新目录。
