## 为什么

issue #83：每次 Bash 调用前的快照 hook 运行 `git status --porcelain`，git 刷新索引的 stat 信息时会拿 `.git/index.lock` 并写回索引。同一时刻在这个 worktree 里运行的 git 命令（合入时主 checkout 的 `git merge --ff-only`、后台合入的 commit 和 rebase）会因为锁被占而失败，被拒的原因和自己的改动无关。

## 要改什么

- `src/work/snapshots/snapshot.ts`：`git --no-optional-locks status --porcelain`。
- BR-2182：写明快照不拿索引的锁、索引文件不变，加一个例子；测试用过时的 stat 信息让 git 想写索引，断言索引文件一个字节都不变（不加修复时这个测试失败）。
