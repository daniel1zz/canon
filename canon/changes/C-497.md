## 为什么

`business-overlap`（BR-2447）要评审判断新业务和领域里已有的业务是不是同一件事，但提示里只有领域 README 的业务名字和说明，看不到每条规则属于哪个业务。两个名字不同的业务底下盖的是同一批规则时，评审没有依据看出来。

## 要改什么

- `canon context --full` 和评审提示里的领域全文：规则标题行带出 `[business: <业务名>]`（BR-2112、BR-2007）。
- 评审提示里改动的规则：标题行下面多一行 `business: <业务名>`，和决策的 `supersedes`、`amends` 同一种写法。
- 没有 `business` 的规则两处都不标。
- 改的规则：BR-2112（`--full` 的输出）、BR-2447（判 `business-overlap` 需要看见的东西）。
