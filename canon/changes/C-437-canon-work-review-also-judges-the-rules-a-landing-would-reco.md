## 为什么

#166：规则只改了 `## 规则`、`## 例子` 没变、又没有测试或验收证据时，canon 自动把它记成“只改措辞”（BR-2243），由合入评审判断这是不是真的只改措辞（BR-2239）。这个判断只在合入、排完一轮队之后才做；判断不是措辞时才发现要补证据，又得再排一轮。`canon work review` 预览按 BR-2358 不问这个判断，所以会话事先没法知道。

负责人 2026-11-09 定了（canon human #10，“预览评审也问（推荐）”）：`canon work review` 也问。

## 要改什么

- `canon work review` 对这次合入会被记成“只改措辞”的规则，也做和合入时同样的措辞判断，输出每条的结论；判断不是措辞的，写明合入时会因为缺证据被拒、要补什么。
- 预览仍然只是报告，不影响合入（BR-2358）；合入时照样再判断一次，以合入那次为准。
- 改 BR-2358、BR-2239，各补两侧例子：只改错字 → 预览说是措辞；改了行为 → 预览说不是措辞、要补证据。

不做：不加关掉“只改措辞”豁免的项目开关（负责人没选）；不改自动判定哪些规则算“只改措辞”的条件（BR-2243）。
