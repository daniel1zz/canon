## 陷阱和假设

- 读历史只针对现在不存在的候选路径，一次 `git log`；没有候选时不调用 git。不在 git 仓库里、又有候选时报一条读不到历史的发现，不悄悄放过。
- 文件名（不含 `/`）按“仓库里有没有同名文件”判断，会遍历一次仓库目录（跳过 `.git`、`node_modules`、`dist`、`.cache`）。
- 挪代码的变更在 open 时写旧位置会被报，写成不带反引号的文字即可。
