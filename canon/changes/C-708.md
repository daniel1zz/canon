## 为什么

负责人 2026-11-27（经 zhushenkongjian 主会话转述）：「canon管理的话这些资产应该是同步到项目级别的」。D-9 已经让 canon 的 skill 装在项目级别，但还有两类 canon 相关的东西留在用户主目录、换机器不会跟过去：

1. canon 自带的 skill 引用了 canon 不发的用户级 skill：canon-product（含 references/benchmark.md）和 canon-uat 都要求用 `agent-browser`。新机器上没有它，这两个 skill 就照着做不了。
2. 用户级规则 `~/.claude/rules/user-*.md`（07-skill-chain、09-behavior、12-tool-call-truthfulness、15-dispatch、16-context-hygiene、20-output-style）、6 个 `user-*` skill 和全局 `~/.claude/CLAUDE.md`：是 N-1（2026-11-03）从旧 lore 改写来的，只在笔记本上。Mac Studio 上 `~/.claude/rules/` 是空的，canon 自己的会话也读不到它们。

## 要改什么

- agent-browser：canon install 把它的 skill 装进项目的 `.claude/skills/`（和 canon-* 一样记进清单、不覆盖改过的文件），或者只作为 C-707 的内置依赖报出来；它的 CLI 是 npm 包，只能报、不能装。用 canon-design 选一种，记成决策。
- user-* 规则：按 canon 的“工作说明是通用流程的唯一来源”（CLAUDE.md）分两类：
  - 讲协作流程的（15-dispatch 的“子 agent 写代码在自己的 worktree、合入走项目流程”，16 的“保留进行中的工作编号”，09 里提 issue 的做法，07 的 skill 链）：并进 `canon brief` 或对应 canon skill，已经有的不重复写。
  - 和项目无关的个人风格（12-tool-call-truthfulness、20-output-style、09 的其余部分）和 6 个 `user-*` skill、全局 CLAUDE.md：是否随 canon install 装进每个用 canon 的项目（`.claude/rules/`），由负责人决定（owner-gate）。装的话会计入每个会话固定加载的文字（session_text_budget，BR-2257）。
- 规则原文只在笔记本上（N-1 记了备份位置 `~/.claude/hooks/BACKUPS/c3-global-config-2026-11-03.tgz`），开工前要先从笔记本取回。
