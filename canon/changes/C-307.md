## 为什么

独立评审（review-D31-D37-D51）指出 D-51 两处文字不实：BR-2295 和决策把 `review: none` 写成“负责人的决定”，canon 并不核对；方案 9、10 和 BR-2216 是为 #115（变更放行自己的评审）加的，按 D-54 是不正常动作，决策没说明为什么还保留；评审命令里的 `claude -p` 在临时 worktree 里会不会加载 main 的 hook 没验证。

## 要改什么

只改文字，不改代码：D-51 写明 `review: none` 是 canon 无法归属到人的项目设置（已知限制）；新增一节说明方案 9、10 为 #115 而加、保留的理由和不删代码；记下已验证的 hook 行为。BR-2145 里“没有配置评审的合入”改成“`review: none` 跳过评审的合入”（评审建议，C-265）。BR-2295 的规则文字从“是负责人的决定”改成“建议先问负责人，canon 不核对”。D-51 的状态不动（它已经是 accepted，C-304）。
