## 为什么

C-106 合入时规则评审提了两条建议：BR-2070 只说“没有提交或评论 issue 时输出 `no findings`”，按字面评审命令失败时也该输出它，正好违背这条规则要分清“评审过、没发现”和“没有跑”的目的；另外只改文档时的输出 `no code changed; nothing to review` 只写在例子里，正文没写。代码已经是对的（失败时返回错误，不走到 `no findings`），缺的是规则文字和测试。

## 要改什么

子领域：knowledge/review。只改 BR-2070 的正文和例子，加一个评审命令失败、输出不是 JSON 时不出现 `no findings` 的测试；代码不变。
