## 为什么

2026-11-21 `C-661` 的 worker 落地后，因为规则提议要设计负责人应用（BR-2525），用 `canon work stop --reason design --release` 停下并放掉了认领。之后设计负责人怎么都收不回：`canon work take C-661 --from <worker>` 说没有认领、没什么可接；`canon work start C-661` 能重新认领，但 `canon rule apply C-661` 说变更还派发着、要先 take；这时 take 又说认领在设计负责人手上、不是那个 worker 的。派发一直结束不了，规则提议也应用不了。

## 要改什么

- BR-2500：认领不在 worker 手上（已放掉，或设计负责人已重新持有）而派发还在时，`take --from <那个 worker>` 只结束派发，认领不变。
- `src/work/delegation/take.ts` 的 `takeBack`，`src/work/claims/commands.ts` 的输出。
- 测试：`src/work/delegation/take.test.ts` 新加一个。
