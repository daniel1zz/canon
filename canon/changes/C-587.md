## 为什么

C-586 合入后的规则评审意见 #162：BR-2511 还写着“它的模块不会自动挪到 `--into` 的版本，要另外改那个版本的 `features`”，和 BR-2521（并进的版本的模块算进最终并入的版本）矛盾。这句是 C-586 漏改的旧说法。

## 要改什么

- BR-2511：那句改成按 BR-2521 算进最终并入的版本，不用改标签或 `features`。
- 测试：`canon release drop R-3 --into R-4` 之后，`R-3` 上的规则出现在 `canon release status R-4` 里。
