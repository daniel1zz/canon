## 为什么

D-151 第一部分：变更的状态要能直接用脚本算出来。现在状态分散在 7 处各算各的；`C-343`（代码已在 main 但没关）、`C-406` 和 `C-1047`（交接原因只是文字）、`C-671`（只在分支上放弃，派发记录还在，一直显示停滞）都算错。

## 要改什么

按 D-151 第一部分：一个模块从变更文件（main 和在途分支）、协调事件和 git 提交算出每个变更的主状态和附加标记，所有读状态的命令改为读它；补上关闭命令、交接原因、放弃结束派发、等负责人只认带变更编号的问题；`canon change list --json` 给出主状态、附加标记和在等什么。规则先写（canon-rules），名字 D-151。
