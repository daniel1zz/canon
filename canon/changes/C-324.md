## 为什么

`floor_quiet_minutes`、`floor_max_untested`、`floor_max_age_minutes`、`review_max_unreviewed`、`review_max_age_minutes` 在 `canon/config.yaml` 里只是注释，因为当时 PATH 上的 canon 不认得它们（BR-2224）。PATH 上的 canon 已经从包含它们的 main 重新构建（`canon floor watch` 日志：after_green rebuilt from main e8015ed1c），`canon config` 在改好的配置里能列出这五个键。

## 要改什么

把五个键写成顶层的真实配置，值不变（20、10、60、10、60），中文注释保留；去掉“先只写成注释”的说明。没有规则列出 config.yaml 的内容，不改规则。
