## 为什么

C-110 合入时规则评审提了三条建议：BR-2143 没写评审命令失败时怎样；BR-2143 末尾的配置校验属于读配置这个触发点（D-5），应单独成一条；`knowledge/review` 的 README 只说评审管规则和决策。另外 canon 自己的配置要等新版 canon 构建好才能加 `instructions`（旧版不认识这个键）。

## 要改什么

- BR-2143：补上评审命令失败或没有有效结论时拒绝合入（代码已经这样做，补规则和测试）；配置格式改为指向 BR-2151。
- 新规则 BR-2151（config）：`instructions` 的格式和默认值。
- `knowledge/review` README：范围和术语加上常驻说明。
- `canon/config.yaml`：`instructions: [CLAUDE.md, src/cli/guide.ts]`。
