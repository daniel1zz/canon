## 为什么

D-159 第 1 步：文档类型要能声明 front matter 字段的格式和表态的步骤，canon 按这份声明校验和改值，后面的步骤（新建命令当场要求、内置字段、合入检查）都建在它上面。

## 要改什么

- BR-2619：`types.<类型>.fields` 可以写成字段 → 声明（`type`、`values`、`pattern`、`none`、`due`），旧的名字列表照样能读；写错是配置错误；不能声明 canon 自己写的字段，也不能重新声明内置字段。
- BR-2622：`canon check` 只校验出现的字段的格式，没出现的不报（旧文档不追溯）；修订 BR-2054。
- BR-2621：`canon doc set <编号> <字段> <值>`（`--clear` 去掉可选字段），记 `doc.set`。
- 代码：`src/knowledge/documents/fields.ts`（声明、格式校验、命令行值），`types.ts`、`config-keys.ts`、`read.ts`、`write.ts`（`setField`），`commands.ts`。
