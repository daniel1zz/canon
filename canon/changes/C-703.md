## 要改什么

只改测试，不改行为和规则：

- `reminders.test.ts`：BR-2635 写明 `--json` 每项都带 `holds`（没挡住谁时是空数组），C-694 加了它但没更新 BR-2527 这条测试的期望。main 红就是因为这条。
- `policies.test.ts`：C-701 加了 `policies.landing`，期望的分组列表补上 `landing`。
- `land-after.test.ts`、`revert.test.ts`：这几条故意让 main 失败再合入，测的是合入的提示（BR-2306）和撤回（BR-2535），C-701 的暂停（BR-2644）会挡住它们；给它们的项目配置关掉 `pause_on_red_main`。revert 那条因此要读 `policies`，后台模式会问 PATH 上的 canon 认不认识这个配置（BR-2224），所以在这条用例里放一个接受任何配置的假 canon，不依赖本机装的版本。
