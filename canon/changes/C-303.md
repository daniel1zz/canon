## 为什么

`src/knowledge/review/code-review.ts` 的 `fileFindings` 带一个 `Filing` 参数（issue 标签和署名），是为了让一致性抽查和代码评审共用而加的。负责人 2026-11-04 选择把一致性抽查“整个删掉 (推荐)”，C-299 删掉后，这个参数只剩代码评审这一种取值，C-299 的子 agent 报告里也指出了这一点。只有一种取值的参数只是多一层间接。

## 要改什么

- 去掉 `Filing` 接口和 `CODE_REVIEW` 常量，`fileFindings` 不再导出、不带这个参数，直接用标签常量和一个署名常量。行为不变（BR-2072、BR-2210）。
- 不改规则。
