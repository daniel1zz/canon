## 为什么

C-3 第 4 项：从旧 lore 的 skill 里按价值挑出值得保留的，改写成 canon 的命令。证据和取舍见 D-7：旧 skill 大多没人主动用过，只有 `lore-design` 有可观的主动使用，`lore-diagnose` 的方法完全通用。

## 要改什么

- 新增 `skills/canon-design`：保留原来的模式、质量门槛和 references；去掉 UI 流程、预览页面和 lore 的治理流程；上下文改用 `canon context`、`canon search`；结果落到决策、规则和变更文件。
- 新增 `skills/canon-diagnose`：保留原来的六个阶段和人工复现脚本模板；先用 `canon context` 看规则；修复时同步规则，测试名引用规则编号；不修的问题提 issue。
- CLAUDE.md 写明 `skills/` 的用途。
- 合入后在这台电脑上把两个 skill 链接到 `~/.claude/skills/`。
