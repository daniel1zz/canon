## 为什么

- 决策 D-42（修改 D-26）；BR-2173 重写，BR-2172、BR-2190、BR-2106、BR-2248、BR-2020、BR-2067、BR-2045、BR-2175 和两个 README 跟着改。
- `src/work/land/batch/batch.ts`：领头步骤先跑；成员步骤不过或冲突时只它回到队列；floor 不过时按前缀二分，拒绝找出的变更（`refuseInBatch`），合入通过的前缀；成员中途变了只退它和后面的，剩下的再测。
