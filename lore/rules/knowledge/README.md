# knowledge

The durable documents under `lore/` and the checks that keep them honest: file model, id allocation, search, context, `lore check`, and the AI review of rule and decision text.

## Terms

- **Rule**: one statement of what the product must do now, in `lore/rules/<domain>/BR-n.md`.
- **Domain**: a directory of rules plus a README naming the code directories it governs.
- **Decision**: why a non-trivial choice was made; `D-n`.
- **Change**: one unit of intended work; `C-n`.
- **Note**: research, retros, references; `N-n`.
