---
id: BR-2004
title: Every id named anywhere must exist
status: active
---
An id named in a document's text, in a change's `rules` list, in a decision's `supersedes`, or in a test file (rule ids only) must belong to a document in the corpus. An id written as code (in backticks or a fenced block) is an example, not a reference. Otherwise `lore check` reports `ref-dangling` at the naming file.
