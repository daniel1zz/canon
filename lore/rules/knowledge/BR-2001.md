---
id: BR-2001
title: Every document is one file whose front-matter id matches its file name
status: active
---
Each rule, decision, change and note is one Markdown file with YAML front matter. The front-matter `id` equals the id in the file name (`BR-n.md`, `D-n-<slug>.md`, `C-n-<slug>.md`, `N-n-<slug>.md`) and `title` is non-empty. A file that breaks this is reported by `lore check` as `file-invalid`; reading the corpus never stops on it.
