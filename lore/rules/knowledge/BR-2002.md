---
id: BR-2002
title: Ids are allocated above the highest id in use and never reused
status: active
---
An id is handed out by the coordination DB, never by a file in the repo. The number is greater than both the last number the DB handed out for that prefix and the highest number present in the files.

Example: the files hold `BR-1562` and the DB is new; the next rule is `BR-1563`, and the one after is `BR-1564` even if the files are unchanged.
