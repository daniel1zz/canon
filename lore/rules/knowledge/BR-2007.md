---
id: BR-2007
title: Context is the whole current domain
status: active
---
`lore context <target>` returns, for every domain the target belongs to: the domain README, every active rule in full, the accepted decisions that name one of those rules, and the open changes that name or list one of them. A target is a repo path (matched against each domain's code directories, in either direction), a domain name, or a document id (a change resolves to the domains of the rules it names or lists). Retired rules and proposed or superseded decisions are left out.
