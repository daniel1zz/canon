---
id: BR-2012
title: Starting a change gives it its own worktree, branch, change file and claim
status: active
---
`lore work start --title <t>` allocates the change id, creates `<checkout>.worktrees/<C-n>` (next to the primary checkout, outside every checkout) on a new branch `change/<C-n>-<slug>` from main, commits the change file there, and claims the change for that worktree. `lore work start <C-n>` does the same for an open change already on main.
