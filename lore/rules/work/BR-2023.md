---
id: BR-2023
title: Every coordination write records who made it, and an agent is never recorded as a human
status: active
---
Each event, claim, handoff and question records an actor, chosen in this order:

1. `LORE_ACTOR`, when set and non-blank. Inside a Claude Code session (`CLAUDECODE=1`) it must start with `agent:`; any other value is refused with exit 2 and nothing is written.
2. Inside a Claude Code session: `agent:` followed by the first 8 characters of `CLAUDE_CODE_SESSION_ID`, or `agent:unknown` when that variable is unset or blank.
3. Otherwise `human:<OS user name>`.
