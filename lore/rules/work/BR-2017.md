---
id: BR-2017
title: Main moves by compare-and-swap, and a checked-out main follows
status: active
---
Main is moved from the exact commit the floor ran on to the landed commit, or not at all (exit 1, land again). If a worktree has main checked out, it is fast-forwarded so its files match the new main; if it has uncommitted changes, main is not moved.
